# 桂子问津 Wenjin

桂子问津是一个以自我调节学习为核心的教育伴生智能平台。系统目标不是替学生完成更多任务，而是通过认知诊断、可撤销脚手架、学习证据和长期记忆，让学生逐步获得更强的独立完成能力。

## 从这里开始

1. 阅读 [项目总览与开发路线](docs/总览/项目总览与开发路线-20261005.md)，了解目标、现状和阶段边界。
2. 阅读 [项目交接文档](docs/总览/项目交接文档-20260928.md)，了解运行方式、设计锚点和已知坑。
3. 阅读 [阶段一需求](docs/需求/阶段一学习闭环-20261005.md)，确定当前开发任务。
4. 阅读 [完整功能与五阶段实施计划](docs/进度/项目最终功能清单与一周实施计划-20261005.md)，按阶段执行并回填状态；旧文件名保留链接兼容，不按一周工期约束。
5. 进入 `platform/` 查看可运行代码、测试、Web 工作台和演示工作区。

## 本地试用

在`platform/`执行`.\.venv\Scripts\python.exe -m app.main`，访问[深色学习工作台](http://127.0.0.1:8000/)。本机已配置可选密码登录，凭据只见忽略的本地配置文档；默认离线模型与明确标记的合成课程，真实课程可通过JSON/CSV来源替换。

学习流程、计划签署、项目、定性复核、恢复队列、家校共享、检索与协作均接真实本地API。PostgreSQL为独立证据归档，主运行时仍SQLite。V2提交推送已获用户授权；不把本地验收宣称为生产多租户或教育效果完成。

最新功能/测试/未验证边界见[剩余任务本地验收](docs/测试/剩余任务本地验收与生产边界-20261006.md)与[环境依赖记录](docs/指南/本地开发环境与依赖记录-20261006.md)。
