## 根目录运行方式

首次安装与正式环境准备（需要 Docker Desktop、Node/npm）：

```powershell
uv sync --locked --extra dev
uv run --locked python scripts/dev_postgres.py
uv run --locked python -m app.manage --env-file .local/database.env migrate
cd frontend
npm ci
npm run build
cd ..
# 仅首次执行，密码通过隐藏输入收取；admin 可更换
uv run --locked python -m app.manage --env-file .local/database.env bootstrap-admin --username admin
uv run --locked python -m app.main --env-file .local/database.env
```

在另一个终端启动计划处理进程：

```powershell
uv run --locked python -m app.worker --env-file .local/database.env
# 单次排查：同一命令末尾加 --once，最多处理一个输入或模型任务
```

学生端：`http://127.0.0.1:4003/student/`；管理端：`http://127.0.0.1:4003/admin/`；API 文档：`http://127.0.0.1:4003/docs`。先初始化管理员，再在管理端创建学生；已有管理员时跳过初始化。正式项目的“学习计划”已可提交目标、调整时间、确认/取消；当前草案来自固定开发模板，不调用外部模型，也不产生教学评分。只有 API 而没有 worker 时，已保存的请求会等待处理。原 HTML 保留为设计基准；旧终端演示 `uv run --locked python -m app.cli` 使用旧演示存储，不进入正式项目数据。

体验 S05：管理员进入“知识点与题库”，核对开发题版本并启用开发测试；学生选择正式项目、确认计划，再进入“津津陪学”。临时空间可直接体验独立的开发单元，不并入正式项目长期画像。标记为 `real_student` 的账号暂不能使用开发题。未知输入进入“内容与解答复核”；人工备注不覆盖原始提交和自动验证结果。

体验 S06：学生进入“错题与复习”，分别查看复习安排、不可验证与复核、学习记忆。可查看原始尝试、追加自己的说明、无提示复做，并切换局部/全局正式项目记忆。默认 1/3/7 天间隔未经过真实学生校准，提前复做不推进间隔，也不显示为已经掌握。

从 S05 升级时，先停 API/worker、备份并迁移，再核对历史事实（默认只报告；确认可重建后加 `--apply`）。具体见 22 号文档：

```powershell
uv run --locked python -m app.manage --env-file .local/database.env backfill-learning-facts
uv run --locked python -m app.manage --env-file .local/database.env backfill-learning-facts --apply
```
