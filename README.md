# 桂子问津 Wenjin

桂子问津是一个以自我调节学习为核心的教育伴生智能平台。系统目标不是替学生完成更多任务，而是通过认知诊断、可撤销脚手架、学习证据和长期记忆，让学生逐步获得更强的独立完成能力。

## V5 当前版本

V5 在 V4 研究 MVP 基线上整合近期本地改进：陪学与角色协作流程、项目/临时会话隔离、全局与项目成长证据、素养可视化、规划 Agent 候选 Harness 和复习队列。使用方法见 [V5 工作台与项目学习使用手册](docs/指南/V5工作台与项目学习使用手册-20261009.md)；V5 变更见 [更新记录](CHANGELOG.md)。本地运行数据、密钥和学习主库备份不随源码发布。

## 本地试用

在 `platform/` 执行 `.\.venv\Scripts\python.exe -m app.main`，访问 [学习工作台](http://127.0.0.1:8000/)。本机已配置可选密码登录；默认离线模型与明确标记的合成课程，真实课程可通过 JSON/CSV 来源替换。

学习、计划、项目、定性复核、恢复、共享、检索和协作接本地API。学生入口 `/` 或 `/learning`；教师 `/teacher`、家长 `/parent`、本地资料与恢复 `/research` 不等于学校SSO。PostgreSQL包含证据归档及显式学习域Repository切片，正常Web主运行时仍SQLite。本地冻结全量与浏览器已通过，不等于远端CI、生产多租户或教育效果完成。

当前功能/测试/未验证边界见 [V5 项目工作空间与规划 Harness 实施记录](docs/进度/V5项目工作空间与规划Harness实施-20261009.md) 和 [V5 架构差距审计](docs/测试/V5-架构愿景与实现差距审计-20261008.md)；V4 覆盖矩阵保留为历史参考。
