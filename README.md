# 桂子问津 Wenjin

桂子问津是一个以自我调节学习为核心的教育伴生智能平台。系统目标不是替学生完成更多任务，而是通过认知诊断、可撤销脚手架、学习证据和长期记忆，让学生逐步获得更强的独立完成能力。

## 本地试用

在`platform/`执行`.\.venv\Scripts\python.exe -m app.main`，访问[深色学习工作台](http://127.0.0.1:8000/)。本机已配置可选密码登录，凭据只见忽略的本地配置文档；默认离线模型与明确标记的合成课程，真实课程可通过JSON/CSV来源替换。

学习、计划、项目、定性复核、恢复、共享、检索和协作接本地API。学生入口 `/` 或 `/learning`；教师 `/teacher`、家长 `/parent`、本地资料与恢复 `/research` 不等于学校SSO。PostgreSQL包含证据归档及显式学习域Repository切片，正常Web主运行时仍SQLite。本地冻结全量与浏览器已通过，不等于远端CI、生产多租户或教育效果完成。

当前功能/测试/未验证边界见[V4覆盖与限制矩阵](docs/测试/V4功能覆盖与限制矩阵-20261006.md)；既有环境见[环境依赖记录](docs/指南/本地开发环境与依赖记录-20261006.md)，本轮增量工程依赖与最终测试以V4工程/冻结记录为准。旧[剩余任务本地验收](docs/测试/剩余任务本地验收与生产边界-20261006.md)保留为历史参考。
