# 桂子问津

初版工程现已平移到仓库根目录，Python 入口为 [`app/main.py`](app/main.py)，依赖配置为 [`pyproject.toml`](pyproject.toml)。原工程运行说明保留在 [README.legacy.md](README.legacy.md)，其中 `cd platform` 等旧路径应以当前根目录为准。

项目以初中数学自主学习闭环为核心：目标与计划、探究式学习、验证与反馈、反思和路径调整。S03 已交付独立 React 双端与真实账号/空间；S04 接入计划确认图；S05 接入方程与应用开发闭环；S06 接入项目复习、原题无提示复做、来源追溯与局部/全局观察记忆。当前使用自编开发题与确定性支架，尚未接真实模型和专业教师审核。

## 根目录运行方式

首次安装与正式环境准备（需要 Docker Desktop、Node/npm）：

```powershell
uv sync --locked --extra dev
uv run --locked python scripts/dev_postgres.py
uv run --locked python -m app.manage --env-file .local/database.env migrate
cd frontend
npm ci
npm run build
cd ..
# 仅首次执行，密码通过隐藏输入收取；admin 可更换
uv run --locked python -m app.manage --env-file .local/database.env bootstrap-admin --username admin
uv run --locked python -m app.main --env-file .local/database.env
```

在另一个终端启动计划处理进程：

```powershell
uv run --locked python -m app.worker --env-file .local/database.env
# 单次排查：同一命令末尾加 --once，最多领取并处理一个输入
```

学生端：`http://127.0.0.1:8000/student/`；管理端：`http://127.0.0.1:8000/admin/`；API 文档：`http://127.0.0.1:8000/docs`。先初始化管理员，再在管理端创建学生；已有管理员时跳过初始化。正式项目的“学习计划”已可提交目标、调整时间、确认/取消；当前草案来自固定开发模板，不调用外部模型，也不产生教学评分。只有 API 而没有 worker 时，已保存的请求会等待处理。原 HTML 保留为设计基准；旧终端演示 `uv run --locked python -m app.cli` 使用旧演示存储，不进入正式项目数据。

体验 S05：管理员进入“知识点与题库”，核对开发题版本并启用开发测试；学生选择正式项目、确认计划，再进入“津津陪学”。临时空间可直接体验独立的开发单元，不并入正式项目长期画像。标记为 `real_student` 的账号暂不能使用开发题。未知输入进入“内容与解答复核”；人工备注不覆盖原始提交和自动验证结果。

体验 S06：学生进入“错题与复习”，分别查看复习安排、不可验证与复核、学习记忆。可查看原始尝试、追加自己的说明、无提示复做，并切换局部/全局正式项目记忆。默认 1/3/7 天间隔未经过真实学生校准，提前复做不推进间隔，也不显示为已经掌握。

从 S05 升级时，先停 API/worker、备份并迁移，再核对历史事实（默认只报告；确认可重建后加 `--apply`）。具体见 22 号文档：

```powershell
uv run --locked python -m app.manage --env-file .local/database.env backfill-learning-facts
uv run --locked python -m app.manage --env-file .local/database.env backfill-learning-facts --apply
```

启动与安装包检查（需要 dev 依赖）：

```powershell
$env:RSI_TEST_POSTGRES = '1'
uv run --locked pytest -q
uv run --locked python scripts/check_server.py
uv build --out-dir .local/dist
uv run --locked python scripts/check_wheel.py .local/dist/rsi_platform-0.1.0-py3-none-any.whl
```

体验 S07：管理员在“知识点与题库”单独审核并启用互动模板；学生在项目或临时空间进入“圆桌讨论”或“我教 AI”。两条路线都先保留学生表达，再展示固定观点或预设误区，最后保存数值核验和过程小结。陪学与互动依次进行；角色尚未连接真实模型，解释质量与素养尚未评定。详情见 24、25 号文档。

体验 S08：学生进入“成长证据”，切换全局宏观/当前空间局部、时间窗口和来源，查看真实过程统计与趋势。来源记录支持类型筛选、分页与原文查看，学生说明单独保留。全局排除临时空间；归档只读。六个观察方向尚无审核量规与校准，不显示能力分数。详情见 26、27 号文档。

体验 S09：先停服备份并迁移到 `s09_001`，再启动 API/worker。管理员在“策略评审 → 课程资料”录入并发布开发参考；学生在正式项目的“规划与策略”提交自述、时长/反思重点和资料引用。管理员审核后仍需学生确认才激活；支持 Skill.md 导出与历史回滚。新陪学保存策略快照，旧运行不随回滚变化；旧 tutor.v1 运行可查看/取消，需要重新开始后使用 v2。真实模型另行确认，本轮为固定开发候选。详情见 28、29 号文档。
