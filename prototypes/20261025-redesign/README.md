# 两套前端布局与使用体验原型

设计问题：保留现有功能，怎样让用户知道从哪里开始、如何继续和怎样回看，而不在单页中不断向下寻找模块？

打开 `index.html` 比较两个方向。所有HTML均内嵌样式和脚本，无CDN、字体下载或模型调用，单个文件可直接复制打开。为匹配用户要求，采用两个独立版本，不修改正式React前端或认证。

| 版本 | 学生端 | 管理端 | 主要区别 |
| --- | --- | --- | --- |
| A 问津书院 | a-student.html | a-admin.html | 米白、墨绿、衬线标题；分组导航与清晰下一步；成长页为顶部五分类 |
| B 问津学习站 | b-student.html | b-admin.html | 深蓝、鸢尾紫、薄荷色；目标任务台、线性学习路线；对话情境栏在左，成长为独立目录布局 |

## 功能归属

- 学习空间：正式项目、临时会话、切换、重命名、归档和恢复。
- 课程与安排：当前课程、学习安排、配套资源；单元库从资源进入。
- 三大活动：津津陪学、圆桌讨论、我教AI均保留直接导航；包括示例对话、提示、活动冲突时恢复/结束、独立检测状态。
- 互动课堂：三场景、公式、课堂回答、本机音色朗读（需设备支持）、本地数轴动画；不冒充新生成的外部音视频。
- 错题与复习：待复习、已安排、待澄清、原始尝试与演示数值检查。
- 成长：总览、知识与表现、复习与支持、素养材料、学习记录。一次只展示对应分类；范围、时间、分类写入hash，支持浏览器返回。关闭来源抽屉不替换主页面。
- 规划与策略：依据、可选参考、差异、确认/拒绝、恢复原安排。
- 学习方式改进：保留Skill语义；候选差异、个人试用、自动建议与撤回，不宣称效果已验证。
- 我的：语音、隐私、演示密码校验、使用引导。
- 独立管理端：支持概览、账号、知识与课程、课堂媒体、内容/解答复核、策略评审、评测与教学验证、Skill评测、运行记录、模型与权限。管理数据与学生数据不相互写入。

这是设计评审用的前端模拟，并非新的后端实现。对话与建议为固定自编演示，输入不会出网；统计为合成数据，不能当作学习效果。状态只保存在页面内存，刷新后复原。示例数值检查只用于演示反馈位置，不能替代正式数学验证器。不要填写真实密码或密钥。

## 本机预览与再生成

在仓库根目录执行：

```powershell
.venv/Scripts/python.exe prototypes/20261025-redesign/source/build.py
.venv/Scripts/python.exe -m http.server 8769 --bind 127.0.0.1 --directory prototypes/20261025-redesign
```

然后访问 http://127.0.0.1:8769/index.html 。也可直接双击HTML离线打开。

`source/theme.css`、`source/prototype.js`、`source/build.py`用于保持四个独立文件同步。原型属于当前debug分支，待用户比较后再选择正式实现方向。
