# 桂子问津前端演示原型 v2

两个独立入口，均可用浏览器直接打开，无需安装依赖：

- [学生端](桂子问津_前端演示.html)
- [管理端](桂子问津_管理端演示.html)

每个 HTML 都内嵌完整样式、脚本和 SVG，可单独复制分享。两端不提供角色切换、不共享登录状态；正式产品仍需独立认证和服务端授权。原有 `docs` 基准和初版工程保持原状。

## 页面与空间

学生端包含项目与会话管理、今日学习、数学单元、计划、陪学、复习、圆桌研讨、我教 AI、成长证据、规划与策略、偏好设置。

工作空间分正式项目和临时会话。项目可创建、重命名、归档和恢复，各自保存草稿、提示级别、计划、反思、研讨、教学练习与策略版本。临时会话不自动进入项目计划、复习或画像。全局成长证据汇总正式项目历史，包含归档项目，排除临时会话。

管理端包含试点概览、知识点与题库、内容与解答复核、运行记录、策略评审及配置权限。

## 建议体验

1. 在学生端切换两个项目，分别留下作答或聊天，再切回确认记录隔离。
2. 新建临时会话，发送问题后查看全局证据，确认该对话未被纳入正式项目。
3. 在圆桌研讨中依次听三席观点，填写自己的解释，再核查共同结论。
4. 在我教 AI 中纠正虚拟学弟的公开误区，观察追问和 TeachReport；到项目成长证据查看过程记录。
5. 在成长证据中切换全局宏观与项目局部，查看六维素养雷达、维度条与证据来源；补充学生自述。
6. 进入规划与策略，编辑学生自述、教材/讲义、课标、考纲/检查点；也可导入本地 `.txt`/`.md` 摘录。
7. 生成候选 Skill.md，运行演示检查，导出候选 JSON；打开独立管理端，在策略评审中导入。
8. 管理端填写评审理由、确认策略边界并导出回执。回到原学生端页面导入回执，再由学生确认激活。回滚保留版本历史。

文件往返演示时保持学生端原页面打开，刷新会重置内存状态。管理端内置审核示例仅供单独预览；要完成某个学生项目的往返，请导入该项目实际导出的候选。

## 演示边界

所有统计、题库规模、素养坐标与学习趋势均为模拟示例；六维图不是经过验证的测量量表。新增解释与讨论只保留过程证据，不自动折算为素养分数。

数学检查和多角色发言使用预设模板。规划草案同样由模板生成，不调用在线模型，不改写真实 Skill.md，不运行实际回归或晋升。离线评审回执和校验码不提供身份认证、防篡改或真实权限控制。

全部状态只在当前页面内暂存，刷新后重置。无后端、数据库、真实通知或上传服务。教材与课标摘录先标记为待核验资料，不能覆盖教学硬约束。

后续必须实现的事项见 [后续实现清单](后续实现清单.md)。

## 原型维护

`source/workspaces.js` 和 `source/workspaces.css` 是本次扩展的维护源，构建脚本将它们内嵌到两个独立 HTML。修改后运行：

```powershell
python prototypes/source/build_prototypes.py
```

构建只更新原型目录，不修改项目文档、后端或数据库。
