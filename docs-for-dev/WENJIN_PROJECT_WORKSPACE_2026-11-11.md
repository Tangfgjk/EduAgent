# 项目工作区导航改造

复用现有学习项目作为主题容器，不把账号的内容工作区与学习项目合并。侧边栏只列项目，文件夹图标和缩进子会话表示归属。单题从项目列表移除，转到“全部练习与错题”；其他旧学习记录与未归属对话保留折叠入口。

项目默认打开对话列表，提供新建项目对话、章节与学习、资料、项目练习和诊断入口。会话继续使用 path_id 绑定，资料使用已有项目资料关联；练习通过后端 mastery_path_id 过滤，旧题没有明确来源的不猜测归属。当前不实现任意普通对话跨项目搬移、跨项目共享文件或 ChatGPT 的项目记忆能力，避免把导航调整误称为完整记忆重构。

验证侧边栏排序/搜索/会话归属以及前端类型。资料、诊断和学习服务仍沿用原账号工作区权限。
