# 经典诊断算法独立调研

日期：2026-11-09。仅查阅一手资料，未安装库、训练模型或验证本项目部署。下文「建议」是针对桂子问津的工程判断，不是来源论文已经验证本场景。

## 结论

建议采用「现有能力证据门 + BKT 影子估计 + 受控题目与评分」作为第一阶段；PFA 作为积累数据后的预测基线，DINA/G-DINA 留给固定知识范围的正式诊断小测，IRT 留给已校准题库的能力估计/选题。算法开源不等于存在适用于任意主题和聊天的预训练诊断模型。BKT 首先适合做可重放的持续状态估计，而不是立刻替换能力门或输出精确掌握百分比。

IRT 与 DINA 在 EduCDM 中均有现成实现，但初始类或示例参数不等于已经校准的新生成题参数。IRT 更适合回答给定量尺下的能力/答题概率；不能单凭一维能力准确定位多个知识点缺口。以上为工程适配判断，不建议在无共同题或锚题校准时直接比较跨试卷 theta。

## 对「BKT 优先」的挑战

以下是基于本项目数据形态的推断与实施约束：

1. BKT 不会自己阅读聊天。它仍需要受控任务、可靠评分、技能映射、时序和模型参数。开放回答如果由同一个大模型出题并打分，会有相关错误；BKT 可以持续累积这种错误，并不能校正它。
2. 经典二元 BKT 不应把 partial 随便当 0.5 当成二元观测；首期 partial、unknown、voided、conflicting 和有辅助成功均保留事实但不进入「独立掌握」更新。之后若建多观测类别模型，需要独立验证，不能说这是原始 BKT。
3. 讲解、看视频、说「我懂了」不是一次独立答对。若后续考虑学习事件转移，需校准资源/转移参数，不能每次聊天自动增加学习概率。
4. 新题同时涉及多个技能时，整体答错无法直接定位哪个技能不会；不要把一条失败机械复制成每个技能都失败。先用单目标探测，或使用带已验证 Q 矩阵的联合模型。
5. 猜测率不应一律等于选项倒数，失误率不应凭经验固定后称作已校准。动态题型/难度、提示与复述都会改变观测含义。
6. 一个遗忘转移参数不自动意味着已经建模真实日历间隔；按天衰减必须定义和验证时间模型。
7. 不把四类能力（辨别、解释、应用、迁移）压成一个均值。可将技能×能力视为候选独立轨道，但数据会更稀疏，不能贸然宣称跨轨道独立或通用共享。

## 建议验收与准入

- 先定义算法接口与版本化回放：输入只读统一事实，输出 p_known、p_next_correct、参数来源/版本、有效样本、排除原因、是否已校准；两个概率不可混名。
- 影子阶段数值只用于开发核查，不改变已掌握和撤架；对学生显示「证据不足/待核查」及实际来源，不给出无校准的 83.72% 精确判断。
- 用合成序列和手工贝叶斯计算校验实现，再对照 pyBKT；固定参数包版本以保证回放。合成验收只证明计算正确，不证明教学有效。
- 开放作答先建立人工复核的匿名评分样例，测评分一致性与错误案例；不确定结果先复核而非强行更新。避免 AI 自己生成的评分标签既训练又评价诊断。
- 按学生和时间切分训练/验证；同题变体、重复尝试、同一会话不得漏到双方。报告 log loss、Brier、校准曲线，并与朴素基线/PFA 比较；AUC 不是概率校准或学习效果证明。
- 不预设「几名学生/几道题即可可靠」的统一数字；依据范围、参数可识别性、留出结果和误差决定。正式效果要看独立迁移与延迟任务，不能只看下一题预测。
- 作废/评分纠正后按来源 ID 重新回放，避免重复计入。跨用户/工作区隔离，当前模型不可擅自修改评分、知识映射或掌握门槛。

## 推荐落地顺序

A. 选一个受控知识范围和少量核查任务，完善题目—技能及评分依据版本。
B. 实现经典 BKT 受约束参数的影子估计，并与 pyBKT 对照，明确固定参数未校准。
C. 积累人工核查过的匿名本地作答，拟合/交叉验证 BKT，与 PFA 竞争；冷启动继续用现有能力证据规则。
D. 达到准入标准后才让概率有限影响探测优先级；撤架仍要求真实独立能力与后续验证。
E. 固定小测任务稳定后再评估 DINA/G-DINA；题库充分校准后再接 IRT/CAT。不同时引入所有模型。
