# 学生自配模型接入（2026-11-14）

用户已确定：学生各自配置提供方与 API Key，不默认共享管理员模型。

## 已完成

- 普通学生设置中新增“我的模型”：提供方、可选 HTTPS 服务地址、模型 ID、密码框形式的 API Key；保存后清空输入，可删除配置。
- 初次配置必须提供密钥；留空仅保持同一提供方和地址的密钥，更换提供方或地址必须重新输入。
- 配置保存在账号对应的服务端 system 私密目录，接口只返回密钥是否存在，不返回明文；不进入学生工作区目录。
- 个人模型进入本人模型选项、能力许可和运行时解析。后台自动规划使用学生默认模型，不继承管理员 task 模型。
- 已登录请求绕过进程全局 LLM 配置缓存，防止用户之间错误复用密钥。未配置模型的普通学生得到设置引导，不使用管理员缓存。
- 当前支持一个个人 API 模型；个人 OAuth 入口继续兼容。管理员继续使用已有“提供方/语言模型”设置。

## 验收

- 个人 API 模型隔离/缓存保护及已有个人 OAuth 回归：13 项通过。
- Docker PostgreSQL 恢复后训练集成：4 项通过，无跳过。
- 个人模型表单、陪学、诊断和训练界面交互：8 项通过。
- TypeScript 类型检查通过。
- 实际 HTTP 普通学生流程：公开注册201 → 登录200 → 读取空配置 → 保存测试配置 → 脱敏响应 → 本人模型选项可见 → 删除配置；验收账号已删除。
- 未向外部服务发送测试密钥，未冒用管理员密钥。使用新学生自己的真实密钥完成外部模型对话仍需学生在页面配置；不把模拟配置称为真实模型调用验收。

## 使用

登录后打开 http://127.0.0.1:3782/settings/personal-models ，填写自己的配置后返回学习。该个人模型同时用于陪学与自动规划；模型费用由提供方账号承担。
