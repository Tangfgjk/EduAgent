# 持续诊断与模型自主教学判断（2026-11-10）

本次采用经典无遗忘 BKT 的轻量在线重放；官方参考为 https://github.com/CAHLR/pyBKT ，对照版本 pyBKT 1.4.3。验证依赖见 requirements/diagnosis-validation.txt。线上不依赖拟合库，也不调用外部专有诊断系统。

## 分工

诊断提供事实与实验估计；导师模型结合学习目标、意愿、当前回答，自主决定讲解、追问、练习、提示、可逆地减弱或恢复帮助。既有 action/scaffold 保留为兼容的回退建议，不再作为必须执行的脚本。模型必须简要说明下一步理由。mastery_status 的 wenjin.decision 与评分后工具输出均包含该契约，系统提示也明确分工。能力入账、来源核验和待答题约束仍由服务端执行，模型不能通过一句“已掌握”修改成绩。

## 算法与数据

prior=.2、learn=.1、guess=.2、slip=.1 是工程假设，不是拟合结果。状态后验与下一次答对概率分开；初始无有效记录时不发布掌握概率。当前是 shadow/uncalibrated，模型不得以数值阈值撤架或跳课，也不得向学生输出准确掌握百分比。

记录按项目、知识目标契约哈希、能力类型、题型和评分方式/版本分流。评分时保存目标契约快照；旧记录缺少快照不倒填、不按名字迁移。辅助/未知辅助、部分正确、无回答、作废/冲突、重复任务、缺少任务/评分契约、目标契约变化均排除。结构化语义评分允许实验跟踪，但明确标记未经独立验证。生成题质量和综合题的技能划分尚待验证，不等同于成熟题库。

从当前有效事实按时间及稳定 ID 重放，不另存可漂移的概率总表；撤销、修正、迟到事件可重新计算。只有已加载项目进入计算，不读取其他学生、工作区或项目。外部报告不初始化 BKT、不作为独立作答。

## 使用

打开学习项目进入陪学，展开“学习详情”，可见“持续诊断 · 实验跟踪”和有效独立作答数。输入主题即可开始，不需要上传资料。完成新注册任务后，诊断进入下一轮导师上下文；日常聊天、阅读、自述理解不直接计分。旧会话已有记录可能显示零条，因为它们缺少新增的目标契约快照。

## 后续边界

本次没有完成本地参数训练、评分人工一致性验证或教学效果实验。PFA/DINA/IRT 未接入。只有经过学生/时间隔离验证的参数与适用范围，才可从 shadow 升级到经校准的教学统计依据。模型自主判断仍以真实表现与学生选择为基础，BKT 单独不授予能力信用。
