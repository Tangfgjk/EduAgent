## 1. PostgreSQL 业务迁移

- 已切换账户、对话/消息/轮次、项目、大纲、学习进度、能力证据、诊断快照的实际业务读写。
- 原始迁移基线：4 个业务库、53 张表、49,176 条记录；全量行内容及数量核验一致。
- PostgreSQL 业务表保留主键、外键、唯一索引、自增序列；每个账号/工作区有独立业务 schema，来源由服务端私密资源映射解析。
- 账户使用 `account_records`：独立用户记录、唯一用户 ID 和用户名、角色约束；写操作由数据库事务锁串行化。旧 `account_registry` 是冻结迁移副本，不再参与业务读写。
- 新账号库首次初始化后自动迁移并加入资源映射；新学生自己项目可读，读取其他账号项目返回 404。
- 模型作用域沿用稳定 scope_id；资源映射相对 runtime-home 保存，避免移动项目后把旧 SQLite 误当新数据。
- 数据库凭据和资源配置位于 `data/system/postgres/`，不进入学生智能体工作目录和 Git。
- SQLite 和 users.json 仅保留迁移基线备份；切回旧文件会丢失切换后的新增数据，不能直接关闭标志当作恢复。
- 恢复演练：使用同一 PostgreSQL 快照导出备份，恢复到独立临时数据库，179 张表、131,970 行逐表数量比较通过后清理恢复库。包含暂存/测试模式，不应当作真实学生数据量。
- 已按新服务端凭据路径重建 PostgreSQL 容器，保留原命名数据卷；健康检查和重建后的业务回归通过。
- 上传文件、资料文件继续存文件系统；日历、运行协调等其他子模块仍可使用自己的 SQLite，未声称全应用消灭 SQLite。

## 2. 个人训练闭环

- 手动按钮创建持久化队列任务，并冻结当前项目、当前用户的数据集。
- 拟合经典无遗忘 BKT 参数：前 80% 序列拟合，后 20% 做时间留出检查；记录 Log loss / Brier 和样本范围。
- 目前采用工程门槛：至少 50 条合格作答、两个序列、每个序列至少 10 条、包含正误。该门槛不是已验证的教学标准。
- 验证通过且目标范围仍匹配才启用；失败或数据不足保留当前模型。不同用户数据不会合并。
- 当前参数注册表、前一版本和回退已接通；模型变更与项目版本、审计事件在同一 PostgreSQL 事务提交。在线诊断按当前有效模型重新回放证据。
- 持久化任务含租约、心跳、重试、幂等和人工重试；重启后按租约恢复（最长约 180 秒），最多自动尝试三次，失败可点击重试。
- 普通聊天、自述、模型评分待核验、来源不完整、模拟/验收项目及曾求助的任务不直接纳入独立训练数据。
- 训练流程使用隔离的模拟夹具做工程验收，没有把模拟记录混成真实学生训练数据，也未声称完成真实学生参数校准。

## 3. 自动规划与撤销

- 训练后后台自动调用配置的真实模型，不要求学生再发一句话。
- 输入为当前目标、学生档案、学习状态、证据及训练结果。模型判断保持计划或重排已有模块/知识点顺序。
- 规划输出做结构校验、知识点集合校验、先修依赖检查、版本冲突检查和当前任务位置保护。
- 决定、理由、任务 ID、来源版本写入审计。修改课程结构另存前后版本；可撤销自动重排，保留所有学习证据。
- 自动规划不删除/新增知识点，也不能直接授予掌握或仅凭 BKT 阈值撤去帮助。涉及知识点增删的历史人工改动仍要求协调引用后恢复。
- 真实模型验收：无独立作答时选择 keep，解释“未知不等于不会”；决定成功落库。报告在私有 real-planner-acceptance.json（无真实学生个人信息）。

## 4. 接续与脚手架

- 每轮读取最新项目目标、未完成任务、能力证据及结构化活动；不会用旧对话摘要覆盖新进度。
- 新对话提供“继续上次/换个问题”。若已有未完成任务，继续入口返回该任务原会话，避免重复注册和替换原任务。
- 帮助类型包含方向提示、换讲法、举例、拆步、类似例题、自检和反思。
- 点击只保存 scaffold.requested；实际提示通过 interaction.hint_delivered 保存原任务、对话和交付轮次。请求不冒充交付。
- 跨对话新增共享内容使用结构化状态和来源编号；自动复制其他会话原文的方案被审批拒绝，已采用更安全的结构化方案。

## 5. 诊断界面与学习流程

- 五个视图：学习概况、证据溯源、数据质量、个人训练、计划变化。
- 默认首页先说明当前目标、已观察到的表现、下一步核查；训练计数及技术限制放对应视图或折叠区域。
- 学习记录、训练资格、能力判断分开展示，训练排除不被呈现为学生答错。
- 精确来源详情、请求/实际提示记录、任务状态、规划理由、模型回退和计划撤销均有入口。
- 浏览器实走：登录 → 仅输入主题创建项目 → 确认基础/目标/时间 → 生成一个知识点大纲 → 新建学习会话 → 正式任务作答 → 正确解释证据落库 → 请求帮助 → 实际提示交付记录 → 查看诊断。
