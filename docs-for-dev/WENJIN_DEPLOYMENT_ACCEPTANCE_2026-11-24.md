## 本轮发现并修复的阻断问题

初次真实陪学测试失败：`The selected workspace folder does not exist.`。

根因是辅助 SQLite `data/**/.runtime/workspaces.sqlite3` 中的工作区登记仍为原 Windows 物理路径，原迁移脚本只覆盖 JSON 与 PostgreSQL。页面、历史查询和健康检查正常，不能证明真实对话正常。

修复提交：`147c819dc`，已推送到 `V23-20261118-Deploy` 并部署到服务器。新增 `scripts/relocate_wenjin_workspaces.py`，并将其集成到 `relocate_wenjin_release.py`。运行 `--apply --workspaces-only` 修正两个辅助登记库、四条登记，补建两个托管目录，保留工作区/账户标识及说明正文。修改前的 SQLite 备份保存在服务器 `data/backups/workspace-relocation/`。

回归测试：`tests/deployment/test_workspace_relocation.py`，6 项通过；覆盖原迁移入口、备份、幂等、个人账号根目录限制、非法路径和外部路径不被误改。

## 当前限制与后续验证

1. Linux 不支持 Windows 本机配音，当前没有可用的个人 TTS 配置，因此新配音和配音视频生成尚不能验收通过；已有音视频完整保留。
2. 当前按用户选择保持 HTTP，浏览器 `isSecureContext=false`、`navigator.mediaDevices` 不可用，网页麦克风录音不能正常使用。此轮未启用 HTTPS 或续期服务。
3. 陪学首轮较慢（约 101 秒），多步模型反馈仍需性能优化；不能用页面加载正常代替响应速度达标。
4. 示例历史项目的 4 条旧证据均缺少合格训练依据，训练可用为 0，系统正确显示需要至少 50 条、两个有效序列且包含正误；本轮没有伪造数据来触发训练。
5. 尚未完成真实学生长期学习、大量学生并发、训练参数质量与自动计划回退的完整验收，不能据此宣称系统已达大规模正式运营标准。
