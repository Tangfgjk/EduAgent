# 课堂语音、导出、模拟与视频实现及验收

日期：2026-11-14。

## 已实现的可使用范围

- 语音：本页中文真实配音、音频控件、按音频时间显示字幕、WAV/VTT下载。默认不自动播放。
- 导出：全课PDF与可编辑PPTX；附资料名称，不导出测验正确答案。公式以文本保留，当前不是OMML/LaTeX原生公式排版导出。
- 模拟：模型根据当前页生成的分类实验，以及从当前页整数系数ax+by=c提取的方程坐标实验。坐标滑块、直线、移动点、左/右计算结果实时显示。均遵循预测→操作→解释，记录持久化，不直接生成独立掌握标签。分类参考由模型生成，未声称金标。
- 视频：全课1280×720配音课件MP4、外置中文VTT字幕、网页播放及文件下载；是课件视频，不是文生写实视频，也不是Remotion动画或自由生成仿真。

## 资源与权限

新增classroom_media.py与独立PG资源任务表，服务端账号/项目/课堂授权贯穿提交、状态、文件读取和模拟操作。相同内容/类型/所有者缓存，生成失败可按资源重试。队列采用SKIP LOCKED、租约token、定期心跳及完成提交检查；重启可按租约恢复。文件位于data/system/classroom-assets，不暴露任意路径；文件读取限定已完成任务清单。音频视频支持浏览器Range读取。

语音在本机使用Windows System.Speech的Microsoft Huihui Desktop中文引擎；不需要外部多模态模型，也没有读取、复制或输出旧项目API Key。Linux等部署需另外接入平台适用的中文语音引擎，当前实现不宣称跨平台语音已验收。

FFmpeg使用imageio-ffmpeg提供的二进制；依赖记录在requirements/classroom-media.txt。大文件不进入Git。当前媒体队列串行执行，尚未做大规模多worker容量与计费认证；音频/视频没有运行中立即终止的专用控制，生成失败重试与断点资源缓存已经实现。

## 使用

学习项目→互动课堂→等待全课就绪→“语音、导出与互动资源”。选择本页配音、PDF/PPTX、分类模拟、方程坐标实验或配音视频。生成后在同一区域播放/下载；视频字幕可在播放器中开关。方程实验要求当前页包含可识别的整数系数ax+by=c，不适用时使用内容分类练习，不偷偷替换为无关例子。

## 保留的边界

复杂公式的图形化排版/原生公式导出、任意领域的自由模拟、动画导演、多音色/外部语音配置以及写实视频模型不包含在本次实现范围。语音是本机中文引擎，视频为配音课件，不能把这些称作已接入外部多模态大模型。生成内容和模拟结论仍需核查。
