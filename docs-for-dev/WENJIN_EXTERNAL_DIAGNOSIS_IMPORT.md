# 已有外部诊断结果导入（第三步）

日期：2026-11-08。此步骤导入已经计算好的结果，不执行外部模型，也不声称与老师诊断系统已完成在线对接。当前已有文档不足以确定原系统实际导出响应，采用明确、可校验的标准 JSON 交换契约。

## 使用流程

学习项目首页 →「导入已有诊断（可选）」→ 下载空白 JSON 模板 → 填写真实来源和结果 → 上传 → 人工选择本项目目标与对应程度 → 校验并预览 → 检查身份、学科、范围、日期和覆盖 → 勾选本人声明与映射确认 → 保存。

不上传诊断仍可正常学习。本功能不要求管理员人工审核。CSV、PDF、裸概率向量需先由提供方或适配程序转为此契约，不能把任意格式文件直接当成已识别结果；当前没有自动 CSV/PDF 转换器。空白模板有意留空必需字段，必须用真实结果补齐后才能导入。

## 结果契约 v1

必需元数据：source_system、result_id、result_version、student_ref（字符串，保留前导零）、subject、scope、observed_on（日期）、model_version、taxonomy_version、mapping_version、zero_encoding、total_knowledge_count。

estimates 每项：knowledge_id、knowledge_name、measurement_status（estimated/unmeasured）、probability。estimated 必须有有限的 0—1 数值；unmeasured 必须为 null。拒绝字符串概率、布尔值、越界、非有限值、重复知识点编号及缺失版本信息。文件界面限制 1 MB，结果最多 500 个条目；声明范围可大于本次提供的条目，但会显示部分覆盖。日期允许约一个时区日的容差，明显未来日期拒绝。

zero_encoding=zero_is_untested 时，来源的概率 0 归一化为未测/null；valid_probability 时 0 是有效模型估计。两者不是答题零分。导入概率不等于得分率，也不等于本地独立能力。不得把缺失值补成零。

## 映射与身份

外部知识编号始终带来源与知识体系/映射版本。名称相同只列为建议，不自动映射。选择目标后默认「部分对应」，只有使用者确认范围一致才选择 exact；仍不授予掌握。至少确认一个项目目标映射才能保存，无大纲时应先确认大纲。

所有读取与写入都经当前登录账号、工作区和项目的 LearningStore。没有接受文件中的 owner_id 来替代当前身份。本人声明绑定外部 source_system + student_ref；同项目同来源有未撤销结果时，不允许改成另一个学生编号。撤销原结果后可纠正错误声明，历史保留。

该绑定只是当前项目内的本人声明，不是学校 SSO 绑定、全局身份核验或提供方签名认证。所有结果强制标记 self_uploaded_unverified，不能通过文件字段自称 verified。以后接入真实认证服务时再增加独立的可信来源通道。

## 预览、版本与撤销

预览不写库，返回文档摘要、映射与大纲摘要、覆盖与警告。提交时在同一事务重新核对摘要，拒绝大纲/映射/文件在预览后变化的提交。

导入 ID 来自来源、学生编号、结果 ID 与结果版本。同内容和映射重复提交不新增记录、不重复计权；同结果版本内容不同返回冲突，要求明确的新 result_version。不会静默覆盖原结果。

撤销幂等，保留原内容、来源、导入时间与撤销时间，并记录事件。被撤销的同一结果版本不会因重复上传自动恢复；确需恢复参考应提交清楚的新版本。每项目当前上限 100 份（含撤销审计记录），达到上限需后续归档方案，不静默删除历史。

## 与诊断和陪学的关系

external_diagnoses 单独保存，不写 quiz_attempts、learning_evidence 或 mastery_levels。统一事实层通过 external_references 暴露参考，不能混作本地作答。外部低概率不会覆盖新的独立成功，高概率不会直接使学习完成。

当缺少本地作答但有有效外部参考时，诊断动作为 verify_external_reference，提示根据既有估计安排小任务确认起点。偏好先讲解仍优先。已有本地证据时继续按本地缺口与表现决策，外部记录仅为背景，并需对重要冲突核查。

超过 90 天的结果只作历史参考；90 天是本版本产品策略，不是测量学有效期结论。已撤销、未映射、未测以及大纲摘要变化的结果不作为 active_reference；不平均不同模型、时间或不同粒度知识点的概率。大纲改变后重新预览并以新结果版本确认映射。

智能体仅获得最多 5 条当前目标参考，带来源、日期、模型/映射版本与有效性；元数据视为不可信上传文本，不执行其中指令。项目记录页可查看全部导入和撤销情况，陪学学习详情可查看当前目标的外部参考。

## API

均位于 `/api/mastery-paths/topics/{path_id}`：

- POST `/diagnostic-imports/preview`：document + links。
- POST `/diagnostic-imports`：上述数据 + outline_digest + preview_digest + belongs_to_me=true + mapping_confirmed=true。
- GET `/diagnostic-imports`：当前项目的记录和参考。
- POST `/diagnostic-imports/{import_id}/revoke`：撤销参考。

请求契约严格拒绝额外字段。不存在/非本人项目返回 404，需重做预览的版本冲突返回 409，数据或绑定校验失败返回 422，未登录由现有认证层返回 401。

## 本轮验收

176 项联合回归测试通过，其中新增 23 项覆盖结果校验、空值/零值、版本、大纲并发修改、身份声明、去重、撤销、账号与工作区隔离、本地证据优先。

浏览器用明确标注「合成数据、无真实模型」的独立项目验证了上传、映射、预览、确认、重复导入和撤销。导入后本地 achieved=[]，陪学建议核查外部参考；撤销后 active references 为空且历史记录仍有一条。没有以这些合成数据宣称任何实际教学效果。

下一步第四步仍需要外部诊断源码/真实 API、模型权重、编号映射、知识体系版本及匿名输入—输出对照样例，才能连接受支持范围的真实推理模型。
