# 互动课堂：章节配音、讲解视频与播放接续

日期：2026-11-15。实现基于现有项目目录与课堂课件，未引入另一套课堂大纲。

## 使用流程

1. 学习项目 → 互动课堂 → 顶部“配音与视频”。
2. 在“课堂资源”选择当前页、当前章节已准备页面或完整课堂，以及配音来源与语速。
3. 点击“生成配音”或“生成讲解视频”。可以先用已准备页面；完整课堂范围和PDF/PPTX导出要求课件全部就绪。
4. 任务卡显示当前步骤和已处理页数。可取消；失败或取消后点击“继续生成”，复用已完成配音及视频片段。
5. 资源就绪后直接播放；可调整倍速，按章节时间轴跳转，回到当前PPT页，或暂停后向津津提问。
6. 播放位置与倍速按账号、课堂、资源保存于PostgreSQL。刷新、离开后可接续。
7. 下载视频、配音、字幕或讲稿；旧版资源通过“历史资源”展开。

## 本次完成

- 音视频支持页/章/全课范围、配音速度和本机/个人TTS提供方。章节快照明确标记不完整范围，已完成章节无需等待全课。
- 新课件支持 spoken_script 自然中文讲稿。已有课件从标题、正文、全部讲解区和公式构造讲稿，常见中学代数公式转为可朗读文字；不播报LaTeX命令。
- 本机中文语音自动选择已安装中文声音；个人语音沿用现有设置服务，密钥不写入任务或前端。无静音成功降级；语音失败会明确报错。
- 按标点切分旁白，以真实音频长度生成字幕；配音统一24kHz单声道PCM，按视频帧时间补齐页尾短停顿。
- MP4采用1280×720 H.264 + AAC + 内嵌中文字幕轨，并提供外置VTT；讲解区标题能与旁白匹配时按实际时间强调对应卡片，未匹配时保持完整PPT画面。
- 视频片段只编码画面，整条合成音轨一次编码，避免逐页AAC拼接累积延迟。音频时长、视频时长与时间轴实际一致。
- 配音缓存跨同课堂的音频/视频复用，文件锁防止重复合成；取消可终止本机TTS和FFmpeg进程，外部语音请求也检查取消。
- 视频与其他资源分队列执行；任务租约、取消令牌、进度和检查点持久化。服务重启后在租约到期恢复，已完成片段复用。
- 文件丢失的缓存任务重新排队生成；资源列表按生成时间排序，播放记录更新不改变“最新资源”版本。
- 公式PNG增加持久化缓存，减少长课堂重启后的重新渲染等待。
- 所有任务、控制、播放位置和文件端点继续验证账号、项目和课堂；课堂删除使资源不可访问并撤销运行令牌。
- 观看与播放接续不生成独立掌握标签，不修改学生诊断结论。

## 运行与边界

- 本机配音依赖Windows中文语音组件；其他部署可使用个人设置中的TTS服务。Linux需中文字体，媒体依赖见requirements/classroom-media.txt。
- 真实生成验收使用Windows本机语音；已接通个人TTS适配层，未逐一向所有外部提供方付费调用验收。
- 视频是带配音、字幕及讲解区强调的PPT讲解视频；没有声称已实现任意实景文生视频、数字人或自由动画仿真。
- 配音中常见代数符号采用规则读法；复杂公式仍应通过课件和讲稿查看，不宣称完整覆盖所有学科数学语音。
- 首次课件内容仍来自生成模型，流程验收不等同于逐页学科专家审稿。

## 开发路径

- deeptutor/learning/classroom_av.py：讲稿、配音、字幕、共享缓存、视频和进程取消。
- deeptutor/learning/classroom_media.py：资源快照、队列、进度、控制和播放持久化。
- web/components/learning/ClassroomMedia.tsx：资源准备与任务列表。
- web/components/learning/ClassroomPlayer.tsx：播放、字幕、时间轴与陪学接续。
- web/lib/classroom-captions.ts：VTT时间解析。
- tests/capabilities/test_classroom_av.py、test_classroom_media.py及web/tests相关用例：回归。
