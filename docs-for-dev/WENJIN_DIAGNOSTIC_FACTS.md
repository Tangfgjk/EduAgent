# 统一诊断事实层（第一步）

实现日期：2026-11-08。对应五步方案中的第一步，不启用新的教学决策、不导入外部诊断、不运行 KT 模型。

## 使用

打开 `/learning`，进入一个项目，在资料区下面展开「诊断依据（数据记录）」。显示各目标的有效观察条数及独立/有辅助/未知辅助分组；可继续展开来源与原始回答。刷新按钮重新读取。空记录显示尚无有效记录，不显示薄弱或掌握百分比。

只读 API：`GET /api/mastery-paths/topics/{path_id}/diagnostic-facts`。沿用当前登录用户与工作区，服务端创建 scoped LearningStore；无权访问的路径返回 404。该 API 没有提交评分或修改掌握状态的写入口，不能通过它制造诊断事实。

## 数据契约

`diagnosis_models.py` 定义 schema_version=1 的 DiagnosticContext、DiagnosticObservation、DiagnosticFacts。

- 一次观察关联项目内知识点、题目、原始记录引用、会话与轮次、发生时间、能力类别、回答、原记录结果、辅助状态、有效性和限制说明。
- 原记录来源是 learning_evidence 与 quiz_attempts；对同一次评估的两个存储表示只投影一次，不另建互相冲突的评分表。新作答通过 diagnostic_evidence_id 显式关联。
- 新注册题目评分记录题干、题型、目标名称、题目契约哈希、评分依据哈希和 native-v1 记录口径版本。哈希用于识别契约变化，不是证明评分正确。正确答案不通过新接口泄露；完整原契约继续由原生 interaction/题目存储负责。
- grading_method 标明 deterministic/semantic/legacy。native-v1 是本地记录口径版本，不能当作提供方实际模型版本；实际提供方审计需结合原轮次日志，旧记录无法凭空补齐。
- 助力状态为 independent、assisted、unknown；注册题目的新评分依据实际辅助标记记录；只有旧 independent=true 的记录不被自动认定为已验证独立。开放定性旧流程没有完整辅助证据时保留 unknown。
- 有效性为 recorded、voided、conflicting。recorded 表示来源记录可归并，不代表测量效度已被证明，也不自动授予掌握。
- 本地没有原始分数时 score/max_score 均为 null，不把 quality 或正确性虚构成试卷得分。契约验证有限数值、合法满分与得分范围；0 是有效分数，缺失是 null。

## 自述与行为分开

LearnerProfile 仍为当前画像来源。新的 profile 更新事件额外保存变化值、可用的原学生消息、会话与轮次；读取时形成不可变历史视图。历史事件只记录字段名而没有字段值时，不用当前值伪造过去内容。当前画像只是一份视图，不另外增加能力证据。旧记录的原话、事件时间及来源缺失明确保留限制。

普通聊天、读完章节、说「我懂了」不会被自动评分。所有证据仍由既有受控任务/评分流程产生；本层没有让大模型扫描聊天并猜测掌握概率。

## 旧数据兼容与去重

不迁移覆盖旧掌握状态，不改变原政策门控。LearningProgress 新字段为可选，旧数据可直接读取。

旧记录只有在题目 ID + 知识点 ID 两侧均唯一时才合并作答与复习收据，并注明是旧记录推断关联。同题重复且不能明确配对时标 conflicting，保留供核查但排除有效计数。新记录显式关联可区分同题重做，不靠名称、最近时间或列表位置强行配对。

作废来源仍可追溯但不计有效观察。模型结果与原记录冲突不静默选择一个。投影输出带 source_revision，读取前后校验版本，发生并发更新时重试或返回 409。列表索引形式引用用于该 source_revision 的来源定位，不是跨任意删除重排后永久不变的全局 ID。

## 验收与边界

测试覆盖无证据、自述、旧记录未知助力、关联去重、同题重做、歧义、作废、结果冲突、任务版本、分数 0/缺失/非法值、自述历史、持久化和跨账号隔离。原评分、语义评估、提示与画像流程纳入回归。

真实浏览器验收：已有验收项目显示 3 条观察，其中有辅助 1 条、未知辅助 2 条，没有把历史默认值补成独立证据；API 返回 200，分数缺失保持 null。

这一步只回答「记录了什么、来自哪里、辅助与有效性怎样」。下一步才基于这些统一事实调整 teaching_decision、解释诊断、核查冲突与提出下一步任务。现有旧掌握显示可能与新事实统计不同，第一步没有静默回写或重新判分。
