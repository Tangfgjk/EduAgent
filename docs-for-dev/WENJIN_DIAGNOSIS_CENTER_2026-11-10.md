# 学习诊断中心：证据与数据集

入口：学习项目页面 → 学习诊断中心。两个标签为学习证据、训练数据。

证据来自已有结构化陪学作答和提示事件，不另抓取全部聊天作为训练标签。详情保留题目快照、回答、评分方式、辅助情况、事件和会话/轮次。查看原对话走账号作用域内的会话接口，关联导师消息 ID 或轮次元数据，高亮来源轮次；历史无定位信息明确降级，不按文本猜测。自由交流不自动生成正误标签；已有自述单独展示。

训练准入复用 BKT 快照与独立二元结果规则，并要求会话轮次来源；语义评分暂排除待核验，旧任务缺契约、辅助、重复和无效数据排除。识别到名称含模拟/验收的项目也排除，另支持创建时声明模拟数据。名称检测不是可靠真实性鉴定，尚需真实数据治理。当前范围限本人当前项目，学生编号在单一数据集内去标识，不允许据此跨数据集合并学生。可手动排除样本，不能手动强行纳入不合格数据。

训练快照保存在当前用户/工作区 LearningStore SQLite 的 diagnostic_datasets 表，固定源版本、规则、有效训练字段、所有候选记录及排除原因和来源。事务内校验源版本，旧版本不会被后续评分改变。保存 SHA256 内容摘要。导出训练字段不包含对话正文；完整导出含来源与回答。旧快照反映历史，不自动随评分撤销而更新；训练前需要创建最新快照。当前没有训练/指标页面，不生成模拟指标。

暂不实现跨项目知识等价映射、自动把自由交流升级为有效标签、人工核验工作流或训练/验证划分。这些是后续校准前的必要工作，当前数据集状态均标未验证。
