# 课件编辑与版本管理

2026-11-21。

## 使用

互动课堂生成完成后，点击课件标题旁的「编辑课件」。每次编辑先进入自己的持久草稿，刷新可继续。正文、标题、公式、讲解区、版式、讲稿和备注可修改；白板可改步骤。复制新页可拆分长内容，也可移动页面或移除草稿页；必须保留每个知识点的讲解。测验页及私有答案契约不开放编辑。

保存并预览后，填写修改说明，点击「发布新版本并打开」。产生新的课堂 ID 与递增版本。原课堂、作答、学习位置、诊断证据和媒体继续保留。课堂中的「课件版本」可以回到旧版；历史课堂选择也标明版本。

编辑后的内容标为待核查，保留原资料线索但不冒充重新核验的结论。配音讲稿不会随正文变更继续默用旧稿：未同步修改的旧讲稿清空，留空时按新页面内容朗读。新版本需重新生成配音/视频/导出；媒体按内容、版本所属课堂与所有者隔离，旧资源不会作为新版资源交付。修改标记同时进入画布、PPT/PDF、视频画面；课堂转入陪学时包含内容来源与版本。

## 持久化与约束

- 草稿保存在 PostgreSQL wenjin_classroom_drafts，按现有账号/工作区 scope 和项目隔离。
- 同一原课堂只保留一个活动草稿；发布和放弃后可新建下一份草稿。
- 草稿保存使用 revision 和行锁，冲突返回409，保留客户端尚未保存的文字。
- 发布校验原内容快照，使用同一事务保存新版本与草稿发布回执；重复发布不会多生成一份版本。分支发布也分配不同版本号。
- 公式、坐标数据、版式容量、字段范围均在服务端校验；仅编辑结构化字段；修改的图文禁用HTML渲染，不提供代码执行入口，也不能修改知识点归属、来源引用、测验答案及成绩。
- 发布课件不增加掌握/训练证据，不修改项目目录或学生模型。旧题仍能回到原课堂版本。

## 后续

本项为结构化课件编辑，不包含自由画布拖拽、上传自定义图片或智能改写。后续多人部署仍需处理多标签事件流连接管理、作业并发及资源配额、备份恢复演练。长期学习效果仍需真实独立与延迟任务数据，编辑行为不构成学习效果证明。
