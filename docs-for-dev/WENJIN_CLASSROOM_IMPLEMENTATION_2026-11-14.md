# 互动课堂第一批实现与验收（2026-11-14）

## 实现范围

已实现图文课堂主链：项目内入口 → 沿用目标/知识点/资料 → 后台生成大纲 → 学生修改标题/目标并确认 → 逐页生成课件/逐步白板/选择题 → 当前页问答 → 作答或明确跳过 → 回顾 → 诊断来源回链。

新增代码：deeptutor/learning/classroom.py，项目mastery-paths课堂API、lifespan worker、Classroom.tsx及项目路由。使用独立PG课堂表、已有账号/工作区scope和模型解析。没有复制OpenMAIC的数据库、账号或整套应用；借鉴其大纲确认、场景和检查点组织，当前未直接移植其第三方渲染包。

生成每步落库、领取时行锁+租约token、模型超时与有限重试，失去token不能提交旧结果；后台重启可在租约过期后恢复。当前worker串行处理场景，不声称完成多worker容量认证。课程内容为不可变生成结果；仅失败步骤重试，已完成页的可视编辑/再生成尚未开放。

正文复用现有Markdown/数学渲染，关闭原始HTML与外链图片。测验答案不返回浏览器，判分在服务端；重复作答幂等，跳过不记错误。课堂题目由模型生成而未获金标验证，全部按受助且待核验保存，禁止直接进入独立BKT训练。诊断记录保存课堂id/scene/version，可回到原页；回到陪学可读到结构化课堂活动。

资料使用项目当前已选来源的片段快照；上传不是必须的。当前不执行新增联网检索和全文RAG召回，不能把无资料生成称为已检索验证。资料展示编号、名称、引用片段；重要知识仍需核查。
