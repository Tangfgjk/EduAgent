### 课堂恢复机制

- 首次作答先落回执；此事务失败时不会留下学习证据。
- 证据同步失败后回执仍存在，重试不能换成另一选项覆盖第一次作答。
- 证据写入成功、确认状态写入失败时，可以重放，不重复记证据。
- 页面重新读取和后台课堂 worker 都能重放；worker 恢复原用户与工作区并核对存储作用域。
- 回执保存课堂版本、时间、页面及作答时的诊断上下文。同步等待期间更改大纲，不会把旧答案重新标到新知识点。
- 旧版故障若已经留下证据但没有课堂答案，优先恢复已提交证据中的事实；无法匹配时拒绝静默覆盖。
- 新课件版本清空答案与待同步回执；删除课堂前先处理其待同步记录。
- 私有页面答案、outbox 和存储路径不投影到学生公共返回值。

这是一套可恢复的一致性机制；跨存储的同步中间态不被伪装成同一数据库原子事务。

- 新产生的真实学习证据单独标记来源；旧项目并不会永久丧失收集新训练数据的能力。

### 本轮额外发现的 Windows 长路径问题（已完成环境修复）

两项知识库移动集成测试在嵌套索引/图片路径较长时失败。实验说明仅给临时目录加 Windows 扩展路径前缀，可能复制成功却仍使发布后的引用不可读，因此没有保留这种不完整的修复。

最终核对发现本机 `LongPathsEnabled=0`，当前进程不是管理员。用户明确授权开启后，通过管理员授权执行了 `scripts/windows_long_paths.ps1 -Action Enable`，保存原值备份，再确认配置为 `1`。使用新 Python 进程复跑知识库移动测试，**14 项全部通过**，包括原先失败的两项。

脚本默认 `-Action Check` 为只读；`Enable`、`Restore` 需要管理员权限。原值备份位于 `data/system/windows-long-paths-backup.json`，支持恢复，不自动重启系统。既有进程若缓存旧配置，需要重新启动后采用新设置。没有保留不完整的临时路径补丁，也没有降低原集成测试断言。

示例（管理员 PowerShell，仅在需要恢复时）：

```powershell
& "C:\Users\21709\Desktop\DeepTutor\DeepTutor\scripts\windows_long_paths.ps1" -Action Restore
```
