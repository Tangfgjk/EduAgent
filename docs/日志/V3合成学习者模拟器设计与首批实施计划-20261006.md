# V3合成学习者模拟器设计与首批实施计划

记录时间：2026-10-06 17:33（Asia/Shanghai，UTC+08:00）。当前分支：本地 `V3`。本轮仅完成设计纳入和文档更新，尚未实现模拟器代码、未提交、未推送。

## 本轮判断

用户提出真人数据难获得，建议用模拟人类智能体与桂子问津对话。评估结论：合理采纳为V3开发方向，但将其定位为合成学习者模拟器，不宣称是真人替代品。它适合连续闭环、策略筛选、预校准、红队和压力测试；真实课程审核、真实学习者效果、真实参数校准、生产合规仍保留独立验收门。

## 架构落位

```text
app/learning/       桂子问津学习事实、状态和决策，保持唯一所有权
app/agents/         派生角色与TeachVirtualStudent，保持现有单回合功能
app/simulation/     SyntheticLearner独立bounded context（V3-S1待开发）
simulation/{run_id} 模拟轨迹、隐藏状态快照、评估报告（与真人数据隔离）
```

模拟客户端通过正常API驱动主系统；主系统不读取模拟器隐藏状态。评估器在仿真侧把隐藏状态与主系统公开估计对照，不能把对照结果写回真人学习状态。

## V3-S1实施顺序

1. 先定义Pydantic schema、版本、seed、profile和场景ID；拒绝额外未定义字段。
2. 实现六类最小画像和固定误区库；误区触发概率由结构化规则决定，LLM不决定正确性。
3. 实现隐藏状态更新、行为策略和可重放随机源；明确提示、完整答案、独立作答、失败和遗忘的增益规则。
4. 实现SimulationStore或run目录隔离、脱敏审计和结果manifest；禁止写入真实SQLite的学习证据表。
5. 实现SimulationClient适配层，优先走公开API；为白盒故障测试单独标记，不把内部调用混成黑盒结果。
6. 实现Evaluator和五组实验，报告仿真版本、参数、seed、轨迹、限制和失败样本。
7. 再评估可选LLM renderer；默认离线确定性，远程模型没有合规Key时保持not_executed。

## 第一批实验

| 实验 | 比较 | 主要指标 | 禁止结论 |
|---|---|---|---|
| 支架渐撤 | 频繁主动提示 vs R-07预算/渐撤 | 独立成功、提示依赖、退出 | 不推断真人自主性提升 |
| 过早答案 | R-01拒绝测试；必要的离线答案暴露反事实 | 当前完成与下一题独立表现 | 不关闭Governor；不推断真实教学效果 |
| KT识别 | 隐藏掌握vs估计；下一次作答预测vs实际二值结果 | 潜变量MAE；作答概率Brier/校准误差 | 不混用概率对象；不称真实参数已校准 |
| 复习调度 | 隐藏保持/遗忘 vs review scheduler | 到期召回、漏复习、误报 | 不称Retention规律已验证 |
| 画像红队 | 六类画像与误区 | 安全规则、状态污染、异常退出 | 不把画像当真实学生分布 |

## 与现有功能的关系

`TeachVirtualStudentRunner` 继续服务“学生讲解，虚拟学生暴露误区”；新Simulation服务“桂子问津教学策略，模拟学生连续学习”。两者共享ActionGovernor和版本/证据纪律，但不共享真人状态写入口。

`calibration.py` 的 `synthetic_ai_generated` 与 `real_learning_data` 分离保持不变；模拟结果可以产生软件评估或预校准候选，不能增加 `real_sample_count`、解锁 `promotion_gate` 或生成 `authorized_human`参考。

## 当前未做与风险

- 没有实现代码和UI入口，因此本日志不称模拟功能已完成。
- 没有真实课程教师审核、真人Pilot、真实参数校准或生产压测；模拟器不会消除这些缺口。
- 主要风险是模拟器偏差、隐藏状态泄漏、仿真结果污染真实指标和LLM随机越过状态规则；验收门必须先于renderer扩展。
- 运行规模、并发压测、模型调用成本和结果保留策略待实现后再定，不能先写成生产承诺。

完整接入方案见[架构设计](../架构/V3合成学习者仿真实验子系统设计-20261006.md)，特别包括单用户API限制、独立应用工厂、显式配置防止继承本机凭据、时间注入与随机流，以及未实现source_kind核心字段的边界。
