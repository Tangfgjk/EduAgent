## 2. 文件与功能

### Provider Registry

文件：`platform/app/llm/registry.py`。

- 注册不可重复的 provider/model/config；支持现有 OpenAI-compatible 客户端、FakeLLM 和配置外部端点。
- timeout、能力、配置版本、模板版本、request ID 与候选状态进入 provenance。API 密钥只能通过环境变量名引用，不成为 config 字段、事件字段或文档内容。
- endpoint 禁止内嵌用户密码及 query/fragment，避免 URL 携带凭据。
- 首选失败时，允许一次显式配置的 fallback，记录 `fallback_from` 与 degraded，不递归调用回退环。
- 生成和回退调用受 Governor 审查，候选文本再作红线检查。返回值 `trusted_for_delivery=False`；教学消费者仍需形成 QUESTION/HINT/EXPLAIN 等具体动作并执行相应 Governor，不能把通用生成结果直接送到学生。
- Registry 提供 close 关闭 HTTP 客户端。没有真实远端 smoke，原因是没有模型 API key；FakeLLM 测试不作为外部模型可用证明。

### 真实最小 RAG

文件：`platform/app/learning/retrieval.py`。

- `RetrievalPort.retrieve(query, context)` 与 `RetrievedEvidence` 独立于 Gateway 和 Storage。
- Markdown 使用 markdown-it-py CommonMark 解析；PDF 使用 pypdf，按行/页和长度切块。PDF 从已经哈希的相同字节解析，避免文件变化造成版本与内容不一致。
- 文档内容 SHA-256 作为 source_version，chunk ID 包含源 ID、版本和块序号。
- BM25 固定参数 k1=1.5、b=0.75；英文词、中文字符及双字词确定性分词；分数相同按 source/chunk ID 排序。
- citation 包含可打开的本地绝对路径和准确行号/页码。源文件更改、删除或越过知识根目录后不输出旧引用。
- `grounded` / `ungrounded` / `conflict` 显式返回；无 KC 或目标 KC 冲突的结果不能用于教学。接地只表示候选材料具备必要条件，不能替代 Verifier。
- 扫描/无文本页面、加密、损坏、不支持格式和空文档均明确失败，导入失败不破坏上一版本的索引。
- 当前索引在内存中、没有文档上传 API、持久化历史原文副本、向量或混合检索、OCR。源文件被更新后历史引用保存需要后续版本化文档库，不把该最小端口标为完整知识库。

真实资料检查结果：`docs/研究/参考资料/` 下四份 PDF 的各页均为 0 字符可提取文本。真实 PDF smoke 结果为明确失败；含 PDF 真实文本流的 fixture 验证了读取文本与 page=1。没有安装 OCR，没有声称扫描资料导入成功。

### 三类派生角色

文件：`platform/app/agents/derived.py`。

- 提示者：hint/question；怀疑者：question；评审者：feedback/question。角色范围写入代码，报告不能增权。
- 输入需 KC 与 evidence refs。模板版本 1.0.0，授权工具列表为空。
- 输出为严格 Pydantic 报告，附 turn/output-token 预算、输入引用、开始状态、退出原因、耗时、产物及逐动作审查。
- 一次调用、禁止隐藏重试；非法 JSON、空报告、工具请求、角色越权、超预算和迟到输出均有显式退出状态。
- 输出 UTF-8 字节数作为保守 token 上界，不冒充供应商真实 token 统计；max_tokens 是可交付输出上界。请求不包含厂商通用 max_tokens 参数，远端成本还需后续完整 usage 端口控制。
- 同一报告批量主动提示会递增本地 GovernorContext.hints_used，防止在一次报告中重复耗用同一预算。
- 考试场景 hint 统一绑定 exam_item，R-09 裁决；反馈 REWRITE 后只保留改写结果。
- 当前 BaseLLM 是同步调用；deadline 保证迟到结果不交付，不提供通用硬取消线程。网络时限由配置 Provider 的 HTTP timeout 控制。报告 observations 仅是候选审计内容，不直接推导掌握或原始事实。
- 暂未连接唯一 Agent Runtime/API/Web，也未替代旧模板调用，避免半集成造成回归。
