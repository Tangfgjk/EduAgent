## 1. 端口契约

### CalibrationObservation

输入是一次模型预测与授权人工参考的比较记录，必须含 `source_kind`（`synthetic_ai_generated` 或 `real_learning_data`）、`collection_research_authorized`、`consent_version`、模型/参数版本、evidence/reference 引用、分组、时间和支架字段。生成样本可以统计为 synthetic 数量，但永远不会进入 `real_sample_count`。

### evaluate_calibration

```python
evaluate_calibration(history, report_id, as_of, authorize, config=None) -> CalibrationReport
```

`authorize(observation)` 是调用方当前 research 授权检查；仅 observation 内的历史布尔字段不授予访问权。报告输出全局和可展示分组错误率、95% Wilson 二项区间、拒绝原因、模型/参数版本、独立学习者数和被隐藏小群体数。每个学习者只保留一个校准观察，重复尝试归入 `same_learner_cluster`，避免把同一学习者当独立样本。

默认 `min_real_samples=50`、`min_group_samples=10`，小群体只计 `suppressed_group_count`，不输出 group 名或指标。全局结果无有效样本时错误率和区间为 null。报告固定 `educational_effect_claim=false`、`automatic_promotion_enabled=false`，明确校准错误率不是教育效果。

### human_sampling_plan

```python
human_sampling_plan(history, seed, sample_size, as_of, authorize) -> SamplingPlan
```

使用固定种子、优先错误样本的内部抽样方案，输出 observation refs 和错误样本数；`publicly_publishable=false`，报告不包含学习者标识。抽样方案仅供授权人工复核，不声称已完成复核。

### promotion_gate

```python
promotion_gate(candidate, report, review, verify_review, verify_report) -> PromotionGateResult
```

参数候选必须使用新版本。晋级至少要求真实独立研究样本、错误率 Wilson 上界达标、评估模型/参数版本完全匹配、分组没有未完成验证、人工 review 记录引用同一 report 且 `verify_review` 通过。结果只可能是 blocked、manual_review_required、candidate_ready_for_manual_activation；`automatic_promotion_enabled=false` 与 `changes_applied=false` 永远固定，不把人工选 token 或配置确认当教育效果证据。

`verify_report` 必须由调用方验证可信报告来源并重新检查当前 research 授权，省略或返回 false 时门控 blocked，防止缓存报告在研究授权撤回后仍然支持候选激活。`verify_review` 不接受 token 选择当复核，必须核验同一报告的人工复核记录。人工 review 时间不能早于评估 as_of。

## 2. 真实数据与合成数据边界

真实校准必须来自 research 用途授权、独立人工 reference；teaching-only、future observation、提示/答案暴露、模型生成 reference 和当前撤回授权均排除。合成输入只能用于检查管道和拒绝逻辑，不能提高真实样本量，也不能解锁晋级门。

数据报告没有 learner_ref 原文，只返回聚合计数；小组少于十个独立样本完全隐藏。Wilson 实现固定 95% 二项区间，边界 0/全错和非法输入都有测试。
