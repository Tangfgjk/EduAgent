## 结构与准入边界

- 每个 KC 必须覆盖诊断、练习、前测、后测、迁移、延迟阶段；测量阶段每 KC 至少两个不同题 ID。缺失、重复题干、同题版本换名、比较组/rubric/难度不匹配都阻挡结构准入。
- 提示从 0 连续至 N，禁止显式答案暴露；也检查未标记的 `x=最终答案` 形式。该规则不声称能识别一切自然语言答案泄漏，教师逐题复核仍不可省略。
- 难度和近迁移描述都是草案假设，没有真实等价性校准；正文明确迁移类型，不能把文字改写称为远迁移。
- 真人课程准入除了结构通过，还需来源用途合法、受信来源权利 verifier、真实审核记录、完整逐题审查覆盖及当前版本 hash。不能把单个课程准入报告当作 Pilot/伦理批准。
- 真人测量必须从受信证据仓库验证真实来源、当前授权以及全历史中的首次暴露；调用者不能只传 `attempt=1` 就获得研究资格。离线模块不提供可由前端用户设置的 verifier。
- 研究方案含 10～30 人的建议探索范围，不主张统计效力或已获招募权限。未成年人研究授权和监护/学习者授权分别要求。
- 保留期限与删除政策仍待实际机构决定；草案不凭空设定合法期限。自动 RSI/参数晋级继续关闭。
- 未修改运行中个人 8000 服务、真人数据库或模拟器模块；独立审核 CLI 不提供或写入真人数据。
