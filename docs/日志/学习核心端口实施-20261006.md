## 已实现功能和职责

`platform/app/learning/mastery_port.py`：`update_mastery(state, evidence) -> (state, skip_reason)`。冻结 `bkt-v1` / `bkt-default-v1`，参数 `p_learn=0.15`、`p_guess=0.2`、`p_slip=0.1`，先验由 `MasteryState` 默认为 0.1。函数不修改输入，不读取时钟，不访问数据库，不调用 LLM。

仅无提示、无答案暴露、无辅助的 passed/failed 二值观测更新 Mastery。partial、unverifiable 保留为事实，由存储审计跳过原因。独立成功才参与后续 Gate，避免在支架下完成被认定为独立掌握。共享资格检查拒绝跨学习者、跨 KC、缺 teaching 授权、重复消费和未知观察策略。

置信度冻结为 `heuristic-count-v1`：`n / (n + 3) × 最低有效验证置信度`。同等验证质量时随证据数量单调增加；低质量证据可以降低该数值；缺失置信度按 0 处理，必须修正证据后重建才能恢复。该数值是保守启发式，不能当作已校准统计置信区间。BKT 失败更新包含学习转移，因此低先验时不保证单次失败让概率降低；高掌握状态下失败会降低概率。

`platform/app/learning/gates.py`：`evaluate_gate(state, evidences, profile) -> MasteryGateResult`。定量模式同时检查概率、数量、置信度；定性模式检查足够独立证据、质量与至少多个定性判定；混合模式必须两者同时通过。返回 mastered / not_mastered / insufficient_evidence / uncertain，保留有效证据、配置引用和原因。重复 Evidence 不增加投票；缺失来源、冲突 Evidence、未知置信方法都不能直接掌握。

`platform/app/learning/review_port.py`：`update_retention(state, evidence) -> (state, skip_reason)`、`retrievability(state, as_of)`、`review_task(state, as_of)`。冻结 `exponential-v1` / `retention-default-v1`；仅无辅助 review/pre/post/transfer 作答参与。Mastery 和 Retention 独立消费，practice 可以更新 Mastery 而不更新 Retention。

Retentivity 实验模型：`R(t)=exp(-elapsed_days/stability)`。成功 stability × 1.8、difficulty − 0.05；失败 stability × 0.35、difficulty + 0.1、lapse + 1。stability 范围 0.25–3650 天，difficulty 限 0–1。下一次复习间隔为 `max(0.05, -ln(0.8) × stability)` 天，目标可提取度 0.8。到期才生成带显式 as_of 和确定性 task_id 的 ReviewTask；还没有保持度证据时返回 None。该算法用于建立可重放闭环，尚未经教育效果数据校准，也不是 FSRS。

`platform/app/learning/replay.py`：`replay(evidences, learner_id, as_of) -> ReplayResult`，其中包含按 KC 的 `mastery` / `retention`、有效事实集合 `evidence_refs` 和每证据/消费者跳过或晚到注解 `skip_reasons`。调用方固定证据集合和事件序号截止；Replay 以 `event_seq` 全序处理、按发生时间不超过 as_of 筛选。重复同内容去重，不同内容同 ID 或重复事件号报错。

追加修正用 supersedes 排除旧判定，不修改原始事实。晚到 Retention 在线返回 `late_evidence_requires_replay`；重放用 `max(previous.last_review_at, occurred_at)` 作为有效处理时间，同时记录 `late_evidence_replayed_at_effective_time`。原始 occurred_at 保留。该语义保持事件全序与稳定重放，不声称按历史发生顺序重新估计。修正必须引用同学习者、更早序号、相同 KC 范围的证据；错误 KC 映射更正需要独立资产迁移，尚未实现。
