# V3学校身份班级关联与独立学习实例实施

记录时间：2026-10-06 20:18（Asia/Shanghai，UTC+08:00）。分支本地V3；未提交推送，未修改gateway/routes.py或config，未写用户真实数据库。

## 实现

新增`app/school/identity.py`（持久身份/tenant/class/membership/assignment/哈希session）、`application.py`（独立学校FastAPI factory）、`federation.py`（未配置OIDC端口）；`scripts/school_instance.py`提供受信离线provision/assign和loopback8012独立启动。

每个学习者使用hash文件名独立Store；student只能own，teacher/parent只assigned且双方仍在当前class；密码PBKDF2、bearer仅存hash，active/role/assignment随请求重查。无public注册/role自授/内部任意代理。

学生metadata不泄漏题干答案，issue/hint/submit内部使用严格server-issued ticket。教学授权source由学校account派生，不信请求source；不通过学校端授予research/evolution。旧highpriv端点一律403，教师/家长不能用旧token代学生写入。
