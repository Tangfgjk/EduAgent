# V5.3 侧边栏创建项目入口补充

更新时间：2026-10-07（Asia/Shanghai）  
关联版本：V5.3 计划版本与签署体验  
状态：本地实现与验证完成

## 调整目标

将“创建项目”和“编辑项目计划”分开：左侧项目栏负责按名称创建、选择和切换项目；计划页只负责当前项目的说明、目标、任务、里程碑、版本与签署。

## 已实现流程

1. 左侧“进行中的项目”标题右侧新增“＋ 新建”。
2. 展开后仅要求填写项目名称，支持取消。
3. 点击“创建并进入计划”后创建空项目，自动切换为当前项目，并打开计划页。
4. 新项目初始不包含目标契约、计划版本、任务、里程碑、聊天或证据。
5. 学生随后在计划页建立目标与成功标准；在“编辑当前项目”区域维护项目说明、任务和里程碑。

## 边界

- 创建项目不自动生成目标、建议、草案或签署计划。
- 已有目标契约的项目在计划页编辑任务与里程碑时，仍遵循 V5.3：先生成未签署草案，签署后才应用安排。
- 未授权教学用途时，侧边栏创建按钮被禁用；服务端也继续执行授权检查。
- 本次未引入“项目名称唯一”硬约束，允许同名项目以兼容已有数据；后续可增加同名提示，不以名称代替项目 ID。

## 涉及文件

- `platform/web/learning.html`：侧边栏创建面板、计划页编辑文案。
- `platform/web/workbench/workbench.js`：创建、自动切换、打开计划页与授权撤回后的清理逻辑。
- `platform/web/workbench/presentation.js`：授权撤回时禁用侧边栏创建按钮。
- `platform/web/workbench/workbench.css`：侧边栏创建面板样式。
- `platform/tests/test_learning_workbench.py`：界面控件结构回归检查。
