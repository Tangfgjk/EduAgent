## 1. 授权与边界

本轮允许先使用 AI 生成课程数据，再替换真实课程数据。生成数据是课程题目和提示资产，全部明确 `synthetic_ai_generated`、`not_real_evidence=true`、`calibration_status=demo`，不生成学习者作答、学习 Evidence、掌握轨迹或教育效果结论。

AI 本次编写生成模板与代码，题目由 Python 固定种子规则生成，不声称调用外部 LLM 批量出题。没有向模型厂商上传资料，没有使用第三方题库原文，没有创建任何学生样本记录。

## 3. 文件与接口

- `platform/app/learning/synthetic_assets.py`：课程生成 Schema、JSON/CSV parser、固定种子生成、质量报告、课程来源替换端口。
- `platform/seeds/synthetic/方程合成课程配置-20261006.json` / `.csv`：等价2KC生成配置，默认seed20261006，2题/单元，36题。
- `platform/seeds/synthetic/四知识点合成课程配置-20261006.json`：4KC完整配置，144题。
- `platform/seeds/synthetic/learning_assets_overlay_v1.json`：可直接合并到已有base的课程资产，不覆盖base ID/version。
- `platform/tests/test_synthetic_assets.py`：25项确定性质量和替换边界测试。

API：

```python
spec = load_generation_spec(json_or_csv_path, seed=20261006)
bundle = generate_assets(spec)
quality = quality_report(bundle)
overlay_json = catalog_overlay(bundle, base_catalog)
loaded = CurriculumAssetProvider(path, source_kind="synthetic_ai_generated").load()
catalog = loaded.catalog
```

CSV列严格为 `kc_id,title,family,prerequisites`，prerequisites内以分号分隔。JSON可配置seed、固定生成时间、每难度/题型数量、难度列表与题型列表。CSV使用默认配置与命令指定seed。拒绝未知列、空/重复KC、缺少先修、循环先修、题目版本重复、缺失提示、伪装真实来源、伪装已校准以及与学习者相关的额外字段。

JSON manifest 序列化哈希决定 `catalog_version` 与所有生成资产 version。改变种子、数量或课程配置必然创建新版本，不复用原ID/version。CLI仅打印质量或bundle，不接数据库、不联网：

```powershell
.\.venv\Scripts\python.exe -m app.learning.synthetic_assets seeds/synthetic/方程合成课程配置-20261006.json
.\.venv\Scripts\python.exe -m app.learning.synthetic_assets seeds/synthetic/四知识点合成课程配置-20261006.json --bundle
```

## 4. 质量与语义限制

支持 BALANCE（等式性质）、SOLVE（求解）、SETUP（识别与情境一致的列式编号）、APPLY（情境数量求解）。SETUP是明确的三选一列式识别，不把数字判对冒充完整开放式建模能力；生成的 L3 也声明这一限制。所有等级与Bloom是模板标签，未经实测标定。

每题含L0轻推、L1定向、L2部分步骤、L3完整解析；answer_exposed与提示形式绑定，生成数据本身不得绕过 Governor 提前交付 L3。跨课程题面唯一；答案、系数、常数、等式右端和显示题面逐项验证。缺提示、题面更改、错误答案/推导会返回明确错误，不静默接受。

质量报告不输出学生能力结论，明确保留 not_calibrated / not_learning_evidence / no_educational_effect_claim / hint_semantics_require_human_review。提示语、情境真实性、Bloom分类、难度与教育效应仍需教师和真实数据审核。

## 5. 替换真实课程资产

真实课程应提供现有 `AssetCatalog` JSON：版本化 KC、rubric、assessment、来源和许可证记录。替换时使用 `CurriculumAssetProvider(path, source_kind="curated_course_assets")` 或主代理统一的 `load_catalog(settings)` 配置入口。课程来源与真实学习Evidence始终不同：即使题目来自真实教材，也不自动成为任何学生的学习表现。

默认生成 overlay 只增加 SETUP/APPLY 知识点；BALANCE/SOLVE已有知识点复用base准确version，新评测版本保留合成来源。先修链按合并后的catalog验证。替换版本不得覆盖已有历史引用；状态重新解释、题型/rubric迁移与人工审查另走现有版本化流程。

原question_bank的EQ001..012映射由课程资产代理独立处理，明确 original_local_question_bank / legacy_version_mapping；原素材没有被错误标成这次AI生成的新题。

## 7. OCR、持久检索和策略/可教角色增量

14:20 后增加：

- `LocalRetrieval` 可接同一个 SQLite 连接和 `RLock`，持久化 `knowledge_sources` / `knowledge_chunks`，重启后按 source SHA 恢复；导入使用 `BEGIN IMMEDIATE`，源变化、大小上限（默认 20 MB）、页数上限（默认 50）和越过固定根目录均拒绝。支持 `bm25`、`vector`、`hybrid` 三种显式模式；vector 是哈希词法特征，不是神经语义向量，混合模式版本 `bm25-hashed-ngram-rrf-v1`。
- 扫描 PDF 只有在显式传入 OCR adapter 时才调用；没有文本且没有 OCR 返回 `ocr_required`，OCR 返回空文本返回 `ocr_no_text`。新增 `LocalOCR` 使用 RapidOCR CPU 与包内 ONNX 模型，所有识别本地完成，不上传资料。实际仓库 DeepTutor 扫描 PDF 第 1 页本地识别 575 字；中文扫描 fixture 能得到“方程”并保留 page=1 引用。OCR 仍是候选文本，不等于教师校对。
- `StrategyCard` / `StrategyRegistry` 新增等式保持、方程建模两张可版本化策略卡，`calibrated=false`，只提供步骤、检查点和提示映射。升级/回滚需要人工注册流程，不自动部署。
- `TeachVirtualStudentRunner` 新增零信任教虚拟学生报告：只接受已授权 artifact/evidence refs，输出一个可检验误区和追问；`trust_weight=0`、`candidate_only=true`，问题动作过同一 Governor，预算/截止失败不交付，绝不写 LearningEvidence 或 Learner Model。
- 外部 API 增加 `GET /api/strategies?kc_id=` 与 `POST /api/teach-student/lesson`。教虚拟学生使用已有证据 artifact 引用，角色报告和动作包含 provider/request/evidence/provenance；来源和模型不可用状态仍显式记录。策略和角色权限受到同一 learner-day 30 turns / 32000 token / 3 个主动提示 ledger 限制；圆桌仍保持三份候选报告、逐动作 Governor、零状态写入。
