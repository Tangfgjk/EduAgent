## 本次交付

- 新增 `platform/app/simulation/lab.py`：独立 loopback 仿真实验室应用工厂 `create_lab_app(output_root)`，默认命令端口 `127.0.0.1:8001`。
- 新增 `platform/web/simulation.html`：独立深色实验室页面，不修改学习工作台；支持画像/场景/seed/回合预算、后台作业、停止、检查点恢复、状态、报告和结构化轨迹。
- 新增 `platform/app/simulation/renderer.py`：可选表达端口。默认使用离线模板；Provider 必须显式注入且受调用预算、可见字段、动作/答案/援助字段和审核短语约束。表达器不能改变作答、答案暴露或提示级别，异常回退模板。
- 运行核心升级为按 KC 独立的合成掌握/保持/误区状态，并支持 `ASK_HINT`、`ASK_EXPLANATION`、`SELF_CHECK`、`REFLECT`、`ANSWER`、`QUIT` 六类结构化行为。概念纠正只在受信知识点接地教学动作中发生，泛化鼓励不改变误区。
- 新增冻结课程包 `platform/app/simulation/course.py`：仿真运行目录同时保存课程包、目录、题库及其 hash；Runtime 使用同一份冻结练习题，避免题干、KC、提示文本漂移。新增 assessment issuance ticket 适配，保证前测/后测/迁移/延迟题的唯一派发与重复回执。
- 新增 `platform/app/simulation/experiments.py`：多画像、多策略配对对照，固定课程/画像/seed，报告缺失/失败样本；提供分离 seed + item hash 的探索性预校准，不自动改参数。
- 新增 `platform/tests/test_simulation_lab.py`、`platform/tests/test_simulation_renderer.py`，Fake Runner/Provider 不冒称远程服务。

## 控制与隔离

- HTTP 只接受 localhost/127.0.0.1/::1 Host 和 loopback client；带外 Origin、cross-site 请求、嵌入和缺失一次性 lab token 均拒绝。
- 请求模型拒绝任意数据库 DSN、文件目录、URL、API key、未知画像/场景和超预算；服务端 `output_root` 是受信启动配置，不从请求读取。
- 同时只运行一个作业，历史最多保留 20 条；结果路径只接受 Runner 返回的安全 run id，并解析在受信根目录内。
- 每次作业只返回公开状态；异常只记录类型，不回显路径、凭据或异常文本。报告和轨迹在作业完成后才可读取。
- 报告的 `failed`、`unsupported`、`timed_out`、`stopped` 不会显示为 `completed`；停止使用协作事件，恢复仅针对已经存在且由本服务产生的停止/超时作业。
- 报告持续标记 `synthetic_ai_generated`、`educational_effect_claim=false`、`automatic_promotion_enabled=false`。

### 真实结构化 Runner 集成

执行：

```text
python -m app.simulation.runner --suite --turns 10 --seed 1
```

旧版六画像 × 五场景共 30 个独立 run 全部 `status=completed`、每项 `errors=[]`；升级后的 Runner 在本地临时目录和全量 730 测试中通过。报告及临时运行目录均位于被忽略的 `platform/data/simulation/`，没有写入 8000 真人服务的数据。

### 实验套件冒烟

执行两 seed、一个画像、五场景（10 runs，`max_turns=3`）：`completed=10`、`failed=0`、`unsupported=0`、`timed_out=0`；配对 baseline/fading 为 2 组；分离 seed + item hash 预校准训练/留出各 1 条。该结果只是结构和流程冒烟，不是参数校准或教育效果结论。

### 浏览器检查

实验室服务使用后台 Uvicorn 绑定 `127.0.0.1:8001`。本子任务运行环境无法创建可见 IAB 标签（平台返回 `visibility not supported in a subagent thread`），因此未在本子任务中生成截图；桌面/移动截图、DOM 横向溢出和像素检查须在主任务浏览器线程完成。API/HTML 已提供响应式断点（700px）、`overflow-wrap` 和表格滚动容器。
