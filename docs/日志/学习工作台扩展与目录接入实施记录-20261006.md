## 目录接入与精确版本

`platform/app/learning/assets.py` 增加统一 `load_catalog(settings)`，评测、扩展路由、会话与路径推荐使用同一个目录加载入口。`RSI_LEARNING_CATALOG_PATH` 可指定 curated AssetCatalog JSON、合成清单/数据包 JSON 或生成 CSV。相对路径在 `platform/` 下解析；`RSI_LEARNING_CATALOG_OVERLAYS` 使用 JSON 非空字符串数组配置增量覆盖层。自定义目录不会静默叠加本地默认演示内容，导入冲突或失效版本引用直接拒绝。

默认目录由原 12 项基础评测、144 项合成补充、12 项原题库映射、2 项教师评审作品任务组成，共 170 项，覆盖 BALANCE、SOLVE、SETUP、APPLY 四个 KC。教师作品使用独立 `seeds/qualitative_assets_v1.json`，不修改基础 12 项历史版本。覆盖层合并后统一校验 KC/rubric 依赖、版本重复、权重与先修 DAG；`EQ001–012` 明确记录原本地题库来源，不冒充 AI 合成或校准课程资产。

普通评测新增证据的 `verifier_details` 保存目录中的 `assessment_provenance`、`calibration_status`、`comparison_group`，旧证据不回填、不改写。公开目录返回 rubric 配置，但始终不返回评测参考答案。explanation/recall 不能通过数字验证入口伪装验证，未配置的 adapter 明确返回客户端错误。

## 计划、会话与修正恢复

新增 `GET /api/learning/plans/{learner}/workspace`，只在教学授权有效时恢复最新目标、当前有效计划和基于当前 baseline 的兼容草案/提案。工作台以选择器与人类可读 Diff 展示已保存版本。`POST /api/learning/plans/{learner}/{version}/accept` 采纳指定已有提案为草案，不重复生成内容，不自动签署。

`GET /api/sessions/{sid}` 接入 Session ID 手填恢复入口。新会话在输入框显示真实 ID，恢复后展示公共会话状态中的当前题目与轮次，继续使用原会话身份；不会虚构历史聊天记录，不把会话 ID 或内容写入 localStorage/sessionStorage。

教师修正产生的恢复任务由后端 Evidence 事务原子写入。浏览器改用 `GET /api/learning/recovery/{learner}` 查看 pending/failed 队列，不再额外创建任务身份。启动并取得教学授权后恢复待处理队列；运行选中任务、失败重试和 `POST .../reconcile` 检查旧历史均需明确点击。结果展示修正前后状态版本与来源、新提案引用；不会自动采纳或签署新提案。教师复核/定性评审保留稳定请求身份，字段变更才生成新请求，供响应丢失时重试。

## 新增工作台入口

保持原深色主题、紧凑三列布局和响应式边界；沿用标签页模式，新增“知识与协作”，共六个标签页。每个 tab/panel 有对应 ARIA 引用，单一 roving tabindex，支持左右方向键与 Home/End。手机标签保持单行横向滚动，不把最长名称挤成多行。

1. 记忆：调用真实 rebuild API，显示 L1 事实来源、L2 会话引用、L3 状态/行为来源和 view ID。
2. 发展指标：由学习者选择前后窗口分界；展示认知样本状态/分布、自主性行为分解与证据/交互来源，不宣告因果效果或排名。
3. 申诉：提交真实 evidence ID、理由、稳定 appeal ID，显示提交回执，等待人工复核。
4. 项目：支持新建/编辑、任务新增/移除/状态修改、证据/会话/知识来源引用、CAS revision 保存、归档/恢复；创建时保留稳定 record ID 防止网络重试生成重复项目。
5. 家校：学习者明确选择不共享/教师/家长/双方，以当前 revision 保存。查询教师或家长看板另需对应一次性凭据；家长仅聚合状态、项目标题与计数，教师显示允许的证据引用、申诉/项目摘要，不展示答案正文。
6. 定性：选择 explanation 任务后提交原作品到 artifacts 端点，先生成 unverifiable 待教师评审证据，不计掌握。教师凭据才可读取作品，并选择匹配版本 rubric 的 reasoning/self_check 等维度评分，评审以追加证据完成。维度来自服务端 rubric 配置，未用模型输出冒充 Bloom 评估。
7. 知识：BM25、词特征向量/混合检索，显示真实 chunk、来源版本、引用位置和原文链接。受限导入仅提供固定知识根目录内的相对文件、来源编号、当前 KC 和 OCR 开关，服务端继续做路径/版本/来源验证。
8. 协作：刷新当前有效证据与实际 provider 列表；单角色、三角色圆桌、策略卡、教虚拟学生均接真实端点。输出显式标记待验证候选和离线固定模板/配置模型模式，显示来源/裁决，不直接写学习状态或签署计划；未调用外部模型时不宣称外部模型 smoke 通过。
9. 本地登录：401 统一跳 `/login`，启用认证时显示退出，退出调用 `/api/auth/logout`；本轮未在页面保存任何密码或 token。

## 撤回与凭据处理

撤回成功清空答题、会话、计划、项目草稿/引用、作品正文、教师/家长凭据、申诉、恢复、指标、记忆、知识查询与候选结果。AbortController 取消在途请求，privacy epoch 阻止撤回前的迟到响应写回屏幕。重复授权只恢复经服务端授权的真实工作区数据，不绕过 audience sharing 的当前 consent 版本检查。

所有教师/家长 token 使用 password 输入，通过请求 header 传递；无论请求成功或失败都清空；未嵌入 HTML、未写浏览器存储。登录密码和服务端环境配置由环境/认证实施记录维护，本文件不复制凭据。
