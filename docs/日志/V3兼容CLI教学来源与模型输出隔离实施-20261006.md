# V3兼容CLI教学来源与模型输出隔离实施

建立/验证时间：2026-10-06 20:26（Asia/Shanghai，UTC+08:00）。本地 `V3`，V2基线 `c975def`。本轮修复旧 `python -m app.cli` 的独立 LearningAgent 执行路径，不以“仅正常网页安全”排除兼容入口。

## 实施内容

- `app/agent/tools.py` 复用 `governance/runtime_sources.py` 与 ActionGovernor；任务必须匹配冻结题库与 catalog，提示必须匹配对应阶梯。已知KC不能让任意模型正文、改题干或模型生成题变为可信内容。
- `explain_gated` 全答案仍经过R-01/R-09，且文本必须是该冻结任务的规范答案；提前请求继续回退可信阶梯提示，回退再次被拒则返回denied，不消耗提示、不显示答案、不继续执行该被拒动作。
- `quiz_generate` 保留接口与模型候选功能，但候选只留在独立有上限的RAM列表，不追加可信bank、不能被task_issue使用。正常学生流程回落到可信题库；无可信题则暂停出题。候选缓存不是持久审核库，真实准入仍走独立课程审核包。
- 移除自由message润色及计划Markdown润色：`_polish_plain`保留兼容名字，但返回服务器原文，不调用模型。计划由默认结构、已受限UnitIntent计数和学习者明确修订组成；模型不能通过“温暖润色”加入答案、改目标或替学生确认。
- UnitIntent和ToolChoice仍可由模型提供经schema验证且有边界的候选；notes不进入学生输出。最终计划与提示正文不直接采用自由模型字符串。
- 弃用不再使用的 `polish` 标志与 `PlanDraft`。默认CLI题库仍为原始本地bank；定制教学课程通过正常Runtime显式bank_factory/catalog配置，不冒称旧CLI已迁移全部课程准入。
- GovernanceService与LearningService保护CLI延续和镜子读取；撤回/隔离之后不可继续学习或读取镜子，新建旧Agent也拒绝读取保留快照。无Consent的全新旧计划草案兼容保留，不据此授权Evidence写入。
- 补充正常Runtime和CLI的数学验证安全边界：冻结数学题不能在解析失败时自由调用LLM rubric、采纳其自报高置信度及feedback。无法确定数学作答就unverifiable；这不改独立定性作品评分API或真实教师审核端口。
