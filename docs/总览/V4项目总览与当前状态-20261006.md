# 桂子问津 Wenjin V4 项目总览与当前状态

更新时间：2026-10-06；当前分支：`V4`；代码基线：V3 `ced270c1ecf721a386abada8d8695ed5906c8c65`。

## 项目是什么

桂子问津以自我调节学习为核心，围绕“作答 → 验证 → 学习证据 → 掌握/保持 → 路径推荐 → 教学动作 → 新证据”建立可追溯闭环。最终教学权属于规则、证据和治理层，模型只能提出受约束的候选。

## 当前可以使用

V3 代码支持本地深色学习工作台、合成学习者仿真、策略离线比较、课程结构检查、学习证据与掌握/保持流程、学校隔离 MVP、学习域 SQLite/PostgreSQL Repository 切片、本地备份恢复和远端 CI。

## 当前不能宣称

不能宣称真实教育效果、真实课程已由教师审核、真实参数已校准、完整平台已迁移 PostgreSQL、学校生产多租户已完成、SSO/常驻生产 worker/TLS/灾备已完成，或合成数据等于真人数据。

## V4 的作用

V4 是最终研究 MVP 收口规划：统一新人入口、职责边界、产品体验和生产/Pilot 前置条件。当前提交只有文档；运行命令和实际功能以 V3 操作手册及代码为准。
