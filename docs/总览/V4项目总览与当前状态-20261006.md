# 桂子问津 Wenjin V4 项目总览与当前状态

更新时间：2026-10-06（Asia/Shanghai）；当前分支：`V4`；起始代码基线：V3 `ced270c1ecf721a386abada8d8695ed5906c8c65`。用户授权的本地 P0 代码与文档收口已完成；锁同步后冻结全量及隔离浏览器验收通过，发布与远端CI待实际执行。

## 项目是什么

桂子问津以自我调节学习为核心，围绕“作答 → 验证 → 学习证据 → 掌握/保持 → 路径推荐 → 教学动作 → 新证据”建立可追溯闭环。最终教学权属于规则、证据和治理层，模型只能提出受约束的候选。

## 当前可以使用

V3 代码支持本地深色学习工作台、合成学习者仿真、策略离线比较、课程结构检查、学习证据与掌握/保持流程、学校隔离 MVP、学习域 SQLite/PostgreSQL Repository 切片、本地备份恢复和远端 CI。

## V4 的作用

V4 是最终研究 MVP 的本地开发收口：恢复原深色学习体验，拆分学生/教师/家长/本地研究入口，增加实际数据驱动的学生成长图和仿真四图，补齐工程质量门、时间/迁移/配置契约及逐功能说明。本地 P0 已完成；锁同步后冻结全量824 passed、2 warnings、无skip，71.14秒。隔离8132工作台20个流程、1440/390视口通过，无pageerror或横向溢出；基础9项专项与96.30%局部覆盖通过。历史72工程/85仿真/20工作台专项不相加冒充全量，见[最终验收与发布记录](../测试/V4最终集成验收与发布记录-20261006.md)。
