## 0. 全局设计原则（UI 层的教育学，原则 P1/P4/P6 的呈现面）

1. **脚手架可见且渐撤显性**：提示阶梯、"自主性仪表"是学生可看见、可讨论的对象，不是隐藏的内部变量。
2. **无暗模式**：不做连胜焦虑、红点催促、排行榜攀比。进度只对自己的历史比较，不用他人比较。
3. **归因措辞规范直达文案**：界面文案禁用能力归因（R-04 的 UI 面），如"你很聪明"→"这个策略用得好"。
4. **镜子优先于评价**：凡是给学生看的状态，都呈现为"假设与证据"（如误区是假设分布），不是审判性标签。
5. **每个界面都有"人"的出口**：学生可召唤真人教师；教师可否决智能体；家长可见但不可窥视（P6）。

**界面 ↔ 教育原则映射**

| 界面机制 | 教育原则 |
|---|---|
| 提示阶梯进度条 | ZPD + 脚手架渐撤（03 §4.1） |
| 自主性仪表 + 干预预算可见 | P4 / R-07 |
| 目标工坊"学生签署"按钮 | R-02 目标归学生所有 |
| 反思关卡不可跳过 | 元认知训练 |
| 误区假设云（含概率） | ToM 贝叶斯假设 + 开放学习者模型 |
| 教师否决/纠正一键入口 | 金标通道（04 §8）/ 同步进化 |

## 0.5 高保真基座（v0.2 融合学生方案）

自 v0.2 起，产品基座采用学生方案《未来学习平台》的 **14 屏高保真稿**
（Codex 式三栏工作区：项目栏 / 模块画布 / AI 对话，八模块可配置；高保真图源见
`~/Downloads/未来学习平台_系统建模与UI流程设计(1)/images/`）。本稿原线框**降级为
"教育承载件规格"**——线框中的机制性元素是教育学原则的承载件，注入高保真屏时
**不得删减，只可美化**。逐屏注入映射：

|---|---|

| UI-07 开放任务 | 阶梯式分层帮助（nudge→hint→范例→讲解）、artifact 验证状态（Verdict 徽章） |
| UI-08 课程与资源（v0.3） | **活书编译**（嵌测验/闪卡/交互模块、每页可对话，源自 DeepTutor）、可插拔检索与**页码级引用**、AI 生成资源的送审状态（REVIEW_RECORD：大纲先审后生成） |

```text
├───────────────────────────────────────────┬──────────────────┤
│  小伴                                     │  作品区(画布/代码) │
│  ┌─────────────────────────────────────┐  │  ┌──────────────┐│
│  │ 好问题: 打八折再减10元, 和先减10元再  │  │  │ 我的解答 v3   ││
│  │ 打八折, 什么时候不一样? 先猜猜看      │  │  │ 80x-10 = 0.8(x-10)│
│  └─────────────────────────────────────┘  │  └──────────────┘│
│  我: 一样的吧...                          │  [运行][验算][版本▾]│

│  我: 咦, 不一样...                        │  环境: Python沙箱 │
│  小伴: 【提示升级 L2】先算两种顺序的差      │  状态: 运行通过 ✓ │
│  我: 我觉得跟"减10"在折扣前还是后有关       │                  │
│  小伴: 这个方向有意思——你能用符号把它写出来吗?                 │
│                                           │                  │
│ ┌───────────────────────────────────────┐ │                  │
│ │ 输入...        [_voice] [拍照] [召唤老师]│ │                  │
│ └───────────────────────────────────────┘ │                  │
├───────────────────────────────────────────┴──────────────────┤
│ 本会话小伴主动提示: 2次/预算5次 · 你先尝试了3次才求助 👍        │
└──────────────────────────────────────────────────────────────┘
```

交互要点：
- 提示阶梯常驻顶部，**升级对学生透明**（"为什么提示变了"可点开看规则解释）；
- `EXPLAIN(worked_full)` 被规则拒绝时，学生看到的是"你先把想法写出来，我们对照"而非无声降级；
- "召唤老师"任何时刻可用（P6：每个界面都有人的出口）；
- 底部"干预预算条"呈现 R-07——智能体不是无限提示的，学生自主尝试被点名表扬。

## 3. 学生端 · 我的镜子（开放学习者模型）

```text
┌──────────────────────────────────────────────────────────────┐
│  我的镜子                          [学生视角] (教师看到的是另一副)│
├──────────────────────────────────────────────────────────────┤
│  掌握图谱(方程应用题)          置信区间=小伴的把握程度           │
│  ▓▓▓▓▓▓▓░░░ 0.68 ±0.06  移项           ↑两周 +0.21           │
│  ▓▓▓▓░░░░░░ 0.41 ±0.09  设未知数                              │
│  ▓▓▓▓▓▓░░░░ 0.55 ±0.07  去括号                                │
│                                                              │
│  小伴对你的一些"猜测"(是猜测, 不是判决):                        │
│  ┌────────────────────────────────────────────────┐          │
│  │ 猜测A: 折扣先减后打时符号容易错  可能性 62%        │          │
│  │ 猜测B: 找不准等量关系          可能性 31%         │          │
│  │ [下一题想帮我确认哪个猜测?]                       │          │
│  └────────────────────────────────────────────────┘          │
│                                                              │
│  我的策略档案: "先代特殊值试探" 对你很有效 (3次验证)              │
│  元认知校准: 你预计做对75% / 实际做对58% → 还有差距, 在缩小        │
│                                                              │
│  自主性仪表  ▓▓▓▓▓▓▓░░░ 0.72 ↑                                │
│   目标自己定: 89% · 求助前先尝试: 78% · 主动自查: 55%            │
│   (自主性越高, 小伴的主动提示预算越少——这是设计, 不是惩罚)        │
└──────────────────────────────────────────────────────────────┘
```

交互要点：一切估计都显示"可能性/区间"，学生可对任何猜测点"不是这样"
（该反馈直接成为状态修正的金标信号）；镜子数据可导出带走（可携带权）。

## 9. 落地说明

- 本稿为**线框级**，进入前端开发前应产出高保真稿（Figma）与组件库；
  但线框中的结构性元素（阶梯条、预算条、镜子假设云、否决入口、同意开关）
  是教育学机制的承载件，**高保真化时不得删减，只可美化**。
- 无障碍与未成年人保护：字号、对比度、防沉迷休息提醒、家长模式切换为必选项。
- **IM 多渠道触达**（v0.3，源自 DeepTutor Partners）：学伴轻量提醒与碎片提问可走
  钉钉/飞书/企微等渠道；正式学习会话仍在工作区内（治理边界不出平台，渠道只做触达）。
- 前端接口面（`platform/gateway/`）按本稿逐屏定义 OpenAPI，与 05 §5 组件图对齐。
