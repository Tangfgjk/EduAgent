记录时间：2026-10-06 22:23（Asia/Shanghai）。分支：V4。范围：Simulation Lab，不涉及个人 8000 学习服务或真实学习者数据。状态：本地实现、专项测试和桌面/移动端浏览器验收通过；不是完整项目发布结论。

## 本次实现

原有实验配置、单任务预算、停止、检查点恢复、持久化作业列表和报告下载保持；将报告 JSON 主导的页面变成深色卡片式证据分析工作台。数据完全来自当前 `SimulationRunner` 的 report / transcript，不复制原型里的数值、预绘改善趋势、示例结论。

页面与分析逻辑分离：`platform/web/simulation.html` 为语义结构，`simulation-assets/lab.css` 为主题/响应式，`simulation-assets/lab.js` 为交互与 SVG 渲染，`simulation-assets/analytics.js` 为无 DOM 的纯数据投影。后者既供浏览器使用也可在 Node 中作契约测试。没有引入图表库、构建步骤或新依赖。后续新增报告字段或图表可扩展独立分析模块，不改变学习域契约。

## 四个视图及口径

| 视图 | 数据来源与定义 | 不可推断内容 |
|---|---|---|
| 掌握度轨迹 | 同一 KC 的 `estimated_mastery_after` 与 `latent_mastery_after`，横轴为实际回合；可切换 KC。 | 不混接不同 KC 的点；潜在状态不是学生真值；缺失值不画成零。 |
| 独立表现 | 和 evaluator `first_independent` 一致：某题第一次出现时必须为 ANSWER、有布尔 verdict、无 hint、未暴露答案；显示累计通过率和 n。 | 请求提示后再答、重试均不是新的独立样本；无样本不等于不会。 |
| 支架依赖观察 | 每个有效 ANSWER 累计 `(hint_level > 0 或 answer_exposed) / 有效作答数`；同时列报告 `hint_dependency` 终值。 | 观察到的辅助占比不等于模拟器潜在依赖参数；报告只有终值，不能虚构潜在依赖时间序列。 |
| per-KC 终态比较 | 各 KC 最后有效估计与 report `per_kc[kc].mastery`，显示绿色/紫色两条及可展开数值表。 | 不是跨学习者排名、真实掌握认证或真实模型校准。 |

没有报告或有效样本时显示明确空状态。图表通过 SVG title、aria-label 和可展开数值表解释采样点；零值保留、缺失值用 `—`。若 API 标记 transcript 截断，页面显著注明累计指标只代表可见窗口，不能冒充完整报告。

运行间比较为两个实际 report 的描述性摘要（场景、回合、独立 n、独立通过率、辅助作答数、依赖终值）。检查 profile/seed/budget/course/engine/simulator/profile version 及运行完成状态；不匹配/字段缺失时警告非配对比较。即使一致也不报告显著性、因果或教育效果；保留 synthetic 标签、教育效果 claim=false、自动晋级关闭。

## 使用方法

在 `platform` 目录运行：

```powershell
uv run python -m app.simulation.lab --port 8001
```

打开 `http://127.0.0.1:8001/`，选择画像、场景、seed 和回合预算，点击开始。完成/停止后点击作业“查看”，四图按实际数据出现；切换知识点看各 KC 轨迹；选择参考运行阅读比较。需要复核时展开完整报告和逐回合轨迹；“下载报告”输出 JSON。停止是协作式停止，主动退出的终态不可恢复；恢复必须通过旧有 checkpoint 和版本验证。CLI 场景 suite 与正式参数晋级流程不变。

## 安全与工程保持

`/simulation-assets` 仅挂载独立静态资产目录，不挂载 output-root，也不暴露学习数据库。原有 loopback Host/peer、same-origin、随机 `x-lab-token`、4096 字节请求上限、单运行 worker、100 回合上限、路径约束、停止/恢复语义保留。页面取消 inline script/style，CSP 收紧到 `script-src 'self'; style-src 'self'`，追加 object/base 限制；所有来自 report 的内容由 textContent/SVG text 节点插入，不拼接 HTML。

浏览器脚本可使用 Playwright 默认 Chromium（自动发现），或设置 `EDU_BROWSER_CHANNEL` / `EDU_CHROME_PATH`；Node 模块从常规安装或 `EDU_PLAYWRIGHT_MODULE` 获取。`EDU_QA_URL` 必须为 127.0.0.1，仅针对隔离测试实例。
