# 我教 AI：三轮讲解与独立验证

适用：V09-20261017 的第二步首项增补，2026-10-17。仅限模拟/成人开发账号与自编概率内容，不代表开放真实学生数据。

## 使用路径

1. 管理员保持模型配置开放，并在「知识点与题库」核对、启用概率陪学基础包及「概率我教 AI · 讲解与新题验证」互动包。没有模型配置时仍可使用预设互动。
2. 学生进入项目或临时空间，打开「我教 AI」，选择上述概率互动包并开始。项目和临时空间的记录继续隔离。
3. 填写「我的数值表达」「我的讲解」，勾选「让 AI 根据本次讲解提出一个问题」，点击「保存表达，邀请学伴」。取消勾选则走预设流程，不发模型请求。
4. 阅读学伴问题，填写「我的比较、纠错与检查依据」及新的候选数值。可选：
   - **保存回应，继续追问**：把本次回应交给模型提出下一个问题。
   - **保存修正，进入新题验证**：结束追问，程序核验修正数值并进入另一题。
5. 每次活动最多请求 3 次模型追问（包含首次；取消和失败也计入）。达到上限后不再显示继续追问按钮。刷新不会重置次数；重复提交同一请求不会新增调用。
6. 另一题验证阶段不显示模型问题或此前追问历史，不开放追问按钮。独立填写数值与检查依据，提交后查看 TeachReport。报告保留全部学生贡献、每次模型状态和有效问题；旧问题可展开查看。

## 等待、取消与失败

- 正在生成时可取消本次追问；也可直接保存修正进入验证，迟到回复会被拦截。
- 请求未完成时不能发下一次追问，避免同时生成多个回复。
- 校验拒绝、超时或取消不自动重试，可以展开预设问题继续思考，或在仍有轮次时提交新的回应请求追问。这属于新的明确请求，会另计一次。
- 管理员停用模型、撤回内容或归档空间后，遵循既有门禁；学生仍可查看已保存历史。

## 模型读取范围

首次发送当前题目、当前候选数值及讲解。第二、三次另带本活动最近至多两轮成功的讲解与追问。只取相同账号、空间、活动、题目、内容版本、当前模型配置及停用代次的有效记录；失败、取消、篡改和其他项目记录不作为模型上下文。

当前学生讲解和历史内容均作不可信数据处理；身份字段脱敏，仍请不要填写个人信息。不向模型发送独立验证题、参考答案、姓名、账号或跨项目记录。

模型追问可以被质疑；数值由程序另行核验，讲解质量、掌握度、迁移与教学效果不由模型自动判定。

## 查看本轮开发评测

管理员进入「评测工作台」，选择「我教 AI 多轮 · DeepSeek 完整流程」。两组固定自编讲解各 3 次请求，6 次均返回可用问题，自动方向匹配 6/6；全部仍待逐条语义复核。首次专项 T04/T05 的旧失败仍保留，并未因此关闭。

开发脚本：

```powershell
# 只检查范围，不发调用
.venv/Scripts/python.exe scripts/evaluate_teach_multiturn.py --check-only
# Fake 工程流程
.venv/Scripts/python.exe scripts/evaluate_teach_multiturn.py
# 真实自编文本：最多 6 次，每次最多 512 tokens，无自动重试
.venv/Scripts/python.exe scripts/evaluate_teach_multiturn.py --live
# 中断后仅对同一代码、语料和配置恢复；已终结请求不会重发
.venv/Scripts/python.exe scripts/evaluate_teach_multiturn.py --live --resume .local/evaluation/实际运行目录
```

脚本只使用独立评测数据库。阅读冻结网页报告不会新增模型调用。
