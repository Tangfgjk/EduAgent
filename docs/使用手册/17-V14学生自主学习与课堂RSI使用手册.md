# V14 使用手册：学生自主学习、互动课堂与 Skill 改进

更新：2026-10-20。API 0.20.0 / 数据库 r14_003。学生端 `http://127.0.0.1:4003/student/`，管理端 `http://127.0.0.1:4003/admin/`。这是模拟/成人开发环境，尚不能对真实学生宣称教学有效。

## 1. 先弄清三个入口

- **主题与课程**：准备“学什么”，生成目标内的课程、题目与活动，确认后绑定当前空间。空间名称只是名字，改名不会改变课程。
- **学习计划**：确认本次目标和时间节奏；正式项目开始陪学前先确认，临时探索可直接学习。
- **规划与策略**：根据过程与体验调整“怎么学”，例如反思重点、已有练习的顺序、支持方式。不会偷偷改数学答案或正在进行的独立测验。

学生主导航是“学习工作台、学习空间、复习、成长、我的”。陪学、圆桌、我教 AI、课程、计划和策略仍能从工作台进入；旧深链接继续可用。

## 2. 管理员首次准备一次

1. 登录管理端，在“学生账号”创建开发账号，初始密码至少6字符。不要把真实学生资料当作模拟资料。
2. “配置与权限 → 模型与运行配置”选择本机已配置密钥的 DeepSeek 与已验证模式，确认开发用途后发布。每日次数0表示不限次数，调用/token仍记账；不是免费。
3. “课程生成与资源 → 生成用途与知识资料设置”开放课程生成、通用互动与需要的私有课程自动开放。核对用途、来源和预算后发布；默认关闭的开关不会因代码升级自行开启。
4. 对旧静态开发内容，首次仍须核对并启用；新生成的覆盖内私有开发课程可经程序核验和两次机器检查后开放。机器检查不代表教师认可；不确定内容仍进入异常复核。
5. 本轮**不要授权外部媒体预算**：用户尚未批准费用；旧OpenMAIC文本预算也保持关闭。已有课堂可继续阅读。关闭预算不影响普通题目学习。

管理员维护公共配置/资料和异常，并非学生每次使用的必经关口。后台“运行能力与试点门槛”显示实际题族、Provider与队列，不是全课标完成率。

## 3. 从新空间完成一轮学习

1. 学生进入“学习空间”，新建正式项目，例如“有理数练习”；要一次性探索可选临时会话。
2. 保存后进入工作台，按“下一步”进入课程准备。输入具体初中数学主题，例如“负数乘除和混合运算顺序”；宽泛的“有理数”需要明确本轮重点，范围外主题会说明限制。
3. 根据页面做诊断，不会可如实表达。含混时可能追加探测，最多4题；也可保留未知结束诊断，不会把未知写成答错。
4. 查看范围并确认生成。等待状态会保存，刷新可恢复，不要重复点击重建。未通过质量检查时查看原因；不要为快而绕过复核。
5. 课程开放后点“确认使用这份课程”。陪学、圆桌和我教 AI 使用该空间当前单元。正式项目按工作台提示确认学习计划。
6. 进入津津陪学。开始时独立尝试，随后练习与反思，最后无辅助检测。独立阶段不提供提示、模型或课堂资源。

## 4. 用聊天完成陪学

- 在“我的回答”输入 `这个答案是3`；系统保留原话，先识别明确最终数值，再用程序独立核验。
- `不是3`、`3或5`、带尚未支持单位的答案等会请求澄清。未知不等于错误。明确改口时以明确的新答案核验，已提交的独立检测结果不会被覆盖。
- 练习中点“给我一点提示”，支持内容出现在同一对话；后续还可请求更具体支持。遇到困难可以恢复支持，不以“少提示”直接评能力。
- 开放模型时点“回应 AI 的追问”继续解释；同题带入有限历史，不带其他项目或保留检测答案。AI理解出的候选数值需要你确认，再由程序判断。
- 练习提交后按提示写“我的反思”，点发送进入下一题；诊断或检测后点“继续下一步”，最后显示学习小结。
- 已保存消息和处理状态通过实时连接更新，刷新会恢复。这里展示已检查结果，不是未经检查的逐token流。失败不自动重新请求收费模型，可继续原有任务；任务详情里可以停止等待。

数值通过只说明支持的数值核验通过。`答案是3，因为1+1=3`可能出现“最终数值通过、等式理由矛盾”的分别记录；不会把最终值正确当成解释正确。几何证明、复杂自然语言推理仍需专业评阅。

## 5. 圆桌与我教 AI

在工作台或当前课程概览进入这两条路线，无须重新猜选空间主题。

- **圆桌**：先写自己的观点与依据，再比较提议、质疑和整理视角；修正后做另一题无辅助验证。模型意见不是正确答案票选，也不代表真的有多位教师。
- **我教 AI**：先讲方法并给出数学表达，AI根据表达选择或提出受限问题；回应后可继续追问或进入新题验证。数学结果单独核验。
- 主区聚焦当前任务；往期活动、小结细节与流程日志收在可展开区域，需要追溯时再打开。
- 同一空间有未结束的学习活动时先完成或结束，不能并发活动绕过检测隔离。当前单元缺少对应活动时明确提示，不偷偷换其他学科/单元。

## 6. 观看互动课堂

1. 当前课程概览、课程页或练习阶段找到“当前课程资源”。展开资源标题。
2. 有场景数据的资源进入互动播放器：看幻灯片布局、公式、图形，点击场景切换；“播放课堂/暂停/下一步”控制讲解与显隐步骤。
3. 有导入音视频时使用原生控制条调音量、暂停和拖动；字幕和“无障碍文字与全部讲解”提供文字替代。无可播放媒体时继续看文字，不会伪装有配音。
4. 场景问题填写答案后独立核验。问题结果、课堂进度和数学掌握是不同记录；可从课堂返回当前陪学。
5. 进度自动保存，也可点“保存进度”；刷新恢复场景、动作和已保存媒体位置。版本变更或检测开启时后台会拒绝旧版本/辅助资源请求。
6. “需要讲解课堂？查看生成与恢复”可复用本课已有课堂。只有另获授权的文本预算可预约新课堂；当前旧预算关闭，不能新增生成。通过范围检查与两次机器检查的私有课堂可自动开放，不确定内容留待复核。
7. “补充媒体与生成状态”是新外部图片、配音、视频能力。**当前未获费用授权**，按钮关闭是预期；本轮只完成代码和离线验收，不能据此宣称已生成新付费媒体。

旧纯文本导入材料仍按安全文本显示；上游原始脚本/任意网页不执行。上游不支持或无法安全转换的组件会列为不支持，不会原样嵌入后台站点。

## 7. 看成长，安排复习

“成长”里可切全局宏观与当前项目局部；临时会话不会混入正式项目全局。时间、来源、辅助条件筛选共同影响证据和图形。

- 日历看哪天留下记录；知识图看哪些内容有证据；独立/辅助趋势看支持条件和分母；复习矩阵看到期卡片及触发原因；支架轨迹看帮助变化。
- 六类雷达是**候选材料分布**，不是素养评分。点击方向、日期或节点查看原题、原话和课程版本；没有材料显示不足，不等于能力低。
- 在“复习”查看到期卡片，打开原始尝试后可补充自述；原话不会被覆盖。无提示复做会保存结果并安排回访，原题复做通过不自动代表迁移掌握。

## 8. 无需反复上传的规划与策略

进入当前正式项目的“规划与策略”，写学习体验，选择时间/反思重点，可展开四类执行参数。参考资料可不选；系统使用带版本的自编教学原则，页面会标明它不是教材/考纲或专业量规。

选择“使用已开放模型生成有来源的候选”后，模型只读授权范围的当前项目片段与摘要。普通受限个人候选通过系统检查后，直接由你确认或拒绝；确认才激活。可以查看 Skill.md/Harness、参数差异和依据，再从“激活历史与回滚”恢复默认或历史合法版本。历史需管理员审核的提案仍保留原流程，不会假造审核记录。

## 9. 体验 Skill 语义改进与自动个人试用

前提：正式项目、模拟/成人账号、已确认课程、激活了四类执行参数的合法基线、DeepSeek用途/额度开放、有当前版本学习事实，当前学习任务已结束。

1. 进入“Skill 改进与试用”，选择“模型理解学习记录”。仅本项目最多6条脱敏记录；每候选最多2次调用（含显式修复），单次2048输出tokens，无自动重试。
2. 若希望通过工程评测后个人试用，明确勾选同意；不勾选不会自动激活。
3. 查看证据引用、改进假设、单项DSL差异、实际消费者测试与保留影子场景。违规、无适当假设或评测失效会阻止试用。
4. 试用只影响本项目后续新任务。可“撤回个人试用，恢复原策略”；签名/来源/账号/项目/基线变化或到期会自动回滚，已开始任务保留其冻结策略。
5. “启用本项目自动语义改进”是持续预授权：新增6条事实且任务结束后触发，每项目每天最多1个候选。关闭时撤回活跃试用并取消排队的自动候选，晚回包不能重新激活。

**已实现模型语义候选与受限自动个人试用，不是任意改代码或自训练模型。工程评测通过不证明学习效果，不能自动推广为全局最优策略。**

## 10. 教学效果验证与个人数据

管理端“教学效果验证”可创建研究协议，事先列四套互不重叠的前测/后测/延迟/迁移题与量规锚点，冻结后采集符合来源和首次无提示条件的事实；延迟/迁移须满足时间条件。报告显示描述性计数和区间，当前结论始终“待验证”。没有专业审核/等值测验和真实学生时，不能把报告写成教学有效。

学生“我的”可导出本人资料及表达。删除申请需明确确认，会先停用账号并撤销会话；并非点击后所有备份/外部记录已消失。管理员查看申请，维护者在停服、备份和检查依赖后执行专用删除命令；默认仅预览。本轮未删除任何真实账号。正式保存期、备份销毁与外部记录处理需另行确定。

## 11. 故障与维护

- 页面要重新登录：确认访问同一主机名/端口，避免混用localhost与127.0.0.1；重置/停用账号会使旧会话失效。
- 长时间等待：先看已保存状态与任务详情，刷新状态，不重复生成；费用未知保守保留预约。
- 预算关闭：复用已有课程/课堂或继续已有练习；学生不能自行扩额。
- 服务启动：Docker中本项目PostgreSQL先就绪，运行迁移，再分别启动 `app.main`、`app.worker --lane teaching`、`app.worker --lane models`，均使用 `.local/database.env`；主端口4003。媒体worker只在另获授权后使用。
- 详细实现与验收范围见[113号记录](../进度/113-V14实现验收与后续关口.md)，下一阶段外部条件单列，不以演示页面替代验收。
