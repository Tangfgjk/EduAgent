# 执行策略与 Skill 版本操作

后续增补：G08已提供基于结构化信号的本机离线候选路径，见[13号手册](13-Skill离线改进与评测操作.md)。本篇仍介绍手动提出与原双重确认路径。

适用：API 0.17.0。学生端 [规划与策略](http://127.0.0.1:4003/student/planner)。仅正式项目，当前仍为模拟/成人开发。

## 1. 提出策略

1. 选择项目，打开“规划与策略”，填写学习体验、每日时长和反思重点。
2. 勾选“调整执行策略（需审核与本人确认）”。
3. 选择练习顺序、复习列表排序、生成课程支持方式和通用追问重点。
4. 选择1–5份管理员已发布的参考资料，点击“生成开发策略提案”。
5. 核对“执行策略编译与差异”：每项的原值/候选值、消费者、策略指纹，以及冻结的学情依据。

四项由你提出；勾选真实模型时，模型当前仍只建议时长和反思重点，不会自动替你改变四项。新提案没有即时生效。

## 2. 审核与确认

管理员进入“策略评审”，打开提案，查看冻结来源、学情摘要、差异和Skill，填写审核依据后通过或退回。通过后学生填写确认理由并确认激活，也可不采纳。

等待期间出现新学习事实、自述、复核、资料状态或课程绑定变化时，旧候选可能失效；请取消后根据新依据重建，不反复提交旧关口。

## 3. 在哪里看到实际变化

- **陪学练习顺序**：选“同版本错题优先”，下次开始陪学时，过去确实数值错误的已有练习题优先出现。诊断与检测位置不变；没有同版本错题则原序。
- **复习列表**：选“到期数值错误来源优先”，刷新“错题与复习”可见排序版本说明。不会提前到期，也不改变1/3/7天间隔。
- **生成课程支持**：选“逐级支持”就逐级查看现有提示；选“先自问，可恢复具体支持”则在已有未用提示通过后先引导自问，仍可继续求助。仅生成课程支持渐撤，静态旧单元不因此升级。
- **通用追问**：选依据、表示或核验，下一次通用互动采用相应安全追问方向；无法辨认学生表达时仍先澄清。当前仍使用受限模板展示，不表示自由生成内容已全部开放。

陪学、圆桌或我教AI页面展开“本任务冻结的执行策略”，可查看版本、指纹和任务顺序。记录保留了开始时配置，便于对照原始尝试；策略不是能力评分。

## 4. 导出与回滚

提案详情可展开/下载 Skill.md。文件是配置的可读导出，不要当作脚本运行，也不能编辑后上传执行任意指令。

“当前学习软策略 → 查看激活历史与回滚”选择本项目曾生效的版本或默认基线，填写理由后回滚。它影响新任务；已经开始的陪学/活动继续原冻结版本。资料被撤回的旧版本不能重新激活。

## 5. 完成边界

当前仅四类受限参数接入了消费者；不自动新增/删改课程题目、不改数学核验/检测/预算、不评分、不证明教学有效，也没有启动自动RSI。未勾选执行策略时仍可使用原两字段规划流程。
