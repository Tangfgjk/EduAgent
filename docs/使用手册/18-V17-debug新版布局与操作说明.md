# V17-debug 新版布局与操作说明

适用：2026-10-26 的 `V17-20261025-debug`。学生端：`http://127.0.0.1:4003/student/`；管理端：`http://127.0.0.1:4003/admin/`。账号沿用原系统；没有改成新的一套数据库。

## 1. 第一次使用

1. 登录学生端，在左侧点「项目」建立持续学习空间；一次短探索用「临时会话」。临时会话不进入全局正式项目统计。
2. 看「今日学习」里的真实下一步，进入「课程与安排」。空间名称只是名称，不会自动当作课程。
3. 在「当前课程」输入想学的主题。例如“负数乘除和运算顺序”。需要细化时展开「具体目标与课程设计选项」，有理数可选本轮概念重点。
4. 保存诊断尝试，查看课程范围，再确认生成。若提示尚不支持，选择已支持单元；这不表示你描述得不好。需要澄清时按提示补重点。
5. 候选可用后查看内容并点「确认使用这份课程」。准备候选与正式切换是两件事；创建候选不会直接换掉原课程。
6. 正式项目到「学习安排」确认目标与时长；临时会话可直接开始已开放活动。已绑定时课程页优先显示「继续学习」和当前课程，而不是要求反复输入主题。

也可以展开「手动选择或调整已发布课程」，填写主题、课程名，选择单元和起始单元后绑定。这里只能选择当前有权限使用的已发布内容。

## 2. 左侧导航怎么选

| 入口 | 什么时候用 |
| --- | --- |
| 今日学习 | 不知道下一步时先来这里；优先恢复实际未完成任务 |
| 学习空间 | 管理项目、临时会话，重命名、归档或恢复 |
| 课程与安排 | 当前课程、学习安排、配套资料；从资源页进入数学单元库 |
| 津津陪学 | 与津津持续作答、求助、回应追问、反思和独立检测 |
| 圆桌讨论 | 比较表示与前提，表达自己的比较修正，最后独立核验 |
| 我教 AI | 讲给学伴听，回应它对讲解的具体问题，再核验 |
| 互动课堂 | 打开已有幻灯片课堂，播放可用媒体、暂停思考、回答互动 |
| 错题与复习 | 查看到期、已安排和待澄清问题，回到原始尝试 |
| 成长 | 分类别看过程、知识覆盖、帮助、素养材料与来源记录 |
| 规划与策略 | 基于当前项目体验与记录提出调整，查看差异，确认、拒绝或回滚 |
| 学习方式改进 | 原Skill功能，查看改进假设、评测、试用、撤回及可选的自动语义改进 |

旧的计划、单元、策略和Skill地址继续可用。功能重排没有删除这些能力。

## 3. 一次陪学怎么进行

1. 选择当前空间和课程，在「津津陪学」开始。
2. 诊断先独立回答。普通中文如“这个答案是3”可保守提取；多候选、否定或不确定表达不会被强行当作数值答案。
3. 练习阶段主要用同一个对话框。选择「回答这道题」提交数值表达；选择「回应AI的追问」讨论思路。按钮不可用时看旁边的真实原因。
4. 需要帮助可点「给我一点提示」。模型处理中可停止生成；额度耗尽后仍可作答或使用剩余预设提示，不必反复重试。
5. 数值通过后，在同一输入区写反思，再继续。确认计划里的优先任务会用于后续新陪学的顺序；其余原练习和独立检测保留，不会为了凑时间删题。
6. 独立检测期间不开放辅助。不会或表达尚不确定时保留真实状态，不自动制造通过。
7. 流程记录和历史在次要入口中可查；结束陪学保留原输入。

AI的追问是结合本轮表达和受限历史生成的。输出无法通过检查时使用备用引导，不能把备用内容当成这次模型成功生成，也不能把AI评价当作数学真值。

## 4. 圆桌与我教AI如何切换

左侧三大活动都有直接入口。相同空间已有陪学或另一活动时，新路线先显示：

- 「回到原任务继续」：恢复原来的表达和进度。
- 「结束原任务后切换」：先弹出明确确认，结束后保留原记录，再进入新路线。

查看成长、复习或已有策略，不需要先把整轮学习删掉。运行中的教学仍保留自己的冻结配置；允许的回滚只影响之后的新任务。

## 5. 成长页如何查

顶部先选范围、时间和来源，再选一个分类。项目内默认当前空间；全局统计排除临时会话。

| 分类 | 看什么、怎么操作 |
| --- | --- |
| 总览 | 少量真实计数和过程趋势；下一步依据实际未完成任务、到期复习，跳转后可返回刚才的成长视图 |
| 知识与表现 | 切换知识覆盖/作答表现；点击节点或条形查看来源，不把提交次数当作掌握度 |
| 复习与支持 | 切换复习安排/帮助使用；查看到期原因和实际提示过程，详细复做进入复习页 |
| 素养材料 | 六个观察方向，单位为候选材料条数；点一个方向查看作品来源，不是能力雷达或成绩 |
| 学习记录 | 月历按月切换，选日期后从服务端查询当天全部匹配记录；每页20条，继续翻页查原文 |

分类、范围、时间、来源、辅助筛选和分页保留在URL里，刷新与浏览器前进/后退能恢复。原始来源用对话框打开，关闭后仍在原分类；保存自述后会更新记录。归档和辅助情况在高级筛选里。

## 6. 规划、Skill与课堂

「规划与策略」先看当前方式，再写本次体验。参考资料可复用平台已开放资料/默认开发参考，不必每次重新上传。系统产生候选后看具体差异与采用的依据，由你确认或拒绝；已有激活历史可按允许状态回滚。

「学习方式改进」可生成离线规则候选或模型语义候选。自动语义改进须明确启用，个人试用也须同意。工程评测通过不等于教学有效；可撤回，停止规则可触发保守回滚，不自动推广为全局策略。

「互动课堂」使用当前课程的已有可用版本，支持场景、公式、可用媒体、课堂回答与进度恢复。普通文字材料不会自动成为幻灯片。固定单元没有课堂生成任务时，先继续练习或准备新的主题课程；没有媒体不影响使用已有文字和公式。

**本次新增真实配音未成功，服务商返回400。** 已有图、视频和文字仍可用；原媒体预算和此次单次复测均不会自动追加，不能靠反复点击开启新收费调用。

## 7. 管理端

管理端与学生端分别登录。概览先看影响学习的队列；这里的数量明确为最近一页，不是全站总量。原账号管理、内容审核、课堂/媒体、解答复核、策略评审、工程评测、教学效果平台、Skill评测、运行记录、模型与权限全部保留。

教学效果平台新增「核对实际策略暴露」模式：预登记基线/候选策略摘要、题集和版本，测验前登记项目分配；之后只采集同来源、题集/版本匹配、首次曝光且无辅助的独立事实。分组不能手挑，登记不替学生启用策略。需要真正先于后测的练习，不能在同一秒事后补练习。完整随访人数、专业审核和真实学生条件没有满足前，效果始终待验证。

账号密码、来源权限、模型预算和内容审核仍以实际配置为准；页面入口调整不会改变角色权限。
