# G00/G01 使用增补：课程绑定与动态内容

日期：2026-10-18。配合 [完整说明书](08-V10完整使用说明书_学生端与管理端.md)，当前访问端口固定 **4003**。

## 学生：先确认学什么，再开始

1. 打开 `http://127.0.0.1:4003/student/`，登录并新建/进入项目或临时会话。
2. 页面顶部出现“请确认此空间的学习主题和课程”。填写主题（如“负数乘除和运算顺序”）、课程名称，勾选管理员已开放的单元，并选择起始单元。
3. 点击“确认课程绑定”。旧项目也要自己确认一次；修改项目名称不会修改课程。
4. 正式项目仍须到“学习计划”确认计划，再进入“津津陪学”。临时会话可直接陪学。
5. 圆桌和我教 AI 自动匹配上方当前单元。若没有相应活动或活动未开放，页面会说明；它不会自动换成概率。
6. 想学课程中的另一单元，使用顶部“当前课程单元”。想调整主题、名称或课程包含的单元，点“调整课程”。先完成或取消正在进行的学习/策略任务；遇到冲突请刷新。
7. 切到其他项目后使用那个项目自己的课程。复习和成长证据保留项目原有历史，不因当前单元改变而清空。

目前主题填写和课程绑定是人工确认，尚未根据任意主题自动检索知识点、生成完整课程。新增的有理数 JSON 是开发示例，需要管理员明确导入。

## 管理员：登记一个新开发单元

1. 打开 `http://127.0.0.1:4003/admin/`，进入“知识点与题库”。
2. 找到“动态内容登记”，展开“导入 content.v1 JSON”。复制仓库 `examples/dynamic-content.rational.json` 全文，粘贴并点击“登记不可变内容版本”。
3. 样例包含一个有理数陪学单元、我教 AI 活动和圆桌活动。它复用自编开发题展示存储机制，不是实际模型生成。重复导入会拒绝；改版应同时改内容和活动 ID，再登记新版本。
4. 下方“跨领域开发内容包”找到新单元，点击“核对…”，检查题目、参考答案、提示，填写开发核对依据并保存“可供开发验证”，再勾选确认启用。
5. 在“新增单元互动审核”找到两个活动，分别核对并保存审核依据、启用。父陪学内容也必须保持开放；仅启用活动不代表父内容已开放。
6. 回到学生页面刷新，在课程确认/调整中加入该单元。陪学、圆桌、我教 AI 即可使用同一内容上下文，无须修改代码常量。

登记后的结构检查不是数学答案审核。管理员应核对自编题的条件、参考答案、活动与独立验证关系；当前仅供模拟/成人开发账号，不能将“启用”当作专业教师审核。

## 模型功能有什么变化

“配置与权限 → 模型与运行配置”增加按用途的数据范围与共用预算表。当前真实模型范围仍是原有受限开发路线，导入一个新单元不会自动获得外部模型调用权限。

我教 AI、圆桌中的模型选择讨论方向，最终问题通过安全模板展示，并会明确说明。不自动评定解释质量、掌握度或教学效果。程序的数值比较与模型建议分开；独立检测不提供模型辅助。
