# 桂子问津使用手册

适用版本：0.10.2。编写日期：2026-10-17。面向当前本机开发体验，按现有页面与功能编写。

你已完成管理员建号和学生登录，接下来从“启用内容”和“选择学习空间”开始。

## 1. 第一次体验：照着这条路线走

建议先体验概率单元，走通陪学、圆桌、我教 AI 和证据记录。下述操作由你在页面中完成，不会自动替你审核或作答。

### 第一步：管理员启用概率内容

打开 [管理端](http://127.0.0.1:8000/admin/)，登录管理员账号：

1. 左侧点击 **知识点与题库**。
2. 找到 **跨领域开发内容包** 中的“等可能事件概率 · 开发单元”。
3. 点击 **核对等可能事件概率 · 开发单元**。
4. 阅读题目、参考数值、提示与误区，勾选开发范围确认，点击 **启用此内容包**。
5. 同页找到 **新增单元互动审核**，点击 **审核概率圆桌与我教 AI · 开发活动**。
6. 阅读互动题与角色模板，勾选确认，点击 **启用此互动包**。

陪学包和互动包分别启用，不能互相代替。启用只表示允许开发测试，不代表已经完成专业教学审核。

编写手册时核对：本机 5 个陪学包、2 个互动包均未启用；你操作后，以页面显示的最新状态为准。

### 第二步：学生新建临时会话

切换到已登录的 [学生端](http://127.0.0.1:8000/student/)：

1. 点击 **项目与会话**。
2. 点击 **新建临时会话**。
3. 空间名称可填写“概率功能体验”，点击 **保存空间**。
4. 核对页面顶部或左侧“当前工作空间”确实是这个空间。

临时会话可直接体验陪学，不需要先确认学习计划。其记录留在当前空间，不自动并入全局正式项目证据。

### 第三步：完成一轮陪学

1. 点击 **津津陪学**。
2. 在 **选择开发单元** 中选择“等可能事件概率 · 开发单元”。
3. 点击 **开始开发单元**。
4. 完成诊断、练习与反思、两道独立检测，最后查看学习小结。

每次进入此页面都先确认所选单元；不能仅凭之前浏览过概率目录，就默认当前仍是概率。

### 第四步：体验圆桌和我教 AI

1. 完成或结束当前陪学。
2. 点击 **圆桌讨论**，在 **选择互动单元** 中选择“概率圆桌与我教 AI · 开发活动”。
3. 点击 **开始圆桌讨论**，先提交自己的初步思路，再比较角色观点，最后提交自己的核验。
4. 圆桌结束后，进入 **我教 AI**，重新确认概率互动单元，点击 **开始我教 AI**。
5. 先讲解，再针对学伴的预设误区补充纠错说明，提交核验后查看 TeachReport。

两条活动是各自独立的流程，不会自动从圆桌跳入我教 AI。同一空间的陪学和互动需依次完成，不能同时开启。

### 第五步：回看过程

- 点击 **错题与复习 → 学习记忆**，查看当前空间留下的过程与来源。
- 点击 **成长证据 → 当前空间局部**，查看本次体验的记录。
- 若“全局宏观”没有这次记录，这是临时空间的正常行为。要体验全局累计，请按第 3 节建立正式项目。

## 3. 正式项目和临时会话怎么选

| 项目 | 正式学习项目 | 临时会话 |
| --- | --- | --- |
| 适合用途 | 持续学习一个目标、积累长期记录 | 快速体验或一次探索 |
| 陪学前的计划 | 需要一份已确认且没有待处理计划的状态 | 不要求先确认计划 |
| 数据归属 | 属于当前项目 | 属于当前临时空间 |
| 全局成长证据与记忆 | 纳入，归档后历史仍可回看 | 不纳入 |
| 规划与策略 | 支持 | 不支持正式策略规划 |

### 建立正式项目

1. **项目与会话 → 新建学习项目**。
2. 填写名称，例如“等可能概率入门”，点击 **保存空间**。
3. 进入 **学习计划**，在“这次想学会什么？”填写目标，例如“区分等可能的基本结果与事件，能说明计数依据”。
4. 选择每天愿意投入的分钟数，点击 **生成计划草案**。
5. 等待草案出现，阅读后点击 **我确认这份计划**；也可使用页面中的时长调整操作或取消。
6. 显示“计划已确认”后，进入 **津津陪学**，选择已启用的单元开始。

当前计划来自开发模板，目标提交不会自动生成完整课程或任意题目。计划目标与实际选择的开发单元需由你核对。

### 切换、归档和恢复

- 使用左侧“当前工作空间”下拉框切换，核对空间名称后再作答。
- 项目与临时空间之间不会自动合并学习记录。
- 归档后可以查看历史，作答、复做和追加说明等写入操作需恢复空间后进行。
- 归档不等于删除；正式项目的历史仍可出现在全局证据中。

## 4. 津津陪学详细操作

当前每个基础包都是 5 道开发题：1 道诊断、2 道练习、2 道独立检测。

### 4.1 先试一题：诊断

1. 阅读题目及输入要求。
2. 在 **我的数值答案** 中填写结果，步骤写在 **我的步骤与依据（可选）**。
3. 点击 **检查我的解答**。
4. 阅读反馈后点击 **继续下一步**。

诊断不提供提示，提交后不能改写该题结果。程序只检查数值，不自动判断你写的推理。

### 4.2 练习、提示与反思

- 练习可以保留多次尝试。数值未通过时，检查条件和运算后可再次提交。
- 需要帮助时点击 **给我一点提示** 或 **再给我一级提示**。
- 提示依次为 L0 轻推、L1 方向、L2 部分步骤、L3 完整对照；使用情况会留下记录。
- 数值通过后，在反思框中写下依据、检查方法或下次提醒，点击 **保存反思并继续**。
- 已尝试但暂时无法继续时，可在按钮出现后选择 **记录为未完成并反思**。

提示为预设文本，不会根据你的自由表达智能调整。反思会保存，但当前没有自动评价其质量。

### 4.3 独立检测与小结

- 两道检测不提供提示，每题提交后不能修改。
- 每题提交后按页面按钮继续；最后点击 **查看学习小结**。
- 小结展示本轮结果、尝试次数、提示使用与反思，不代表掌握度或素养得分。
- 刷新可恢复已保存的过程。中途想停止时，点击 **结束这次陪学**，已保存的记录仍保留。

### 4.4 答案怎么输入

当前支持数值、分数和有限的四则运算，例如 `0.25`、`1/4`、`(2+3)/4`。这只是格式示例，不是当前题目的参考答案。

- 单位、列式和说明放到步骤框；数值答案框按题目要求填写。
- 方程题可以按页面提示填写 `x=数值`。
- 任意证明、复杂代数式或纯文字答案，当前可能无法验证。
- **不可验证不等于答错**，也不等于已经通过，会单独保留并可进入人工复核。

## 5. 圆桌讨论与我教 AI

当前支持方程、概率两个独立审核的互动包，其它基础包尚未提供这两条互动路线。

### 圆桌讨论

1. 选择互动单元，开始活动。
2. 填写 **我的数值表达** 和 **我的初步思路**，点击 **保存表达，邀请学伴**。
3. 阅读思路提出者、质疑者和整理者的观点；其中可能有故意设置、等待核验的错误。
4. 在 **我的比较、纠错与检查依据** 中写下自己的比较与依据，并填写最终数值表达。
5. 点击 **保存核验，生成小结**，回看自己的两次贡献及核验结果。

### 我教 AI

1. 选择互动单元，开始活动。
2. 填写 **我的讲解** 与数值表达，先保存自己的说明。
3. 阅读虚拟学伴的预设误区，针对其问题补充解释与检查依据。
4. 再次提交数值与说明，查看 **TeachReport · 讲解记录**。

当前学伴使用固定模板，不会真正理解你的讲解或按原文动态回应。TeachReport 是过程记录，不能作为教学或讲解质量评分。活动后的数值核验属于辅助后表现，不计为独立检测。

暂时不确定数值时可以如实表达，末次输入若超出验证范围会进入待复核；不会因此获得自动判断的教学评价。

## 6. 错题、复习和学习记忆

进入 **错题与复习**，有三个页签：

| 页签 | 看什么、怎么用 |
| --- | --- |
| 复习安排 | 在“待复习 / 已安排 / 全部记录”之间切换；点击“无提示复做”再次提交，或“查看原始尝试”回看来源 |
| 不可验证与复核 | 查看无法自动核验的提交及人工结论；通过“查看来源与说明”追溯原文 |
| 学习记忆 | 查看当前空间或全局正式项目的学习摘要和观察来源 |

### 哪些情况会出现复习条目

- 陪学数值未通过，或练习中使用提示后答对，会形成对应复习来源。
- 不可验证提交先进入复核，不直接当作错题。
- 人工复核建议回看的记录可形成复习来源；互动角色话术不会自己变成学生错题。
- 如果当前没有这些记录，复习列表为空是正常情况。

默认复习间隔为 1 / 3 / 7 天，目前未经真实学生校准。提前复做会保存结果，但不会推进间隔；一次原题通过不等于掌握或迁移能力通过。

查看原始来源后，可追加 **我的说明** 并点击 **保存我的说明**。说明作为学生自述单独保留，不覆盖原答案或程序判断。

诊断/独立检测期间，以及另一个互动尚未结束时，部分复做会被阻止；先完成或结束当前流程。已撤回或版本不匹配的内容也不能自动复做。

## 7. 成长证据怎么看

进入 **成长证据**：

1. 选择 **当前空间局部**，查看正在使用的项目或临时会话。
2. 选择 **全局宏观**，查看自己的正式项目汇总，临时会话不包含在内。
3. 选择最近 14 / 30 / 90 天，并按需要切换数据来源。
4. 查看提交、提示、反思、独立检测和互动贡献等过程统计，点击图表或页面中的筛选选项查看相应记录。
5. 在来源记录中点击 **查看原始来源**，核对具体题目、输入与说明。

注意：

- 正确率、交互次数和提示次数都是当前口径下的过程数据，不等于知识点完整覆盖或能力分数。
- “素养观察”当前显示量规待审核/未评定，不会因多提交几次就自动提高分数。
- 没有记录不代表能力为零；如果只在临时空间体验，查看其局部而非全局。
- 来源标签按环境与账号配置标记；开发账号显示“模拟数据”不表示你的实际输入没有保存。

## 8. 规划与策略：熟悉基础功能后再体验

这条路线只对正式项目开放，需要管理员先发布参考资料。

### 管理员准备资料

1. **策略评审 → 课程资料 → 录入课程资料**。
2. 填写标题、类别、版本、来源和有权使用的参考正文，保存资料版本。
3. 核对后勾选开发参考确认，点击 **发布资料**。

### 学生提交、管理员审核、学生确认

1. 学生选择正式项目，进入 **规划与策略**。
2. 填写“我的学习体验”，选择每日建议时长与反思重点，引用 1–5 份已发布资料。
3. 点击 **生成开发策略提案**，查看提案与来源。
4. 管理员在 **策略评审 → 提案评审** 中查看并决定是否通过。
5. 管理员通过后，学生返回此项目，核对并确认，策略才会激活。

当前策略来自固定开发候选，只调整允许范围内的建议时长和反思重点，不会自动理解课程正文、改写教学硬规则或判定教学效果。

激活的反思重点由后续新陪学保存；已有运行不会中途改变。在学习计划中，时长建议需要学生主动点击“采用当前策略建议”。可查看 Skill.md 导出、激活历史和回滚入口；回滚只影响后续使用，不改写旧记录。

## 9. 管理员日常操作

| 操作 | 页面与说明 |
| --- | --- |
| 创建学生 | 学生账号 → 创建学生账号；初始密码最低 6 位 |
| 重置学生密码 | 学生账号 → 对应学生 → 重置密码；旧会话失效 |
| 禁用学生 | 学生账号 → 禁用；已有会话失效，记录保留；当前页面尚无重新启用入口，操作前核对 |
| 启用原方程陪学 | 知识点与题库顶部方程卡片，核对并勾选后“启用开发测试” |
| 启用其它陪学包 | 跨领域开发内容包 → 核对目标包 → 勾选 → 启用此内容包 |
| 启用方程互动 | 圆桌与我教 AI · 互动模板审核 → 审核互动模板 → 勾选 → 启用互动开发 |
| 启用概率互动 | 新增单元互动审核 → 审核概率包 → 勾选 → 启用此互动包 |
| 复核不可验证解答 | 内容与解答复核 → 待复核 → 复核这条解答；核对原文、参考数值并写依据，允许“仍无法判断” |
| 发布参考与审核策略 | 策略评审 → 课程资料 / 提案评审 |

管理员对解答的结论与依据独立保存，不覆盖原始学生提交，也不自动形成专业教师金标。

## 10. 常见问题

| 问题 | 处理方式 |
| --- | --- |
| 登录后没有题可做，开始按钮不能点 | 管理员先启用所选陪学包；进入页面确认选中了已启用的单元 |
| 陪学已启用，但圆桌/我教 AI 仍不能开始 | 两类内容独立审核；还需启用对应互动包，并确认页面所选互动单元 |
| 正式项目提示先确认计划 | 去“学习计划”生成并确认；待处理计划需先完成或取消 |
| 提示“请先完成或结束当前活动” | 查看当前空间的陪学、圆桌与我教 AI，先完成或结束未完成流程 |
| 一直显示等待处理或准备任务 | 刷新检查状态；若持续不变，检查本机 worker 和数据库是否正常，不要反复新建相同任务 |
| 数学文字答案被判不可验证 | 数值框按页面要求填写，推理放步骤框；超出范围的提交进入复核，不当作答错 |
| 全局证据为空 | 检查是否只使用了临时会话、所选时间和来源；先查看“当前空间局部” |
| 复习列表为空 | 可能尚未出现符合条件的来源；切到“全部记录”核对，不必为了产生记录故意作错 |
| 归档后不能继续 | 在项目与会话中恢复当前空间，再作答或复做 |
| 页面提示版本/步骤已更新 | 刷新后核对当前状态再操作；不可自动把旧内容当成新版本继续 |
| 切换页面后出现登录界面 | 0.10.2 升级后首次刷新需各登录一次；后续若仍出现，记录具体页面与时间，核对退出、期限、禁用或重置情况 |
| 想自由提问并获得针对文字的 AI 回答 | 当前尚未接真实模型，自由输入只保存为记录，不会获得模型语义理解 |

## 11. 当前能力范围

当前基础内容为方程、有理数运算、一次函数求值、勾股定理计算、等可能事件概率，共 5 包、25 题；互动支持方程与概率。它们是代表性自编开发样例，不是完整七至九年级课程。

**当前未接真实模型，不自动理解课程正文、学生自由表达或评定教学效果。** 数值通过不等于推理正确、知识掌握或素养提高。已有专业审核前的真实学生开发内容门禁，不会因为管理员勾选开发启用而绕过。

更完整的后续目标见 [下一步开发清单](../进度/36-下一步开发清单_真实模型与教学验证.md)。
