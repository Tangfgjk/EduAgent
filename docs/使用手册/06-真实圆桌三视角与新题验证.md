# 真实圆桌：三视角与新题验证

日期：2026-10-17；仅用于模拟/成人开发账号和自编概率题。三视角由同一模型的一次调用生成，不是三位独立专家，也不是专家共识。

## 管理员准备

1. 到「评测工作台」，选择「圆桌三视角 · DeepSeek 专项评测」，查看三角色原文与逐条复核维度。当前 6 次调用均有有效结果，但方向匹配 5/6，R02 及所有问题语义仍待复核，报告标记检查未通过。
2. 模型继续使用既有「配置与权限 → 模型与运行配置」中的 DeepSeek。模型设置不在学生端；每日次数 0 代表不限额，仍记录预算预约与 tokens，失败不自动重试。
3. 到「知识点与题库」，确认基础概率内容已启用，找到新包 **概率圆桌 · 三种视角与新题验证**，点击审核，阅读题干、预设回退、另一题参考及版本。
4. 填写具体开发核对依据并保存，再勾选开发用途确认、启用互动包。新包默认未启用，独立于旧圆桌、我教 AI 及模型总开关。开发核对不等于教师专业审核；评测建议不会自动发布或停用模型。

## 学生操作

1. 进入一个项目或临时空间，打开「圆桌讨论」。默认选择新概率圆桌包；也可选择旧模板包。
2. 开始后填写「我的数值表达」「我的初步思路」。勾选「让 AI 根据本次思路生成三种圆桌视角」，点击「保存表达，邀请学伴」。取消勾选会使用预设观点，不请求模型。
3. 模型返回后分别阅读：
   - **思路提出者**：建议下一步可探索的表示或检查方法。
   - **质疑者**：询问当前假设及依据，不代表学生一定错了。
   - **整理者**：提出待比较或补充的依据，不代替学生形成结论。
4. 自己比较观点，填写修正后的数值与「我的比较、纠错与检查依据」，点击「保存修正，进入新题验证」。程序先核验本题数值，这次是辅助后的核验。
5. 另一题验证阶段隐藏圆桌观点、预设回退与此前过程，不再开放模型调用。独立填写答案和依据，提交后查看「圆桌讨论小结」。报告恢复展示角色观点及三条学生原始贡献，保留各自来源。

每次活动最多一次模型请求，同时生成三种视角，不允许继续请求或自动重试。刷新不新增调用。生成中可点「取消圆桌生成」，也可直接继续修正；步骤改变后迟到回复被拦截。失败时可展开「先使用预设圆桌」，继续自己的修正与验证。

## 数据与解释边界

只发送本题题干、候选数值及当前思路，经身份字段和邮箱/手机号脱敏；不发送其他项目、历史聊天、独立验证题或参考答案。请不要在输入中填写个人信息。真实学生账号不开放模型调用。

模型观点始终待核验。结构校验会检查角色数量、固定分工标识、连续引用、不允许的输出及完全重复问题，无法证明语义差异、数学前提或追问质量。学生可以反对模型，不由模型评分或决定是否掌握。

## 开发评测命令

```powershell
# 查看范围，不调用模型
.venv/Scripts/python.exe scripts/evaluate_roundtable.py --check-only
# 固定六样本，Fake 完整流程
.venv/Scripts/python.exe scripts/evaluate_roundtable.py
# 固定六样本，DeepSeek 最多六次，每次最多 512 tokens，无自动重试
.venv/Scripts/python.exe scripts/evaluate_roundtable.py --live
# 恢复相同运行，代码、语料和配置须一致；已终结请求不重发
.venv/Scripts/python.exe scripts/evaluate_roundtable.py --live --resume .local/evaluation/实际运行目录
```

运行使用独立评测数据库，保存报告后经显式登记才出现在工作台。网页阅读和逐条复核不产生模型调用。
