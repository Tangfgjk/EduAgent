# 有来源模型规划与策略确认

日期：2026-10-18；适用模拟/成人开发账号。真实学生数据尚未开放。

## 一、准备资料与模型

管理员在「策略评审 → 课程资料」录入标题、类别、版本、来源与正文，核对开发用途后发布。教材、课标、考纲、自编参考都可录入；来源是录入者声明，系统没有自动验证其真实性或专业质量。改正文需新建版本，旧版本保留。

管理端统一选择模型。当前本机仍为 DeepSeek、概率陪学 v3 配置、每日次数 0（不限额）；规划使用独立提示 `planning.sources.v1`，共用调用额度、计数和任务运行器，单次最多输出 512 tokens。学生不直接切换 Provider。

## 二、生成有来源候选

1. 学生进入一个正式项目，打开「规划与策略」。临时空间不开放策略规划。
2. 填写「我的学习体验」、请求的每日时长和反思重点，选择 1–5 份已发布参考资料。
3. 勾选 **使用已开放模型生成有来源的候选**，阅读发送范围，再点「生成开发策略提案」。不勾选仍走固定模板，不发送模型请求。

模型规划需先完成或结束当前项目中的陪学、圆桌与我教 AI；正在独立检测时不能用规划发起新辅助。生成期间若开始学习，结果会被拦截，需要取消后重新安排规划。
4. 等待模型候选。生成前页面中的时长只是学生请求值，不是模型建议，也不能审核或激活。
5. 候选生成后查看模型建议与请求基线的差异、逐条引用和理由。每条引用可展开核对模型实际读取的片段及来源标识；不要把引用命中当成理解正确。

模型只可建议：每日时长严格整数 5–60，以及反思侧重依据（basis）或核验（verification）。不能修改教学硬规则、答案、题库审核、独立检测、权限、模型配置或素养分数。

## 三、明确输入范围

真实调用范围已经本轮确认：

- 当前学习体验，最多 1000 字，作为学生自述。
- 当前项目同来源最近最多 6 条学习事实，附机器状态与每条最多 200 字学生原文；不发送参考答案或任务快照。
- 最多 3 条关联自述，每条最多 200 字。
- 选定资料每份仅前 800 字，最多 5 份；长文未读部分不会交给模型。
- 同账号、同来源、活跃正式项目的全局计数摘要，包含当前项目；不发送其他项目原文、标题或临时空间数据，不将数量作为能力评分。

身份、账号、邮箱、手机号经过脱敏，仍请不要填写个人信息。本轮不向模型发送人工判断原文，只有相应全局计数。完整冻结来源供本项目的学生和负责评审的管理员查阅；模型只读上述更小切片。

## 四、审核、确认和生效

管理员在「策略评审 → 提案评审」查看冻结依据和模型引用，填写评审依据，通过或退回。通过后仍未生效，必须由学生再次填写确认/拒绝理由。

学生确认后才激活策略。每日时长只是学习计划里的可主动采用建议；反思重点影响后续新陪学运行，不会改已确认计划、已有学习记录或独立检测规则。

「查看 Skill.md 与 Harness 候选」显示固定格式的可读导出和两字段 JSON；可下载 Skill.md。它不是模型编写的任意指令，不写入仓库技能目录，也不作为代码或任意提示执行。

## 五、失败、取消、失效和回滚

- 生成中或失败后可「取消此提案」。不自动重试；取消后可重新使用固定模板或明确发起新请求，新模型请求另计次数。
- 无效输出、超时或被拒绝的候选不会生成可激活策略，且不会覆盖已有生效策略。
- 审核/确认前新增项目学习事实、自述或人工判断，资料发布状态或策略基线变化，会使提案失效。引用了全局计数时，新建/归档正式项目或全局来源计数变化也须重新生成；新建临时空间不影响全局计数。
- 每份提案仍有 7 天确认期限；冻结来源不新鲜时不能批准或激活，退回、拒绝和取消可收尾。
- 在「当前学习软策略 → 查看激活历史与回滚」填写理由，回到平台默认或本项目曾激活且仍有效的版本。回滚只影响后续学习，历史保留。
