# 有理数教学 Agent 与动态课程操作

更新：2026-10-19。API0.19.0，数据库仍为`g08_001`。这是主题驱动教学首轮样板，当前限模拟/成人开发账号。

首次完整体验请先看[新版完整使用流程手册](16-新版完整使用流程手册_0.19.md)；本篇解释有理数Agent专项操作与实现边界。

## 1. 从哪里开始

学生在自己的项目或临时会话进入[主题与课程](http://127.0.0.1:4003/student/courses)，查看当前课程后，向下找到“准备新的主题课程”。

1. 保持“启用有理数教学 Agent 设计”勾选。
2. 输入主题，例如`有理数`。
3. 填写具体目标，例如`区分绝对值与相反数，并用数轴检查`。
4. 勾选“相反数”“绝对值与距离”，最多3项。
5. 点击“解析主题并准备诊断”。如果只输入宽泛“有理数”且没有选择重点，系统先要求澄清，不先调用模型或强行套题。

目前支持七类目标：数轴位置与移动、相反数、绝对值与距离、大小比较、加减、乘除、混合运算顺序。具体主题可以识别重点；同时涉及过多目标时先缩小本轮范围。其他数学主题继续使用原有受限生成能力。

## 2. 准备观察与生成

完成两道数值准备诊断，填写依据，保存并查看本轮范围。这里仍是有资料支持的准备信息，不是严格无辅助前测；解释尚未评阅。

可以调整“这轮更想练什么”，保存后确认范围并生成。模型收到本轮脱敏目标、选择的概念、各概念的数值观察计数、允许来源片段和已曝光问题参数；不读取其他项目正文。没有出现在两道准备题中的目标标记为未观察，不推断学生会或不会。

**DeepSeek**根据这些输入设计候选，决定：

- 所选目标内采用哪些可核验题型、参数和任务顺序；
- 5–11道主题任务中的诊断、练习和检测数量；
- 概念讲解、安排理由、不同表示与自查问题；
- 圆桌适合比较哪个概念，“我教 AI”适合讲清哪个概念，以及各自独立验证题。

**Fake**仅提供可重复的开发样例，不宣称具有模型理解能力。管理端已有服务配置决定本轮用哪种服务；学生不自行切换厂商。

数学题干根据结构化问题编译，程序独立计算参考值，检查除数、参数、目标覆盖、阶段顺序和重复问题。自由讲解与概念问题仍需人工评阅。

## 3. 管理端怎么审核

进入[课程生成与资源](http://127.0.0.1:4003/admin/generation)，按项目找到候选，展开“查看课程内容、来源与核验依据”中的“Agent 教学设计、目标与任务组合”。

核对：

1. 每个选定概念是否有适当练习和检测，顺序和理由是否合理。
2. 题目、参考结果和运算前提是否对应；验证题与准备题、练习不重用。
3. 讲解、表示、自查、圆桌和讲解问题是否适合本概念。
4. 讲到相反数和对称时有没有漏掉零的例外；绝对值与两点距离是否混淆。
5. 所有自由文字是否泄露检测或活动验证的具体题目/答案。

填写依据，核对后发布开发版本；语义不合适则退回。数值检查通过不能替代这一步，开发复核也不等于专业教师审核。

本次真实探针曾出现“相反数在原点另一侧”需要补足零例外的表述，因此该隔离样例未自动发布。后续提示已强调这一边界，不能据此保证所有后续讲解都正确。

## 4. 学生确认并体验不同活动

审核发布后，学生刷新主题页并“确认使用这份课程”。可展开“Agent 教学设计与依据”查看每个目标的安排理由；任务阶段与题型组合随课程版本保存。

- **陪学**：按这份课程的实际任务数量学习。在练习中查看“为什么这样引导”；数值未通过/不可验证时优先邀请另一种表示核对，已有无提示通过时可邀请自查，求助后仍能恢复具体支持。
- **圆桌**：使用本课程已审核的概念比较问题，讨论前提、表示与检查方法。
- **我教 AI**：围绕选定概念的讲解目标发问。请求模型时，模型根据当前表达选择已审核概念问题的方向。
- **检测**：保持无辅助，课程讲解和资源仍隔离；完成后查看事实，不据单次结果评定掌握或素养。

课程设计由模型提出；运行中的首次支持选择仍有数值/提示规则约束。即时模型不直接把未审核自由文字展示成教学结论，也不会任意删改检测。已有手工策略的优先方向仍按冻结策略执行。

## 5. 旧课程与额度

旧静态课程、旧生成课程和进行中任务保持原版本。**想体验新版，需要重新准备一份课程并完成审核、确认；改项目名称不会升级。** 切换前先完成或结束当前学习/策略任务。

沿用课程4096输出tokens/次、每课程最多6次调用（含最多1次明确内容修复）、通用互动512tokens/次和每活动最多3次等既有上限，无自动重试。不扩大OpenMAIC预算；生成文本课程不自动预约OpenMAIC。

本轮没有自动重构全部课程、开放证明/任意题干自动核验、自动判定长篇解释或教学效果，也没有启用真实学生与自动RSI。数学编译器支持11种有理数问题形式；超出支持范围需继续建设。

实现及验证见[开发验收](../进度/107-有理数教学Agent动态课程开发验收.md)。
