# 分步课堂与本地知识库

## 体验新版课堂

1. 登录学生端，选择自己的项目；确认一个包含四则运算练习的动态生成课程。
2. 打开左侧「互动课堂」，展开「准备分步数学课堂」，点击「准备分步课堂」。不调用收费媒体服务，重复点击会复用同版本。
3. 课堂包括观察例题、分步推演、自己尝试三页。可直接点左侧页面，或用上一页/下一页。
4. 推演页点「下一步」逐步展示，或点「播放课堂」。需要设备中文音色时勾选本机朗读；没有音色会明确提示。
5. 点「全屏课堂」集中观看，浏览器Esc退出。手机可横向滚动选择页面；推演公式在画布下方另有大字阅读区。
6. 互动页提交最终数值，如“这个答案是3”。解释仍需自己说明，数值符合不等于解释已被评定。
7. 可请求提示回看推演，随后继续作答；课堂下方提供当前项目陪学与复习入口。播放位置自动保存，也可手动保存，刷新可恢复。

如显示「当前课程尚无可验证的四则运算例题」，继续原有课堂/陪学，不会生成貌似正确的假演示。原有课程和版本都保留。乱码图片和无意义视频已经隔离；不再把它们当课堂必备内容。

## 建立自己的本地知识库

1. 左侧「本地知识库」→填写标题和正文，或选择UTF-8的txt/md文件。
2. 点击「保存到当前项目」。资料只属于当前空间，切换项目不会混用。
3. 输入关键词，点击「本地检索」。结果是资料原文片段，显示版本与位置，点击「查看来源全文」阅读。
4. 没有结果时换关键词；系统不会编造答案。资料清单可查看或删除，个人设置中的数据导出包含本人知识库。
5. 课堂里的「查阅本地资料」可进入当前项目知识库。独立检测期间请独立作答，检索和全文阅读暂时关闭。

首版不支持PDF、图片OCR、云模型问答或自动总结；上传资料不会自动发给DeepSeek。数学内容仍需要核对，不会自动变成系统参考答案。

## 管理端媒体核对

在课程生成/资源管理中的媒体预算任务处，展开完成素材的「文字与教学含义检查」。先看图片或完整播放视频，填写它帮助理解的具体内容，逐字检查与核对数学关系后才能开放；不合格选择保持隔离。不需重新批准费用，也不会因此重试生成。
