# 新版完整使用流程手册（0.19.0）

更新：2026-10-19。适用于当前本机版本，主服务端口固定 **4003**。

建议第一次用“**相反数与绝对值**”走完整流程。先完成课程准备、审核和陪学，再体验讨论、讲解、证据与策略。当前是模拟/成人开发版，真实学生教学与专业效果评价尚未开放。

## 一、流程总览

**管理员准备账号和配置 → 学生创建项目 → 选择目标 → 准备诊断 → 生成课程 → 管理员审核 → 学生确认课程与计划 → 陪学 → 圆桌 → 我教AI → 复习与成长证据 → 规划与策略 → 可选Skill离线改进。**

| 阶段 | 使用哪一端 | 完成标志 |
|---|---|---|
| 准备 | 管理端 | 有学生账号，课程与互动用途开放，模型配置可用 |
| 课程准备 | 学生端 | 目标清楚、两道准备诊断已保存、课程范围已确认 |
| 课程生成 | 学生端 | 数学检查通过，进入待开发审核 |
| 审核发布 | 管理端 | 课程已发布；有问题则退回 |
| 确认与计划 | 学生端 | 已绑定新课程；正式项目的学习计划已确认 |
| 学习活动 | 学生端 | 陪学、圆桌、我教AI依次完成或明确结束 |
| 证据与调整 | 双端 | 能回看来源，策略经过审核和学生确认 |

## 二、打开页面与管理员准备

打开两个标签页：

- [学生端](http://127.0.0.1:4003/student/courses)：学习、生成课程、确认与回顾。
- [管理端](http://127.0.0.1:4003/admin/generation)：账号、内容、模型、课程和策略审核。

两个端分别使用对应身份登录。首次管理员由维护者在本机初始化；学生在管理端“学生账号”创建，密码至少6个字符，忘记密码由管理员重置。现有账号可直接使用，不必为升级重复创建。

管理员检查：

1. **配置与权限 → 模型与运行配置**：核对已发布服务与密钥状态。DeepSeek是真实调用，Fake是不出网的开发模拟；学生不在自己的页面选择厂商。
2. **课程生成与资源 → 生成用途与知识资料设置**：展开后核对课程候选生成、通用陪学/圆桌/我教AI等用途是否开放。
3. 若要体验后面的“规划与策略”，提前在**策略评审 → 课程资料**登记并发布至少一份可使用的自编参考资料。

配置已开放就无需重复发布。每日次数为0表示不限次数，仍会产生服务商费用；课程、互动、搜索和OpenMAIC的限制分别执行。

## 三、学生创建学习空间

1. 登录学生端，进入“项目与会话”。
2. 选择“新建学习项目”，名称可以填写：`有理数概念理解`。
3. 保存并进入，核对左侧“当前工作空间”。
4. 打开“主题与课程”。

**正式项目**适合持续学习，支持后续项目策略和Skill离线改进。**临时会话**适合一次短期探索，局部记录会保存，不自动纳入全局正式项目画像。

铅笔图标用于重命名，箱子图标用于归档；归档保留记录、停止新增，可从“已归档”恢复。项目名称与实际课程分开：改名不会切换课程或升级旧内容。

## 四、准备新版有理数课程

### 1. 找到输入区域

“主题与课程”从上往下依次是：

1. 当前课程与学习路线。
2. 当前课程资源。
3. **准备新的主题课程**。
4. 本次课程准备步骤及历史记录。

进入第3块填写新主题。即使顶部已有旧课程，也可以准备新候选；只有完成审核并确认使用后才切换。

### 2. 推荐直接照填的示例

| 页面字段 | 推荐填写 |
|---|---|
| 我想学什么？ | `有理数` |
| 启用有理数教学Agent设计 | 保持勾选 |
| 本轮具体想学会什么？ | `区分相反数与绝对值，能用数轴说明并检查结果。` |
| 本轮重点 | 勾选“相反数”和“绝对值与距离” |

点击 **“解析主题并准备诊断”**。

当前有七类目标，每轮最多选择三项：数轴位置与移动、相反数、绝对值与距离、大小比较、加减法、乘除法、混合运算顺序。

只写宽泛“有理数”且没选重点时，系统会先提示选择1–3个目标。这时回到输入区补选，再提交即可，不是模型调用失败。具体主题可以识别目标；新教学设计目前只对有理数开放，其他主题沿用已有受限题族。

### 3. 完成两道准备诊断

1. 阅读屏幕上实际出现的题目。
2. 在“诊断1答案”“诊断2答案”填写数值或分数。
3. 在依据栏写自己的思路，例如如何使用定义、数轴或运算法则。
4. 点击 **“保存诊断并查看课程范围”**。

题目和数值可能变化，不要照抄别人的答案。这里展示了来源材料，因此是课程准备信息，不当作严格无辅助前测；程序也尚未评定解释质量。

### 4. 确认范围，发起生成

阅读“本轮课程范围”。需要时调整“这轮更想练什么”，点击 **“保存本轮重点调整”**，然后点击 **“确认范围并生成课程”**。

这一步开始使用管理端已发布的服务。DeepSeek会结合本轮目标、数值观察与来源设计课程；Fake只模拟流程。模型可以设计5–11道主任务，以及概念讲解、支架、圆桌/讲解用途和各自独立验证题。

提交一次后等待状态变化；刷新或离开页面不会自动重发。返回时从“这个空间的课程准备记录”选择对应记录，不需要重复新建。

| 显示状态 | 接下来做什么 |
|---|---|
| 已进入生成队列 / 正在生成 | 等待，较久时请管理员检查运行记录和worker |
| 数学检查通过·内容待开发审核 | 切到管理端审核 |
| 本次生成未完成 | 查看原因；只有符合条件的明确内容失败可申请一次修复 |
| 调用结果未知 | 先核对运行记录，不重复提交付费请求 |
| 课程已发布·等待你的选择 | 回学生端确认使用 |

## 五、切到管理端审核课程

1. 打开 **“课程生成与资源”**。
2. 按项目找到刚才的课程；可输入项目名称或主题筛选当前批次，更早记录需翻页。
3. 展开 **“查看课程内容、来源与核验依据”**。
4. 查看讲解、学习目标、**“Agent教学设计、目标与任务组合”**，并展开完整候选核对题目、参考结果及检测。

重点检查：

- 是否覆盖学生选择的目标，题目和活动是否合适。
- 计算条件、数值、讲解和概念问题是否正确。
- 讲相反数和数轴对称时是否明确零的例外；绝对值与两点距离是否混淆。
- 练习、准备题、检测和活动验证是否隔离，讲解或问句有没有泄露检测答案。

核对后填写至少10字审核依据，勾选核对确认，再点 **“审核并发布开发版本”**。有问题选择 **“退回或撤回”**，保留原因；不要为继续体验随意通过。当前页面不提供任意修改候选后原地发布的编辑器，退回后需重新准备合适候选。

**数学检查通过只表示结构化问题的数值等检查通过，自由讲解仍需人工审核。** 如果同一位演示者先查看管理端参考答案，再回学生端作答，这轮只用于演示机制，不作为真实独立学习效果。

## 六、回学生端，确认新课程与学习计划

### 确认使用课程

回到同一空间的“主题与课程”，刷新并选中对应记录，点击 **“确认使用这份课程”**。

检查顶部课程名称和版本；“当前课程与学习路线”会集中显示三类活动的开放状态。发布后还可以查看“Agent教学设计与依据”。

**旧课程不会自动升级。** 新建项目、勾选Agent或改项目名都不等于已换课，必须生成、审核并确认使用。切换被阻止时，先完成或结束该空间正在进行的学习/策略任务。

### 正式项目确认计划

1. 打开 **“学习计划”**。
2. 填目标：`能区分相反数与绝对值，并用数轴独立核对。`
3. 选择每日投入时间，例如15分钟。
4. 点击 **“生成计划草案”**，阅读后点 **“我确认这份计划”**。
5. 如改时间，先“更新草案”，再确认。

正式项目开始陪学前需要有效确认计划；临时会话可按开放路线探索。计划草案仍是固定开发流程；刚才的Agent课程设计与后面的策略版本是另外两项功能。

## 七、完成一轮津津陪学

1. 从概览点击“查看津津陪学”，或左侧进入 **“津津陪学”**。
2. 核对当前课程，点击 **“开始开发单元”**。
3. 按题面独立完成诊断；数值放答案栏，解释写依据栏。
4. 练习时先尝试，需要时点 **“给我一点提示”**，仍不会可继续请求支持。
5. 如开放AI追问，写出当前困惑，例如：`我不确定相反数与绝对值在数轴上的区别，应该先核对什么？`
6. 查看 **“为什么这样引导”**：本题目标、支持选择的事实依据，以及课程Agent的安排理由。
7. 按页面填写反思、继续后续任务，最后完成无辅助检测并查看小结。

新课程数量与组合可以不同，不固定为五道题。数值未通过或无法验证时会邀请表示核对；已有无提示通过等记录时可转向自查，求助后仍可恢复具体支持。

诊断和检测阶段不给提示与资源。程序核验数值，不能据一次通过认定学生已掌握或讲解已经正确。

## 八、依次体验圆桌和我教AI

**先完成或结束当前陪学，再开始其他活动。** 同一空间的陪学、圆桌和讲解路线依次进行。

### 圆桌讨论

1. 打开 **“圆桌讨论”**，确认同一课程。
2. 点击开始，先写自己的答案和思路。
3. 阅读比较问题和不同视角，核对前提、表示和检查方法。
4. 写自己的比较与修正，按页面完成另一题验证，查看小结。

新版问题来自本课程已审核的概念设计。模型选择讨论方向；三种视角不是三位独立专家，不能按多数意见判断正确。

### 我教AI

1. 圆桌结束后打开 **“我教AI”**。
2. 按本题给出数值，写自己的讲解。
3. 如需模型追问，勾选 **“让AI根据本次讲解选择追问方向”**，点击保存表达。
4. 阅读问题并补充或修正；通用活动最多三轮。
5. 点击 **“保存修正，进入新题验证”**，独立作答，查看结果。

模型依据本轮表达选择已审核的概念问题，不会直接把即时未审自由文字当作教学结论。长篇解释与素养尚无自动专业评分。

## 九、查看资源、复习与成长证据

### 当前课程资源

在“主题与课程”上方或陪学练习阶段找到 **“当前课程资源”**，展开已审核材料阅读。

课程发布可能带有已审核的文字讲解，不代表已经生成OpenMAIC课堂。资源为空时可联系管理员核对生成、审核或撤回状态；其他空间的资源不会自动共享。

管理员在课程卡片点击 **“查看本课程资源审核”**，可筛选、预览和审核资源。OpenMAIC首轮真实生成预算已停止，当前可用已有资源或导入课堂，不需要为普通课程体验重新预约生成。

### 错题与复习

打开 **“错题与复习”**，看当前项目的安排，点击来源回看答案与提示；按页面进行原题复做，必要时补充自己的说明。

新项目可能尚未到期。默认1/3/7天是开发间隔，提前复做单独记录，不推进到期间隔；原题复做不等于新题迁移。无法验证的答案可在管理端“内容与解答复核”追加人工数值意见。

### 成长证据

1. 打开 **“成长证据”**，先看“当前空间局部”。
2. 选择日期、数据来源，查看知识点、学习表现、支架时间线和素养材料。
3. 点击图形或列表的 **“查看原始来源”**，核对题目、答案、依据和过程。
4. 切换“全局宏观”，查看本人正式项目汇总；临时会话不自动进入这里。
5. 需要时追加学生自述；原始答案和自动结果不被覆盖。

六方向素养条形显示候选材料数量，当前均未评定，没有能力分。数据空白时先核对项目、日期、来源及归档筛选。

## 十、提出并激活下一阶段策略

这一部分适用于正式项目；第一次体验可以完成前九节后再来。

1. 学生进入 **“规划与策略”**，填写学习体验，例如：`计算能完成，但相反数遇到零时仍需要核对定义。`
2. 选择时长、反思重点，以及1–5份已发布参考资料；没有资料请管理员先登记发布。
3. 如需改变任务执行，勾选 **“调整执行策略（需审核与本人确认）”**：练习顺序、复习排序、生成课程支持方式、通用追问重点。
4. 可选择已开放模型生成有来源候选；当前模型只建议时长和反思，四项执行参数在这条路径由学生选择。
5. 点击 **“生成开发策略提案”**，核对冻结的来源、学情摘要、参数差异和Skill。
6. 管理员切到 **“策略评审”**，填写依据并审核。
7. 学生回来确认激活。后续新任务使用新策略；旧任务保留原配置。

可以查看/导出Skill.md，也可以在激活历史回滚到有效旧版或默认基线。文件是白名单策略的可读形式，不是任意指令执行入口。

## 十一、可选：Skill离线改进

前提是正式项目、已确认课程、有效四参数策略基线，以及同项目/来源/内容版本的实际学习证据。

1. 学生 **“Skill离线改进 → 生成离线改进候选”**。
2. 核对单参数变化、冻结来源和新旧机制评测。
3. 管理员 **“Skill进化评测”**填写依据，复核通过或拒绝。
4. 学生刷新并 **“采纳为待审策略”**。
5. 再走普通策略审核与学生确认，新任务才生效。

没有候选可能是证据不足或该参数已经采用，不必反复生成。候选冻结后再增加记录、修改课程或切换基线，可能使旧候选失效。消费者代码升级也可能要求重新评测。

这里仍是本机规则提出候选、工程样本检查机制，不是DeepSeek自动理解正文后的教学自进化，也不证明学习收益；评测通过不自动发布。

## 十二、遇到问题按这里处理

| 现象 | 处理 |
|---|---|
| 看不到新Agent选项 | 确认访问4003的“主题与课程”，刷新页面；旧标签页必要时强制刷新 |
| 仍然只有旧题型 | 检查是否确认使用了新生成并审核的课程；旧课程不会自动升级 |
| 主题需要澄清 | 在输入区域选择1–3个有理数重点，再提交 |
| 排队很久 | 看管理端“运行记录”，检查教学与模型worker；不要重复付费提交 |
| 数学检查失败 | 保留报告；符合条件才申请一次明确内容修复，不能直接发布 |
| 上游结果未知 | 核对运行和费用记录，不自动重试 |
| 已发布但学生没换课 | 学生还需点“确认使用这份课程” |
| 陪学开始不了 | 核对课程、计划、开放状态、归档状态和同空间在途任务 |
| 圆桌/我教AI被阻止 | 先完成或结束当前陪学/另一活动，再核对当前课程 |
| 检测时资源不可见 | 独立检测隔离；完成后再阅读 |
| 没有到期复习或证据 | 新项目需实际操作积累；核对时间与来源，不伪造记录 |
| 策略审核通过但没变化 | 检查学生确认、有效版本，以及是否为新任务 |
| OpenMAIC预约禁用 | 看独立预算和已有任务状态；不通过换账号绕过 |

### 第一次体验的完成清单

- [ ] 新建或选择正式项目。
- [ ] 为“相反数＋绝对值与距离”生成新版候选。
- [ ] 完成管理员审核、学生确认课程和计划。
- [ ] 完成一轮陪学，体验一次求助并查看支持依据。
- [ ] 依次体验圆桌和我教AI，完成独立验证。
- [ ] 在成长证据找到本次原始来源。
- [ ] 如需要，完成一次策略审核和激活。
