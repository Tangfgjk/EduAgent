# 成长证据与学情观察使用说明

适用：2026-10-18 / API 0.16.0。本机学生端 [进入学习](http://127.0.0.1:4003/student/)。

## 1. 留下可查看的学习过程

选择自己的项目，在“主题与课程”确认课程后，进行陪学、复习、圆桌或我教 AI。提交答案、依据、反思或请求提示后，系统才有实际材料。只建立项目不会生成学情记录；项目名称不决定知识点映射。

## 2. 打开成长证据

1. 左侧选择“成长证据”。默认“全局宏观”汇集本人正式项目，临时探索不混入；可勾选是否包含归档项目。
2. 切换“当前空间局部”，查看当前项目或临时会话。归档空间仍可查原记录，不能新增自述。
3. 选择最近14/30/90天和数据来源。模拟、成人测试、真实学生分别显示；模拟数据不能证明真实效果。
4. 有新记录时点击“刷新证据”。来源列表分页和记录类型筛选不改变上方范围的总数。

## 3. 逐块看懂页面

### 知识点地图

实心卡表示该内容版本有记录，虚线卡表示没有该开发知识点记录。卡片显示事实次数、不同题数和版本。点击卡片后在“图形来源钻取”中选择“查看这条原始材料”。“查看开发先修关系”说明开发 KC 的依赖，不是正式课标达标图。

无记录不等于不会；未映射不等于材料丢失。一个单元有记录，也不表示所有知识点都已学会。

### 学习表现

浅色条长度显示提交数，深色部分显示数值通过数。初始诊断、练习有无提示、首次曝光/已见/曝光未知检测，以及提前/到期/时点未知原题复做分别展示。点击一行查看材料来源。相同题重复通过不代表新题迁移，数值通过也不证明解释有效。

### 支架时间线

查看何时逐级支持、先自我提问、请求帮助或恢复具体支持。点击事件可回看原始尝试。“未记录”表示旧事实没有支架决定，系统不会猜测。渐撤是生成课程的既有开发机制，历史静态单元不因此自动新增渐撤规则。

### 数学素养

六方向条形显示候选材料条数。点击方向可看归档规则及来源。材料可以跨维度重复出现；当前均为“未评定”，没有能力分。非空依据不等于正确推理，几何文字不等于已经完成作图。

### 供规划使用的学情摘要

查看事实、自述、人工数值复核的独立计数；展开可看截止时间、指纹和最多6条来源索引。正式项目的局部页有“带着证据查看规划与策略”入口。

## 4. 查看与补充材料

点击图形来源、支架事件或下方列表的“查看原始来源”，核对自己的答案、依据和过程。需要纠正体验描述时，在弹窗的学生自述中补充说明。保存后关闭弹窗，摘要会刷新；原始答案及自动核验不被覆盖。

人工数值复核由管理端已有“无法验证答案”流程完成，不会自动成为素养专业评定。

## 5. 在规划与策略里使用

1. 选择正式项目，打开“规划与策略”，填写本次体验并选择已发布的参考资料。
2. 创建开发策略提案，可使用现有固定方式或已开放的模型候选方式。
3. 在详情“冻结的学情观察摘要”核对最近30天、当前项目、对应来源的观察计数和指纹。
4. 管理员审核，再由学生确认，既有生效与回滚流程不变。

当前摘要保存在本机用于核对，没有自动新增外部模型数据；它也不会自动改变课程或支架。课程/复习/追问与 Skill 的进一步可执行调整属于后续 G07。

## 6. 常见情况

- **全局空白，局部有记录？** 当前是临时会话，或全局排除了归档/该来源/日期。
- **候选材料很多却没有素养分？** 正式量规和专业评阅尚未完成，不能用数量假造分数。
- **到期复习做错为何仍计入到期？** 计的是按时点发生的提交，不是通过或推进复习日程。
- **规划详情没有新摘要？** 旧提案保持当时快照；新提案才冻结这一字段。
- **能看到整套七至九年级掌握度吗？** 暂不能；当前仅6个开发 KC 映射和实际过程覆盖。
