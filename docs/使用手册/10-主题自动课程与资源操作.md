# 主题自动课程与资源操作

适用：0.15.0 / 2026-10-18 开发版。学生端 `http://127.0.0.1:4003/student/`，管理端 `http://127.0.0.1:4003/admin/`。

## 1. 管理员准备

1. 在“配置与权限 → 模型与运行配置”核对已发布 DeepSeek/Fake、账号/全站日额度与本机密钥状态。Fake 不出网，只验证机制。
2. 打开独立菜单“课程生成与资源”。核对数据范围，勾选课程候选生成、通用陪学/圆桌/我教 AI，确认开发用途后发布。
3. 仅模拟/成人开发账号可使用新内容；真实学生暂不开放。本次已开启课程、通用互动与Tavily搜索；OpenMAIC首轮一门课堂已生成并审核，资源预算现已停止，不会自动生成第二门。
4. 需要补充资料时，展开“登记本地知识资料”，填写 KC、版本位置与已授权正文，确认使用权后登记。填网址不会自动下载网页。
5. 来源出问题时在同处撤回，保留既有学习记录。恢复来源不代替重新审核内容。

## 2. 学生从主题开始

1. 登录，创建或选择正式项目/临时会话。名称不决定课程；选择“主题与课程”。
2. 输入具体初中数学主题，例如“负数乘除和运算顺序”。点击“解析主题并准备诊断”。
3. 查看来源与本次支持范围，完成两道诊断并写依据。暂不判解释质量；因为页面有概念材料，这次不计严格无辅助效果测量。
4. 保存后看课程范围，可选择更重视“说明法则与前提”“表示条件”或“独立检查”，点击“保存本轮重点调整”。
5. 点击“确认范围并生成课程”。离开/刷新不会自动重发调用；排队需模型 worker。未知状态不要重复点击创建同一付费任务。
6. 数值检查通过后显示“内容待开发审核”。未审候选不对学生展示，请管理员到课程生成页核对。
7. 管理员发布后，刷新并点击“确认使用这份课程”。陪学、圆桌和我教 AI 自动使用相同当前课程，不再手选不相关单元。

主题不明确时重新输入一个更具体的单元；范围外不强行套题。目前自动题族只有有理数混合计算、一次方程、一次函数求值、勾股数值、等可能摸球概率和平均数，不是整套课标。

## 3. 管理员审核课程

1. “课程生成与资源 → 项目课程候选”查看该空间任务及完整候选。
2. 核对来源、数学条件、独立检查报告、讲解是否合理、目标是否超出题目覆盖，以及陪学检测/活动验证的隔离。
3. 输入至少十字审核依据，勾选检查确认，发布开发版本。没有核对过就退回，不让模型自批。
4. 失败时查看错误/校验原因；只有确定的候选内容核验失败可由学生申请一次修复，未知上游状态不自动重试。
5. 发布后仍可退回/撤回，未来调用受版本和来源门禁约束；历史记录不删除。

开发审核不代表专业教师审核。系统不会通过一个“数值通过”标签证明教材正确性或教学效果。

## 4. 陪学、圆桌与我教 AI

- 陪学：先诊断、练习、反思，再检测。练习时可逐级求助；有过无提示数值通过后，下一练习首次帮助会先请你提出检查问题，仍可继续求助恢复支持。
- 我教 AI：先写自己的数值表达和讲解，勾选模型追问后保存。AI 根据本轮表达选择方向，以有限模板提问；最多三轮，可保存修正进入另一题验证。
- 圆桌：先写自己的思路，模型选择讨论方向，三种视角请你核对前提、整理依据。请比较后给出自己的修正；不是多数意见直接判答案。
- 独立验证：不调用模型、不展示资源或提示。此前见过同题即使没作答，也不会再次算作新的独立检测。平台外曝光无法自动识别。
- 每个空间同一时间依次进行陪学或活动。切换路线前先完成或结束当前任务，避免同时运行造成检测辅助混入。
- “错题与复习”保留现有错题/辅助后通过的原题复习。原题复做不等于未见题迁移或教学效果。

## 5. 资源导入与预览

1. 管理员找到目标课程，展开“导入 OpenMAIC 课堂导出包”，上传 `.maic.zip` / ZIP，最大5MB。
2. 点击“安全导入待审资源”。只保留文字卡，不执行原包脚本/交互，也不读取原包自报评分。
3. 在“资源审核”展开安全预览，核对文本、来源和适用条件，填写依据并发布。
4. 学生在主题页或练习阶段的“当前课程资源”展开查看；诊断/独立检测不开放资源。
5. 管理员的“预约 OpenMAIC 文本课堂”只有在本机预算已明确授权并初始化后才可运行。当前首轮预算已完成并停止，新增第二门需要后续明确预算。已知课堂可在任务区选择“重新导入已生成文本（不调用模型）”，复用同一课堂读取，不重开预算。

## 6. 外部知识发现

“外部知识发现 → 检索允许来源”需要服务商/范围/预算确认及本机 Tavily 密钥。密钥不在网页或聊天中粘贴，维护者本机执行：

```powershell
.venv/Scripts/python.exe -m app.manage set-search-key
```

之后由管理员启用搜索。只发送标准数学关键词；结果最多五条，标记为发现资料。管理员确认授权并登记正文后，学生新建的课程准备才会使用，不能自动将搜索网页当教材。

## 7. 常见问题

| 提示/现象 | 处理 |
|---|---|
| 主题需澄清 | 一次聚焦一个已支持单元；证明、中位数等不会自动替换成另一类计算 |
| 内容未开放/真实学生不可用 | 管理员核对开发发布与账号来源；不要通过改标签假装取得试点授权 |
| 排队持续不变 | 检查 4003 API、teaching worker、models worker 是否都运行；不要刷新后重复付费请求 |
| 课程失败 | 看校验原因；明确内容失败可申请一次修复，原尝试/用量保留 |
| 上游结果未知 | 不自动重试；核对状态和服务商记录，未知费用不计零 |
| 课程已绑定但活动不能开始 | 先结束同空间仍在进行的陪学/其他活动，核对来源与审核是否撤回 |
| 检测时看不到资源 | 这是独立检测隔离，完成后再看；已见过的题按重复曝光记录 |
| OpenMAIC 已启动却不能预约 | 独立预算尚未开放或已停止；服务健康不代表总预算获准 |

部署与预算详见 [92 号文档](../调研/92-外部检索与OpenMAIC本机配置.md)，实现及限制见 [90 号文档](../架构/90-G02G05主题课程与资源实现边界.md)。
