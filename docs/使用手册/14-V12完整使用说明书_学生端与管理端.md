## 1. 从哪里进入，第一次怎么体验

| 入口 | 地址 | 身份 |
|---|---|---|
| 学生端 | [打开学生端](http://127.0.0.1:4003/student/) | 管理员创建的学生账号 |
| 管理端 | [打开管理端](http://127.0.0.1:4003/admin/) | 本机初始化的管理员 |
| 接口文档 | [API 文档](http://127.0.0.1:4003/docs) | 开发排查使用 |
| OpenMAIC 独立服务 | `http://127.0.0.1:4004` | 资源维护使用，不是学生学习入口 |

两个端是独立页面；用对应身份登录。学生密码至少 6 个字符，忘记密码联系管理员。切换浏览器标签页不应退出；会话过期、主动退出或浏览器删除站点数据后需重新登录。

**建议首次路线**：管理员核对并开放一个开发单元 → 创建学生账号 → 学生新建正式项目 → 明确绑定课程 → 确认学习计划 → 陪学 → 圆桌/我教 AI → 复习和成长证据 → 提出策略。想体验自动课程，再按第4节完成生成与双端审核。

当前仅模拟/成人开发测试；真实学生账号不自动开放开发内容。DeepSeek 是真实付费调用，Fake 是不出网的模拟调用。数值通过不等于解释/教学效果通过。

## 2. 管理员先准备

### 2.1 学生账号

打开“学生账号”，创建账号，填写显示名称、登录名和至少 6 字符密码。通过相应操作可重置密码或管理账号状态。不要通过修改数据来源标签绕过真实学生限制；演示账号使用模拟或成人开发来源。

### 2.2 知识点与题库

查看单元题面、参考数值、提示、误区和检测任务，核对内容版本并保存开发核对意见，再确认开发用途并启用。陪学包和静态互动包分别审核；开陪学不代表所有互动都开放。

已有七个自编开发单元共35题，覆盖方程、有理数、一次函数求值、勾股计算、等可能概率、概率计数与事件、平均数与频率。它们是开发样例，不代表全学段课程完成。

如需导入动态内容，按[课程绑定与动态内容手册](09-G00G01课程绑定与动态内容操作.md)核对 JSON、版本、题目阶段、来源及核验结果；新内容仍需开发审核。不要直接修改数据库把候选改成已发布。

### 2.3 模型和生成能力

1. “配置与权限 → 模型与运行配置”查看服务、提示版本、密钥是否就绪和额度。
2. 选择 DeepSeek 或 Fake。v3 是提示策略候选名称，不表示页面可自由选择任意模型型号。
3. 核对开发确认后发布；学生端不配置密钥、不自行切换服务商。
4. 每日次数 **0 表示不限次数，不是免费**；单次输出、课程/活动调用上限与独立资源预算仍分别执行。实际金额以服务商账单为准。
5. “课程生成与资源”另行核对课程生成、通用互动和搜索开关。模型配置发布不等于所有路线自动开放。

密钥由维护者本机交互配置，不粘贴在页面、文档或聊天中；服务端只显示就绪状态。OpenMAIC 首轮预算已经停止，不能因为 DeepSeek 不限次数就再生成一门资源课程。

## 3. 学生的项目、课程和计划

### 今日学习 / 项目与会话

- “今日学习”进入已有项目或新建空间。
- “项目与会话”分学习项目、临时会话、已归档。铅笔是重命名；箱子是归档，悬停有提示。归档保留记录，恢复后可继续。
- 左侧“当前工作空间”控制陪学、复习、讨论、证据和规划的归属；进入功能前先核对空间。
- 正式项目用于持续学习，临时空间用于短期探索，不自动进入全局正式项目画像。归档空间只读。

### 课程绑定 / 数学单元

项目名称是自由命名，系统不会因“有理数”三个字就猜定课程。通过顶部课程栏或“数学单元”选择已开放课程并确认，或通过第4节生成并确认课程。之后同项目的陪学、圆桌和我教 AI 沿用课程上下文。

若某旧静态课程没有对应互动包，页面会说明缺失；不要为继续操作选另一个无关单元。需要通用互动时使用已审核的生成课程。课程/版本变化后旧运行保留原课程，新任务使用新绑定。

### 学习计划

填写本项目目标与每日时间，提交后等待草案，阅读并确认，也可以调整或取消。正式项目按页面关口完成计划后开始；临时空间按可用路线短期探索。固定计划草案不是整套模型生成课程，也不是“规划与策略”的策略版本。

## 4. 从自由主题生成课程

1. 选择自己的空间，进入“主题与课程”。输入具体主题，例如“有理数混合运算”。
2. 点击“解析主题并准备诊断”。检查范围、来源，完成两道诊断并写依据；材料已展示，因此这不是严格的无辅助效果测验。
3. 必要时调整本轮重点，确认范围后生成。生成进入队列，刷新不会自动重发。
4. 独立数值和条件核验通过后，等待管理员审核；未经审核的完整候选不直接给学生当课程。
5. 管理员进入“课程生成与资源 → 项目课程候选”，核对完整内容、来源、检测隔离及报告，填写至少十字依据并发布开发版本；不合适则退回。
6. 学生刷新，点击“确认使用这份课程”。随后进入陪学/圆桌/我教 AI，核对顶部课程版本。

支持六类开发题族：有理数混合计算、一次方程、一次函数求值、勾股数值、等可能概率、平均数。含糊、证明类及未支持主题会澄清/拒绝，不会强行换成相似计算题。

明确内容核验失败的候选可按页面申请一次修复；上游未知结果不能盲目重发，原请求和用量仍保留。详见[主题课程专项手册](10-主题自动课程与资源操作.md)。

## 5. 三种学习活动怎么用

同一空间依次进行活动；先完成/结束当前任务，再开始另一条路线。

### 津津陪学

1. 核对空间、课程、计划与开放状态，开始新任务。
2. 按页面进行诊断和练习；分别填写数值答案与解释，数值栏按题目格式填写，不把长篇说明塞进数值栏。
3. 不会时逐级请求帮助。生成课程如采用渐撤策略，会先邀请自问，仍可继续请求具体支持。
4. 提交反思，进入检测。检测阶段没有模型帮助或资源；保持独立作答。
5. 查看结果：数值通过、数值错误、无法验证分别处理。保存过程后到成长证据查看来源。

模型选择提问方向，当前界面仍使用受控表达，不保证开放式解释语义已经判定。概率专用多轮与生成课程的通用路线有不同轮数/内容规则，以页面提示为准。

### 圆桌讨论

先写自己的答案与依据，再阅读不同视角，比较前提、表示和核验方法，提交自己的判断/修正，最后做验证题。同一模型的三种视角不是三位独立专家，不能按多数意见直接判真。

### 我教 AI

先给自己的解答和讲解，按页面选择已开放的模型追问，阅读问题后补充或修正。通用活动最多三轮，随后进入另一题的独立数值验证。不能用“我说了很多字”推断讲解质量达标；目前没有自动专业解释评分。

同题曾被展示，即使未提交，也不能再次计为新鲜独立检测；平台外曝光无法自动识别。模型异常时查看状态和原因，不通过新建任务来无条件重复付费请求。

## 6. 错题、复习与记忆

“错题与复习”查看复习安排、不可验证/复核与学习记忆。打开来源可核对原始答案、提示使用和时间；追加自己的说明不会覆盖原事实。

选择到期任务进行无提示原题复做。默认1/3/7天是开发规则；提前复做单独记录，不推进到期间隔。错题优先策略只调整顺序，不修改间隔。原题通过不是未见题迁移，也不自动证明掌握。

无法验证的答案可进入管理端复核；人工数值意见与自动结果分开存储。全局记忆仅汇集本人正式项目；局部记忆保留当前空间上下文。

## 7. 成长证据图形怎么看

1. 切换“全局宏观”或“当前空间局部”，选择14/30/90天、来源以及是否包含归档。全局不混入临时空间。
2. **知识点地图**：查看六个开发 KC 的实际记录、不同题数和版本。没有记录不等于不会，有记录也不等于整单元掌握。
3. **学习表现**：区分诊断、练习有无提示、首次/已见/未知曝光检测、提前/到期原题复做；条形是次数及数值通过，不是统一能力分。
4. **支架时间线**：查看逐级支持、自问和恢复帮助。旧数据没有状态则显示未记录，不补猜。
5. **数学素养**：六方向条形为候选材料数量，均未评定；材料可重复归入不同方向，不可以相加成素养总分。
6. 点击图形或记录“查看原始来源”，核对答案、依据与自述。补充自述保留为新信息，不改原提交。
7. 查看供规划使用的本机冻结摘要，正式项目可进入“规划与策略”。本机摘要不会因此自动扩大外部模型发送范围。

详细图形口径见[成长证据手册](11-成长证据与学情观察操作.md)。

## 8. 规划与策略：怎样影响下一次学习

1. 管理员先在“策略评审 → 课程资料”登记并发布允许使用的参考资料；录入网址不代表自动理解网页正文。
2. 学生在正式项目填写体验、每日时长和反思重点，选择1–5份参考资料。可用固定候选或已开放的模型候选。
3. 需要实际执行变化时勾选四项执行策略：练习顺序、复习顺序、生成课程支持方式、通用追问重点。当前真实规划模型只建议时长/反思，四项由此路径手动提出。
4. 提交后检查冻结来源、学情摘要、参数差异、Skill 和指纹。此时尚未生效。
5. 管理员在“策略评审”填写依据通过；学生回到提案核对后确认激活，也可不采纳。
6. 下一次新任务查看“本任务冻结的执行策略”。已有任务保持开始时版本。需恢复时在激活历史选择有效旧版本或默认基线，填写理由回滚。

Skill.md 可导出阅读，是白名单配置的可读形式，不是上传任意代码执行的入口。来源、课程或事实变化使提案过期时，刷新并基于新依据重建。详见[策略专项手册](12-执行策略与Skill版本操作.md)。

## 9. Skill 离线改进：怎样走完整审核

前提：模拟/成人开发账号、正式项目、已确认课程、有效的四参数策略基线及本项目实际操作证据。临时会话不适用。

1. 学生进入“Skill 离线改进”，点击“生成离线改进候选”，等待教学 worker。
2. 阅读假设、单参数原值→新值、来源和冻结机制评测。系统根据数值错误、求助和人工数值纠正提出规则候选，不理解长篇正文。
3. 管理员进入“Skill 进化评测”，核对父版本、diff、来源、新旧实际机制报告及限制；填写至少十字依据，通过或拒绝。
4. 通过后学生刷新，填写理由，采纳为**普通待审策略**。
5. 再走第8节的管理员策略审核、学生确认。改进评测通过本身不改变当前策略。
6. 管理员可撤回评测复核；已关联版本后续新任务可能回到默认配置，历史指针和原记录保留。

没有候选通常是来源不足或相应参数已采用；不代表系统故障，不要伪造记录来点亮按钮。课程、基线、来源、语料或消费者代码改变后旧评测失效。四个自编样本证明工程机制，不证明学习收益；自动真实 RSI 未开放。详见[离线改进手册](13-Skill离线改进与评测操作.md)。

## 11. OpenMAIC 资源与外部检索

资源导入：在管理端目标课程上传 `.maic.zip`/ZIP（最大5MB）→安全导入→预览文本→填写依据并发布。只保留允许的文本卡，不执行原包脚本或采用原包自报评分。学生在课程页/练习阶段查看资源，诊断与检测阶段隐藏。

管理端可在课程卡片点击“查看本课程资源审核”筛选对应资源，资源列表单独翻页。OpenMAIC预算状态显示在页面顶部和任务区；未配置、停止、耗尽、已关联其他课程或已有任务时，预约按钮禁用并说明原因。学生端只展示已可用资源，空态不会把“待审核/已撤回”误报成“未生成”。

已有独立 OpenMAIC v1.2.0 服务4004，一门三场景真实文本课堂已验收；图片/音频/视频未开放。当前预算停止，新增课堂须另行确认预算。可重新导入已知生成课堂的文本，此操作不重新生成模型内容。

Tavily 仅发送标准数学关键词，限定 `moe.gov.cn`、`pep.com.cn`、`zxx.edu.cn`；每主题最多2次、全站每天20次、每次最多5条，不自动升级搜索或重试。管理员确认授权并登记正文后，后续课程准备才能引用；填入网址不会自动抓取教材。

## 12. 启动与维护（维护者）

已启动的系统不必重复开进程。首次依赖安装、初始化详见根目录 README。日常先启动 Docker Desktop，进入仓库：

```powershell
Set-Location 'C:\Users\21709\Desktop\桂子问津\EduAgent'
uv run --locked python scripts/dev_postgres.py
uv run --locked python -m app.manage --env-file .local/database.env migrate
uv run --locked python -m app.main --env-file .local/database.env
```

有现存运行任务时先完成升级备份/停服安排，不对运行中的系统盲目迁移。首次或前端源码更新后在启动前构建：

```powershell
Set-Location 'C:\Users\21709\Desktop\桂子问津\EduAgent\frontend'
npm ci
npm run build
```

两个另外的 PowerShell 终端分别运行：

```powershell
# 终端二，在仓库根目录
uv run --locked python -m app.worker --env-file .local/database.env --lane teaching
```

```powershell
# 终端三，在仓库根目录
uv run --locked python -m app.worker --env-file .local/database.env --lane models
```

也可用默认 combined 单 worker，但不要无意同时启动重复的整套预览进程。只开 API 未开 worker 时，已保存任务会排队。首次管理员初始化使用 `app.manage ... bootstrap-admin --username <登录名>`，密码隐藏输入；已有管理员不要重复初始化。数据和密钥位于忽略的本机目录，不随 Git 分支推送。

OpenMAIC 维护遵循[独立部署说明](../调研/92-外部检索与OpenMAIC本机配置.md)，不随日常启动自动重建或重开资源预算。

## 13. 常见问题与处理顺序

| 现象 | 先检查 |
|---|---|
| 登录成功但无项目 | 是否用的是自己账号；先创建正式项目 |
| 项目叫有理数但内容不匹配 | 显式课程绑定和版本；改名称不会自动改课程 |
| 开始按钮不可用 | 账号来源、内容/互动审核、课程确认、计划关口、同空间活动是否已结束 |
| 任务一直排队 | API 和 teaching/models worker 是否运行，运行记录是否显示失败 |
| 刷新后状态冲突 | 刷新两端状态，重新核对修订；不要重复批准旧提案 |
| 模型未知/超时/取消 | 看任务与账本，不自动重试；已发送调用可能产生费用 |
| 成长证据空白 | 空间、全局/局部、日期、来源和归档过滤；临时空间不会进全局 |
| 素养没有分数 | 尚无正式量规，材料数量不是能力分 |
| 策略通过却未生效 | 还需学生确认；检查是新任务还是沿用旧运行；来源是否撤回 |
| Skill 没有候选 | 四参数基线、课程、同版本有效证据是否齐备，目标参数是否已经采用 |
| OpenMAIC 健康却不能预约 | 独立预算已停止；不通过换账号绕过 |
