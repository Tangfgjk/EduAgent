## 一、入口与基本概念

| 入口 | 地址 | 谁使用 |
|---|---|---|
| 学生端 | [打开学生端](http://127.0.0.1:4003/student/) | 学生角色账号；当前真实模型只开放模拟/成人开发用途 |
| 管理端 | [打开管理端](http://127.0.0.1:4003/admin/) | 管理员；建号、开放内容、复核与模型配置 |

两个页面分别登录，可以在同一浏览器打开两个标签页。退出管理端不会主动退出学生端。请使用已经设置的账号密码；本手册不包含密码或模型密钥。

### 1. 项目和临时会话有什么区别

| 事项 | 正式学习项目 | 临时会话 |
|---|---|---|
| 用途 | 围绕目标持续学习、积累证据 | 一次短体验或零散探索 |
| 开始陪学前 | 先确认学习计划，并处理完待确认计划 | 可以直接开始 |
| 陪学、圆桌、我教 AI、局部复习 | 支持 | 支持 |
| 全局记忆与成长证据 | 纳入，包括归档后的历史 | 排除，只看本空间局部 |
| 规划与策略 | 支持 | 不支持 |
| 归档 | 保留历史，停止新输入，可恢复 | 同左 |

“临时会话”目前也是受限的学习空间，不是可以随意询问任何话题的通用聊天窗口。不同空间的数据不会自动合并。

### 2. 计划、策略、模型是三件不同的事

- **学习计划**：你提出目标、选择时间并确认。当前草案是固定开发模板。
- **规划与策略**：结合体验、学习记录与资料提出调整候选，目前只调整每日建议时长和反思重点；可选真实模型，需要管理员审核和你再次确认。
- **模型配置**：管理员统一决定 DeepSeek/Fake、追问版本和次数。学生不能自行切换服务商或填写密钥。

页面“v3 候选版”指概率追问提示版本 `probability.followup.v3`，不是厂商模型型号的名称；实际请求型号看管理端“当前型号”。

### 3. 当前哪些功能真的用了模型

| 功能 | 什么时候会调用 |
|---|---|
| 概率陪学追问 | 原“等可能事件概率”单元的练习阶段，主动提交思路并请求追问 |
| 概率我教 AI 新流程 | 明确选择模型追问；每活动最多 3 次请求 |
| 概率圆桌新流程 | 明确选择模型三视角；每活动最多 1 次请求 |
| 有来源规划 | 正式项目中勾选模型生成候选后提交 |
| 学习计划、旧互动包、其他陪学单元 | 当前主要使用固定流程/文本，不能因全局开放 DeepSeek 就视为全部智能化 |
| 阅读记忆、证据、冻结评测报告 | 不调用模型 |

模型生成内容仍待核验，程序数值验证与模型分开。当前发现自由追问可能用中文夹带答案，门禁尚待修复；圆桌也存在无依据分歧等已知语义问题。体验时可以反对或跳过模型意见，请勿将它们当成教师结论，当前不用于真实学生教学。

## 二、首次使用：管理员准备

学生端开始按钮不能点时，通常先检查这里。

### 1. 创建学生账号

1. 登录管理端，点击左侧 **学生账号**。
2. 点击 **创建学生账号**。
3. 填写学生姓名、学生账号、初始密码；学生密码至少 6 个字符。
4. 点击 **保存学生账号**。
5. 将账号与初始密码交给体验者，在学生端登录。管理员账号不能代替学生账号进入学生学习流程。

账号的开发数据来源由运行环境决定，页面不能把账号随意切换成真实学生以绕过模型范围限制。

### 2. 启用要体验的基础内容

进入 **知识点与题库**。当前共有 7 个自编开发单元，每个 5 题，合计 35 题：

| 单元 | 适合体验 |
|---|---|
| 一元一次方程与应用 · 开发单元 | 数值输入、等式思路、分级提示 |
| 有理数运算 · 开发单元 | 正负数和简单运算 |
| 一次函数求值 · 开发单元 | 给定模型代入求值 |
| 勾股定理计算 · 开发单元 | 直角三角形整值边长计算 |
| 等可能事件概率 · 开发单元 | 真实模型概率追问、互动基础 |
| 概率计数与事件 · 扩展开发单元 | 更多开发概率任务 |
| 平均数与频率 · 扩展开发单元 | 统计数值任务 |

原方程包在顶部独立卡片，其余在 **跨领域开发内容包**。可按年级/领域查找，点击 **核对＋单元名称** 查看题面、参考数值、分级提示、误区和检测题。

若窗口出现 **开发内容核对记录**：先选择 **开发核对通过** 或 **需要修改**，填写具体依据（至少 5 字），点击 **保存复核记录**。通过不会自动启用，还需勾选开发用途确认，再点 **启用此内容包**。原方程卡片的开放按钮为 **启用开发测试**。

只在确实核对后填写“通过”，不要为点亮按钮随意写审核意见。开发核对不等于专业数学教师审核。以后若发现问题，可停用内容；有复核记录的版本新增“需要修改”意见会撤回该版本。

### 3. 启用圆桌与我教 AI

互动包和基础陪学包分别管理。在同一页面找到 **圆桌与我教 AI · 互动模板审核** 或 **新增单元互动审核**。

| 互动包 | 学生端用途 | 是否为新模型路线 |
|---|---|---|
| 方程圆桌与我教 AI · 开发活动 | 方程两条互动 | 固定模板 |
| 概率圆桌与我教 AI · 开发活动 | 概率旧版两条互动 | 固定模板 |
| 概率我教 AI · 讲解与新题验证 | 我教 AI 新版 | 可选模型，最多 3 次追问 |
| 概率圆桌 · 三种视角与新题验证 | 圆桌新版 | 可选模型，一次生成三视角 |

体验新版概率路线时，先开放基础 **等可能事件概率 · 开发单元**，再分别核对、启用目标互动包。新版有开发核对表时，先保存核对记录，再勾选确认、点击 **启用此互动包**。

仅开放旧概率互动，不能自动开放两个新版包。学生页会按当前空间最近一次实际陪学匹配互动，优先已启用的新流程，再选已启用的旧流程；缺少对应包会明确提示，不自动换成概率。尚无陪学记录时，首次请明确选择互动单元。

### 4. 开放模型

进入 **配置与权限 → 模型与运行配置**：

1. 先阅读“当前型号”“当前追问模式”“DeepSeek 本机密钥”和已发布配置。已经开放且符合用途时，无需重复发布。
2. 需要更改时，“开发服务”选 **DeepSeek · 真实开发模型**；选 Fake 只验证流程，不会得到真实模型理解。
3. “追问模式”可选 **同题最多 4 轮 · v3 候选版**。
4. 单次输出上限当前最多 512 tokens；两项每日次数填 `0` 表示开发不限次数，不表示免费，仍记录预约和用量。
5. 核对开发用途、外发范围和额度后，勾选确认，点击 **发布开发模型配置**。

密钥不在浏览器填写。如果显示未配置，请检查本机凭据和服务读取权限，不要在聊天或文档中粘贴密钥。需要暂停时点击 **停用模型追问**；旧在途结果也会受停用门禁约束。

**此设置同时控制陪学、我教 AI、圆桌和模型规划。页面当前的范围说明尚未完整更新，应结合本手册的各路线说明核对。** 发布新配置会让后续追问重新收集相同配置的历史；未必取消已经冻结旧配置的任务，若要阻断旧结果应使用停用。

## 三、学生第一轮体验

推荐先用一个临时空间熟悉交互，再建正式项目体验规划。

1. 学生登录后进入 **项目与会话 → 新建临时会话**，名称填写“概率功能体验”，保存。
2. 核对左侧 **当前工作空间** 和页面顶部名称。
3. 进入 **津津陪学**，选择 **等可能事件概率 · 开发单元**，点击 **开始开发单元**。
4. 完成诊断；在练习阶段先尝试，再使用提示或模型追问；保存反思；完成两道独立检测，查看小结。
5. 完成或结束陪学，再进入 **我教 AI**，选择新版“讲解与新题验证”，按第四部分操作。
6. 完成我教 AI，再进入 **圆桌讨论**，选择新版“三种视角与新题验证”。
7. 进入 **成长证据 → 当前空间局部**、**错题与复习 → 学习记忆** 回看自己的过程。

不必为了产生错题或复习记录故意答错。临时记录不出现在“全局宏观”是正常现象。

正式项目体验：新建学习项目 → 确认学习计划 → 完成一次陪学 → 查看全局与局部证据 → 结束活跃学习流程 → 提交规划候选 → 管理员审核 → 学生确认。课程资料的准备见管理端说明。

## 四、学生端逐项说明

### 1. 今日学习

用于看空间概览、进入项目和跳转学习路线。这里显示的空间属于当前登录账号。它还不是自动生成个性化每日课表的推荐中心。

点击项目卡片 **进入项目**，再核对当前空间。也可通过左侧下拉框切换已有空间。手机先点击左上角 **打开导航**。

### 2. 项目与会话

- **新建学习项目 / 新建临时会话**：输入空间名称，点击 **保存空间**。
- **重命名**：点击对应卡片的重命名图标，修改名称并保存。
- **归档**：点击归档图标，核对名称后确认；历史保留，新作答和说明停止。
- **恢复**：切到“已归档”，找到空间，点击 **恢复 → 确认恢复**。
- **切换**：使用左侧“当前工作空间”；不同空间不会自动同步题目、讨论或计划。

目前没有删除空间或把临时记录一键合入正式项目的功能。

### 3. 数学单元

按年级/领域查看已有开发单元与启用状态，选择适合的内容，再进入陪学。“查看与学习”会携带所选单元；普通导航回陪学时，默认沿用当前空间最近一次学习单元。空间名称只是标题，不用于猜测课程。

七个单元是代表样例，不等于完整七至九年级课程；函数图像、几何证明和复杂表达式还不能按完整学科系统使用。

### 4. 学习计划

只在正式项目中使用：

1. 在 **这次想学会什么？** 填写目标，例如“说明等可能概率中分子、分母的计数依据”。
2. 选择 **每天愿意投入几分钟？**，点击 **生成计划草案**。
3. 等待“等待你确认”，阅读草案。调整时间后先点 **更新草案**，阅读更新结果，再确认；也可点 **取消这次流程**。
4. 确认后点击 **我确认这份计划**，看到“计划已确认”再去陪学。
5. 可在“最近的计划流程”回看，并展开流程事件查看保存/确认过程。

项目存在待处理或待确认计划时，先完成或取消。当前草案是固定模板，不会根据目标自动生成全套题目；要自己核对实际选择的单元。

有已激活策略时，可以主动点击 **采用当前策略建议**，再生成/确认计划。策略不会自动改写已确认的计划。

### 5. 津津陪学：诊断、练习、反思、检测

一个基础单元当前为：1 道诊断、2 道练习、2 道独立检测。

| 阶段 | 操作 | 接下来怎么做 |
|---|---|---|
| 诊断 | 填“我的数值答案”，步骤放“我的步骤与依据（可选）”，点“检查我的解答” | 阅读反馈，按页面点“继续下一步”；诊断不开放提示 |
| 练习 | 先自己尝试；未通过时可修改后再次提交 | 需要帮助时使用提示；通过后反思 |
| 分级提示 | 点“给我一点提示”，之后“再给我一级提示” | 依次 L0 轻推、L1 方向、L2 部分步骤、L3 完整对照，按页面条件放行 |
| 反思 | 写下本步依据、检查方法或下次提醒 | 点“保存反思并继续”；卡住时可在按钮出现后“记录为未完成并反思” |
| 独立检测 | 不提供提示，独立提交结果与依据 | 每题提交后不能改写；按按钮继续，最后“查看学习小结” |
| 小结与历史 | 看结果、尝试、提示和反思，展开学习回顾/流程记录 | 可回看当时保存的输入和已开放提示，不能回填成新的结果 |

数值框支持有界数值、分数和四则运算，如 `0.25`、`1/4`、`(2+3)/4`；这些只是格式示例。方程题可按要求写 `x=数值`。单位、解释、证明写进步骤框。不可验证会进入复核，不等于答错或通过。

当前程序主要验证有理数结果，不自动检查全部推导、定义域、单位或证明。数值通过不代表已经掌握。

中途可点击 **结束这次陪学**；刷新可以恢复已保存过程。显示“输入已保存，等待教学处理”时不要反复新建；先用 **刷新处理状态** 核对。

### 6. 概率陪学中的真实模型追问

使用原“等可能事件概率”基础包，在**练习阶段**找到模型追问区：

1. 在 **我想让 AI 帮我澄清的思路** 中写当前疑惑，例如“我不确定这里应该按颜色还是按每个球计数”。
2. 点击 **提交思路并请求追问**，等待状态更新。
3. 阅读引用和追问，再回到自己的解题，不需要把模型问题当成正确答案。
4. 有下一次开放机会时可继续表达；次数受当前提示阶梯与配置限制，并不是无限聊天。
5. 等待期间可 **取消本次模型追问** 或 **刷新追问状态**。失败时使用已有预设提示继续。

v3 模式每次最多读取本轮和最近 3 轮同题、同空间、同配置的成功交流；不读取其他项目。诊断和独立检测不开放模型。其他概率扩展包也不会仅因名称含“概率”自动获得此功能。

### 7. 我教 AI：最多三次追问

先完成或结束当前空间的陪学/其他互动。选择 **概率我教 AI · 讲解与新题验证**：

1. 点击 **开始我教 AI**。
2. 填 **我的数值表达** 和 **我的讲解**。先把自己的依据写出来。
3. 要用真实模型，勾选 **让 AI 根据本次讲解提出一个问题**，点 **保存表达，邀请学伴**；不勾选使用预设互动。
4. 阅读学伴问题，在 **我的比较、纠错与检查依据** 中回应，更新候选数值。
5. 想再讨论，点 **保存回应，继续追问**；想结束追问，点 **保存修正，进入新题验证**。
6. 最多 3 次模型请求，包含第一次、失败和取消；刷新不重置次数。一次还没结束，不能同时请求下一次。
7. 另一题验证时，旧追问暂时隐藏，不再提供模型辅助。提交后看 **TeachReport · 讲解记录** 和历史贡献。

后续追问最多附带本活动最近 2 轮成功讲解和问题。可以取消本次追问或结束整个活动；失败不自动重试。继续提交新回应属于新请求，会计次数。

选择方程或旧概率互动包时，流程使用固定误区与模板；不要期待它逐字理解讲解。TeachReport 记录过程和数值结果，不评价讲解质量或素养。

### 8. 圆桌讨论：一份思路、三个视角

选择 **概率圆桌 · 三种视角与新题验证**，先确认该包已单独启用：

1. 点击 **开始圆桌讨论**，填 **我的数值表达**、**我的初步思路**。
2. 勾选 **让 AI 根据本次思路生成三种圆桌视角**，点 **保存表达，邀请学伴**。
3. 分别阅读思路提出者、质疑者、整理者；三席来自同一模型的一次请求，不是三位独立专家。
4. 在 **我的比较、纠错与检查依据** 中写自己的判断，不必迎合模型；填修正数值，点 **保存修正，进入新题验证**。
5. 在另一题中独立提交，最后看 **圆桌讨论小结**、自己的原始贡献和模型状态。

每次活动最多一次模型请求。等待时可 **取消圆桌生成**，失败时可展开 **先使用预设圆桌**；也可以继续自己的修正。新版另一题验证会隐藏旧观点，不再调用模型。

旧互动包没有新版的完整验证阶段，按其页面完成比较与数值核验即可。模型可能提出并不存在的分歧，请核对依据，不把三席一致视为共识证明。

### 9. 错题与复习

这里有三个页签：

| 页签 | 怎么使用 |
|---|---|
| 复习安排 | 切“待复习 / 已安排 / 全部记录”；点击“无提示复做”，填写数值和步骤，再“提交无提示复做” |
| 不可验证与复核 | 看程序无法核验的提交与人工结论；点“查看来源与说明”核对原文 |
| 学习记忆 | 切“当前空间记忆 / 全局正式项目”，阅读摘要和来源；全局不包含临时空间 |

数值未通过、提示后答对等符合规则的记录会进入复习；不可验证先进入复核，不能直接当错题。默认间隔 1/3/7 天，未校准真实学生。提前复做会保存结果，但不推进间隔。

点击 **查看原始尝试 / 查看原始来源**，可看自己的原文、自动核验、当时已开放的提示和人工意见。填写 **补充或纠正说明（学生自述） → 保存我的说明**，补充当时体验或纠正说明；原始结果不会被覆盖。

当前空间处于诊断/独立检测或冲突活动时，部分复习会被阻止；先完成或结束相关流程。归档空间只能查看，恢复后再追加说明或复做。

### 10. 成长证据

1. 选 **全局宏观** 看正式项目汇总，或 **当前空间局部** 看当前项目/临时空间。
2. 选择最近 14/30/90 天和数据来源，必要时点击 **刷新证据**。
3. 看学习事实、作答、提示、反思、检测和互动贡献；数值核验按来源、阶段分开。
4. 在过程趋势里切换指标和来源，点击日期圆点，或展开数据表查看。
5. 下方选择记录类型、翻页，点 **查看原始来源** 回到具体记录。
6. 点击六个素养观察方向，可以查看当前未评定说明。

没有能力评分是当前真实状态：量规未完成审核，六维不能靠互动次数自动赋分。图上的次数曲线也不是能力增长曲线。

成长证据的全局包含归档正式项目；规划给模型的全局摘要只统计活跃正式项目，两者口径不同。互动“另一题验证”保留在互动贡献中，不混入陪学独立检测次数。

### 11. 规划与策略

前提：正式项目、管理员已发布资料；用模型时还需要模型开放，并先完成/结束本项目中的陪学和互动。

**生成提案：**

1. 填 **我的学习体验**，例如“计数能列出来，但说明分子分母依据时容易含糊，希望下次多解释依据”。
2. 选择每日建议时长、反思重点，引用 1–5 份已发布资料。
3. 使用固定候选时不勾模型选项；要用模型则勾 **使用已开放模型生成有来源的候选**，核对范围。
4. 点 **生成开发策略提案**。等待生成后查看候选时长、反思重点与自己的请求基线。
5. 展开引用里的 **核对模型实际读取的片段与来源标识**，核对理由。生成前显示的请求值不是已经生成的模型建议。

**审核与生效：**

1. 管理员去 **策略评审 → 提案评审 → 查看提案与依据**，填写依据，通过或退回。
2. 通过后学生回到该项目，填写 **我的确认或拒绝理由**。
3. 点击 **我确认，激活此策略** 才生效；不接受可点 **暂不采纳**。
4. 时长需要在学习计划中主动采用；反思重点影响后续新陪学，不中途修改旧运行。

**查看和回滚：**

- 展开 **查看 Skill.md 与 Harness 候选** 看可读文本与两个字段，页面提供 Skill.md 下载入口；它不是可任意执行的代码/提示文件。
- 在 **当前学习软策略 → 查看激活历史与回滚** 选择曾激活且仍有效的本项目版本或平台默认，填写理由后回滚。
- 可 **取消此提案**。失败不会覆盖已有生效策略；取消后发新请求会另计次数，不自动重试。
- 审核/确认前新增证据、自述、人工判断、资料变化、全局正式项目计数变化等可能使候选失效；按提示重新生成。确认期限为 7 天。

**模型实际读取：**本次体验最多 1000 字；当前项目同来源最近最多 6 条事实，每条学生文字最多 200 字；最多 3 条关联自述，每条 200 字；最多 5 份资料，每份前 800 字；全局只有同账号活跃正式项目计数。不会发送其他项目原文、临时记录或人工判断原文。系统做有限身份字段/邮箱/手机号脱敏，请仍勿填写个人信息。

### 12. 偏好与账号

可查看当前姓名、账号和身份。忘记密码联系管理员重置。学习偏好、提示节奏、通知/复习提醒目前属于准备项，尚未保存为可用设置；学生端也没有模型密钥或 Provider 切换入口。

## 五、管理端逐项说明

### 1. 试点概览

查看账号速览、内容/复核与策略入口。这不是实时教学效果或全站经营指标面板；不要把首页“已开放”视为真实学生试点已获准。

### 2. 学生账号

创建方法见第二部分。列表支持分页；用对应行操作目标学生：

- **重置密码**：填写至少 6 字符的新密码，确认后旧登录会话失效，学生需用新密码登录。
- **禁用**：核对学生后确认；记录保留，学生旧会话失效。当前没有普通页面重新启用按钮，操作前仔细核对。
- 两个操作都不是删除学生学习记录。

### 3. 知识点与题库

用于查看已有固定内容、核对版本与启停，详见第二部分。当前不是任意题目录入或 AI 自动出题编辑器。

基础陪学包、互动包、模型配置是三道独立准备：开放模型不代替内容审核，开放陪学也不代替互动审核。新版本需重新核对，旧记录保留当时版本。

### 4. 内容与解答复核

1. 打开 **内容与解答复核**，切换待复核/已处理队列。
2. 点击目标解答的复核入口，核对题目、学生原文和参考数值。
3. 选择 **数值正确 / 数值错误 / 仍无法判断**，填写具体依据并保存。
4. 学生随后可在来源页和复核页查看意见。

只对你能判断的范围给出结论。人工意见与原始自动核验分开保存；数值复核不能自动变成解释质量评定或教师金标。

### 5. 运行记录

当前左侧 **运行记录** 仍是功能准备页，不能在这里搜索所有会话或处理全部故障。

目前可用的排查入口：学生陪学内的处理状态/流程记录、各活动历史、**配置与权限** 下的最近 20 次模型任务；更完整的任务/死信工作台待开发。

### 6. 评测工作台

1. 选择 **评测运行**，当前共 17 份冻结报告，包含陪学、我教 AI、多轮、圆桌和规划。
2. 先看是真实开发模型还是 Fake，再看提示版本、失败分母、引用和 token；阅读报告不会发模型请求。
3. 可筛选不符合开发参考的条目，展开运行指标和重复稳定性。
4. 对每条输入阅读模型原文和参考依据，选择结论、填写依据，再点 **保存复核记录**。

| 结论 | 何时选择 |
|---|---|
| 本条开发参考可接受 | 当前输入、输出与参考经你核对可接受 |
| 模型方向或问题待改进 | 针对性、数学前提、泄题、措辞等有问题 |
| 参考方向存在歧义 | 参考本身不足以作唯一标准 |
| 运行失败或结果不可用 | 未产生有效结果，保留失败事实 |

**版本对比**：选择同语料的 v2 报告，在 **右侧对照报告** 选 v3；查看改善、退步、未变化与两侧问题。不同语料、内容版本、型号、模式和路线不能直接比较。

**状态解释**：“仅模拟”只说明工程流程；“评测检查未通过”需要解决问题；“待逐条人工复核”需要补意见；“可作开发候选”也不是正式教学发布。规划 `source_contract` 只表示字段和引用符合规则，不评价建议质量。

复核意见会保留历史；不会自动修提示词、切模型、发布或停用配置。网页没有一键真实复测/任意上传报告入口，重新评测由开发脚本另行执行。

### 7. 策略评审与课程资料

**准备资料：**

1. **策略评审 → 课程资料 → 录入课程资料**。
2. 填资料标题、类别（自编参考/教材/课标/考纲）、版本、来源和参考正文；只录有权使用的材料。
3. 点 **保存资料版本**。再展开正文，核对来源与版本。
4. 勾选 **我已核对来源与正文，理解这仅是开发参考**，点 **发布资料**。保存不等于发布。
5. 修正文时新建版本；旧正文不能直接覆盖。需要撤回时勾选确认后 **停用资料**，相关策略的可用性会重新检查。

可用于功能体验的自编资料示例：标题“概率计数开发参考”、类别“自编开发参考”、版本“dev-1”、来源“团队自编测试材料”、正文“以等可能的基本结果为计数单位，分别说明总结果数与满足事件条件的结果数，并保留检查依据。”这是开发材料，不冒充课标原文或专业金标。

**审核学生提案：**

1. 切 **提案评审**，点 **查看提案与依据**。
2. 核对项目、自述、学习事实、引用资料、模型实际片段与候选的两个字段。
3. 填 **评审依据**。不合适点 **退回提案**；可交学生决定时点 **审核通过，交学生确认**。
4. 审核通过不会自动激活，学生还需确认。资料/证据/基线变化或过期时，按提示退回或重新生成，不强行沿用旧候选。

### 8. 配置与权限

模型发布方法见第二部分。还可以查看今日已预约次数、已知输入/输出 tokens、缺失用量和费用未知次数，以及最近 20 次模型任务。

| 任务状态 | 你应如何处理 |
|---|---|
| 等待教学步骤 / 等待调用 | 先等 worker 处理，不重复点击 |
| 模型处理中 | 可由学生取消；取消不保证远端停止计费 |
| 已保存建议 | 回到对应学习/规划页面查看并核验 |
| 失败 | 继续预设路线或收尾提案；不会自动重试 |
| 过期结果已拦截 | 内容、步骤、权限或配置已变化，旧结果不生效 |
| 结果未知 | 不自动重发，费用可能未知，先核对服务状态 |

这里的 tokens 与调用次数不是人民币账单。0 为不限次仍会产生费用；开发不限次配置不应未经确认直接沿用到真实试点。审核职责细分、版本审核规则等显示“准备中”的项暂不能操作。

## 六、常见问题与处理

| 现象 | 处理方法 |
|---|---|
| 无法打开两个入口 | 先检查 API、Docker/数据库是否运行，见第七部分 |
| 登录学生端提示身份不符 | 使用管理员创建的学生账号；不要用管理员账号 |
| 开始按钮禁用 | 检查对应互动包是否已开发、选中包是否启用、空间是否归档；有理数目前只有陪学包，没有圆桌/我教 AI 包 |
| 已启用概率但新版互动不能用 | 基础包、旧互动、新我教 AI、新圆桌分别审核启用 |
| 正式项目要求先确认计划 | 去学习计划生成并确认；待处理计划先确认或取消 |
| learning_busy / 要求结束当前活动 | 完成或结束当前项目里的陪学、圆桌或我教 AI，再切路线；别为绕过检测另开辅助流程 |
| 始终等待处理 | 刷新状态；持续不变检查 teaching worker、models worker 和数据库；不要不断新建同样任务 |
| 没有模型按钮 | 核对具体单元、当前阶段、模型开放/额度和账号开发范围；不是所有页面都支持模型 |
| 模型失败或输出被拒绝 | 可使用预设提示/观点继续；规划可取消后重新选择固定候选，不会自动覆盖旧策略 |
| 我教 AI 不能再追问 | 可能已请求 3 次，失败/取消也计入；保存修正进入另一题验证即可 |
| 提示或旧观点在验证阶段消失 | 新题无辅助阶段的正常行为，提交后报告恢复历史 |
| 全局证据没有刚才的记录 | 若使用临时空间，查看“当前空间局部”；同时检查时间和来源筛选 |
| 六维雷达没有分数 | 尚未评定，不是故障；不能将过程次数换算为能力 |
| 复习列表为空 | 切“全部记录”核对，尚无符合条件来源时正常为空 |
| 策略没有激活 | 检查是否管理员已通过、学生是否再次确认；生成完成不代表生效 |
| 提案显示来源更新或过期 | 检查新增学习、自述、归档/新项目、资料发布等变化；取消/退回后重新生成 |
| Skill 下载提示未登录/401 | 当前下载为直接链接；分端会话下可能遇到认证问题。先复制页面已展示的 Skill 文本保存，保留错误供修复，勿修改浏览器 Cookie 绕过认证 |
| 忘记密码、账号禁用 | 联系管理员；重置密码后用新密码登录；禁用恢复暂非普通页面功能 |
| 切其他网页回来被要求登录 | 正常切换应保持登录；若退出、到期、密码重置/禁用会失效。持续异常请记录地址、时间和操作顺序 |

遇到异常，保留：发生时间、学生端/管理端、当前空间、所选单元、操作步骤、页面错误码或请求 ID。不要记录密码、密钥或不必要的个人原文。

## 七、本机启动与日常顺序

页面能正常打开时无需重复启动。以下仅适用于**已有依赖、已迁移数据库和现有本机配置**，不要为启动而重建/清空数据库。

1. 打开 Docker Desktop，确认项目 PostgreSQL 容器运行。
2. 在仓库根目录打开三个独立 PowerShell 终端，分别运行：

```powershell
# 三个终端都先切到仓库根目录
Set-Location 'C:\Users\21709\Desktop\桂子问津\EduAgent'

# 终端一：API
.venv/Scripts/python.exe -m app.main --env-file .local/database.env
```

```powershell
# 终端二：教学 worker
Set-Location 'C:\Users\21709\Desktop\桂子问津\EduAgent'
.venv/Scripts/python.exe -m app.worker --env-file .local/database.env --lane teaching
```

```powershell
# 终端三：模型 worker
Set-Location 'C:\Users\21709\Desktop\桂子问津\EduAgent'
.venv/Scripts/python.exe -m app.worker --env-file .local/database.env --lane models
```

3. 打开学生端和管理端。源码更新过前端而页面未更新时，开发者需在仓库根运行 `npm run build --prefix frontend`。
4. 结束本机服务时，在这三个终端分别按 Ctrl+C；下次启动可恢复已保存记录。正在真实生成时取消本机等待不保证服务商停止计费，不要将重启当成免费重试。

日常使用顺序：**管理员确认内容和模型 → 学生选空间 → 正式项目确认计划 → 学习/反思/检测 → 复习与证据 → 规划候选 → 管理审核 → 学生确认**。

完整能力和问题清单见 [V10 系统评估](../进度/83-V10系统完成情况与设计对照评估.md)。专项细节可查 [三轮我教 AI](05-我教AI三轮讲解与独立验证.md)、[真实圆桌](06-真实圆桌三视角与新题验证.md)、[有来源规划](07-有来源模型规划与策略确认.md)。
