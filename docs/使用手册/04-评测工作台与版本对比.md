# 评测工作台与版本对比

适用范围：2026-10-17 的 V09 开发增补。管理员进入「评测工作台」，本机地址为 http://127.0.0.1:8000/admin/evaluations 。

## 1. 选择报告

「评测运行」列出 11 份冻结报告，包含历史单轮、多轮 v2/v3、回归对照，以及最新的「我教 AI」Fake/DeepSeek 专项。阅读报告不产生模型调用。

默认展示真实「我教 AI」专项：12 条主样本加 6 次预定重复，18 次尝试中 16 次返回可用问题，2 次未通过输出校验。失败保留在总数中。勾选「仅显示不符合开发参考的条目」可定位 T04、T05。

「查看运行指标与重复稳定性」区分主样本和全部尝试。方向匹配表示输出方向符合自编参考，不表示数学措辞正确或教学有效。重复方向相同也不表示问题语义相同。已知 tokens 是用量，不能直接作为费用；用量不完整也不能视为免费。

## 2. 对比提示版本

选择「多轮 v2 · 真实基线」，在「右侧对照报告」选择 v3，即可查看方向匹配的改善、退步和左右追问。本次冻结运行的结果为改善 3、退步 0、未变化 15；这是同一组开发样本的单次对照，不代表统计显著或泛化效果。

页面只提供同语料、型号、模式和路线的候选，服务端还核对内容版本、样本集合、输入及参考。不同语料、Fake 与真实模型不能直接比较。取消「只看方向匹配状态变化」可阅读全部对照；展开指标可比较耗时和 tokens。

## 3. 逐条复核

阅读自编输入、候选数值、引用、追问和自动检查结果后，选择结论并填写具体依据：

- 本条开发参考可接受：当前样本的输出及参考经开发人员核对可接受。
- 模型方向或问题待改进：方向不适合，或问题存在数学前提、针对性、泄露答案、措辞等问题。
- 参考方向存在歧义：应先修订参考定义，不能仅据此判断模型错误。
- 运行失败或结果不可用：没有有效问题，例如 T04、T05；保留失败事实。

「我教 AI」按页面列出的六个维度核对：数学前提、针对讲解、避免泄露答案、避免评分、单一清楚且适龄、含糊输入与注入处理。数字答案继续独立验证，模型问题不用于自动判分。

保存后刷新仍可查看历史意见；新意见保留旧版本，并绑定报告哈希与具体尝试。重复样本也需要分别复核。正式预览库未自动填入复核结论，浏览器验收的意见只存在于隔离测试库。

## 4. 理解检查状态

| 状态 | 含义 |
|---|---|
| 仅模拟 | 只能证明工程流程运行，不能作为真实模型准入证据 |
| 评测检查未通过 | 存在工程失败、参考不匹配或人工复核问题 |
| 待逐条人工复核 | 自动检查通过，但仍有样本尚未复核 |
| 可作开发候选 | 自动检查通过且每条最新开发意见均可接受，仍非正式教学发布 |

状态只提供报告建议，不会自动发布、停用或切换当前模型，也不能替代教师审核与教学效果研究。

## 5. 重新运行评测

开发命令在仓库根目录运行：

```powershell
.venv/Scripts/python.exe scripts/evaluate_teach.py --check-only
.venv/Scripts/python.exe scripts/evaluate_teach.py
# 显式调用真实 DeepSeek，产生费用，仅使用自编开发文本
.venv/Scripts/python.exe scripts/evaluate_teach.py --live
# 中断后使用输出提示的运行目录恢复，真实模式需保留 --live
.venv/Scripts/python.exe scripts/evaluate_teach.py --live --resume .local/evaluation/teach-live-实际运行目录
```

默认 Fake；每次完整运行预定 18 次，不自动重试失败。结果存入忽略目录 `.local/evaluation/`，使用独立评测数据库，不修改当前预览配置。恢复核对语料、代码指纹与配置，已终结尝试不重复调用。源码变化后应新建运行，不篡改历史清单。

本轮没有任意文件上传入口。新报告经开发核对后显式登记、计算哈希并随应用打包；运行完成并不会自动出现在网页。历史报告持续保留。
