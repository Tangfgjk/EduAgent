# V3合成学习者模拟器采纳决策与边界

评估时间：2026-10-06 17:33（Asia/Shanghai，UTC+08:00）。

来源：[V3合成学习者模拟器建议原文](../反馈/V3合成学习者模拟器建议-用户意见原文-20261006.txt)，SHA256：`8808cb4406406c10aa27da9ca56f1f6c473675df878ba1509a0623ba08b204d1`。

## 决策

采纳“合成学习者/学习者模拟器”作为V3下一步工作，但将其定义为独立的 `Simulation/Evaluation` 子系统和实验客户端，不作为真人数据替代品，不进入生产学习者证据池，不修改真实学习者掌握状态。

从桂子问津主系统看，它与真人客户端一样通过公开、受授权的API或客户端协议交互；从代码架构看，它是 `app/simulation/` 下的独立 bounded context，不塞入 `app/learning/`，也不把现有 `TeachVirtualStudentRunner` 改造成同一个类。

## 为什么合理

它能缓解当前“真人样本难获得”的工程瓶颈：重复运行学习闭环、发现课程/提示问题、比较策略、评估BKT估计与隐藏状态的差异、压测会话/事务/恢复和队列。但它无法证明真人教育效果、无法完成真实课程教师审核、无法替代真实参数校准，也不能证明生产基础设施已经具备学校部署能力。

因此四项缺口的准确状态是：

| 目标 | 模拟器作用 | 不能宣称 |
|---|---|---|
| 真实课程 | 批量找题目、先修、提示和路径的异常 | 教师审核、来源许可和课程有效性 |
| 真实学习者 | 覆盖可控学习者画像、连续多轮交互和红队 | 真人行为分布、长期效果和群体公平性 |
| 真实参数校准 | 预校准、敏感性和参数回归测试 | 真实人群最优参数、因果效果 |
| 生产基础设施 | 并发、恢复、幂等、资源和成本压测 | 生产安全、可用性、运维与合规验收 |

所有模拟输出的来源必须保持 `synthetic_ai_generated` 或等价明确标记；现有 `calibration.py` 对 `real_learning_data` 的准入、人工参考、研究授权和自动晋级关闭规则不放宽。

## 建议中的调整与暂缓

- 不沿用附件里的 `V2.1` 名称；当前是V3，拆为S1a/S1b/S2/S3，不新开分支。
- 采纳最小四件核心和物理隔离，不机械创建十几个空模块；第一版全确定性模板，不预设“80%/20%”LLM比例。
- 六类画像是反例/假设而非人口统计代表；增加零增益等竞争模型，防止用自己写的增益规则循环证明策略有效。
- Brier/概率校准评估下一次作答概率对二值结果；潜在mastery对照用MAE等，不能混用两者。
- “允许过早答案/总是主动提示”若违反Governor，作为拒绝测试或离线反事实，不通过禁用硬约束实现对照。
- 暂缓1000人规模、远程renderer、正式UI和数字孪生。先单人隔离、多轮/固定时钟和预算，再逐步负载验证；当前单用户API不能直接当多用户平台。
- 采纳Synthetic/Human/Production三层验收，但不让基础身份/隐私等生产安全前提晚于真实Pilot；基础设施开发可同步做，不依赖先取得真人样本。

## 结构决策

采用“结构化潜在状态 + 行为策略 + 可选语言渲染”的混合模型：

```text
SyntheticLearnerProfile
    -> LatentLearnerState（模拟器隐藏）
    -> BehaviorPolicy（决定作答/求助/自检/反思/退出）
    -> DeterministicAnswerModel（由掌握度、误区、保持度决定）
    -> SimulationClient（只走桂子问津公开交互）
    -> 桂子问津 Verifier -> Evidence -> Mastery/Retention -> Path/Action
    -> SimulationEvaluator（比较隐藏真值与系统估计）
```

LLM只能作为可选 renderer，把结构化动作表达成自然语言，不能决定模拟学生是否掌握、是否触发误区、是否产生学习增益。第一版以确定性和可复现为主，使用显式 `seed`、profile版本、课程版本和策略版本；随机性必须可重放。

现有 `TeachVirtualStudentRunner` 保留为“真人教虚拟学生”的单回合候选工具；新的 `SyntheticLearner` 是“桂子问津教模拟学生”的连续实验客户端，二者不合并。

## 硬边界

1. 模拟器持有 `true_mastery`、误区、保持度、挫败、自主性、提示依赖等隐藏状态；桂子问津请求和响应中不得泄漏隐藏值。
2. 模拟运行写入独立的 `simulation/{run_id}` 结果/存储，不能仅靠 `learner_id=sim_*` 与真人表混放；模拟证据不能进入真人Evidence Pool、真实校准样本或生产指标。
3. SimulationClient尽量通过正常API和动作门禁交互，不直接调用 `LearningService` 私有状态；需要测试内部故障时另设明确的集成夹具，并标注白盒测试。
4. 模拟结果只能输出软件回归、策略比较、负载报告和 `simulation_precalibration`；所有教育效果、群体结论和生产就绪结论都必须拒绝自动推断。
5. 模拟器不能绕过Consent、Governor、考试隔离、证据来源和审计；测试身份也不能访问真实数据。
6. 新画像、误区和学习规律必须版本化并可解释；不使用“数字孪生”“真实人格”或未经证据支持的永久心理标签作为产品承诺。

## 第一版范围（V3-S1）

只实现四个核心能力：

- `SyntheticLearnerProfile`：初始KC掌握、误区倾向、自主性、求助倾向、挫败敏感度、坚持度、学习率和版本。
- `LatentLearnerState`：当前掌握/保持、误区激活、挫败、提示依赖、回合计数和seed；支持快照与重放。
- `BehaviorPolicy`：`ANSWER`、`ASK_HINT`、`ASK_EXPLANATION`、`SELF_CHECK`、`REFLECT`、`QUIT`，由状态和画像决定。
- `SimulationRunner/Evaluator`：按场景运行多轮，隔离结果，输出独立成功、提示依赖、隐藏掌握与系统估计的误差、失败原因和资源指标。

先不用复杂LLM renderer、数字孪生、自动参数晋级、在线真人适配或神经认知模型。至少准备六类画像：基础薄弱、高掌握低自信、高自主、易挫败、提示依赖、固定误区；课程首选一元一次方程。

## 验收门

- 同一 `seed + profile_version + course_version + policy_version` 可重放得到相同结构化轨迹；不同seed不能改变边界约束。
- 模拟器能触发固定误区并在提示/独立作答后按明确规则更新隐藏状态；完整答案暴露不应伪造独立学习增益。
- 桂子问津只能看到客户端交互和正常Evidence；隐藏真值不会出现在API、日志、审计或模型提示中。
- 至少验证脚手架渐撤、过早答案、KT估计、遗忘复习、六类画像红队五组实验；结果带仿真版本和限制声明。
- 结果与真实数据、教师审核、真实校准、生产压测分开存储和报告；现有全量回归不因模拟器引入而减少。
