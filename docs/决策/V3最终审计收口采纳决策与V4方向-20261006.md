# V3最终审计收口采纳决策与V4方向

记录时间：2026-10-06（Asia/Shanghai）
适用分支：`V4`（从 `V3` HEAD `ced270c1ecf721a386abada8d8695ed5906c8c65` 创建）
反馈原文：[V3最终审计与收口建议](../反馈/V3最终审计与收口建议-外部反馈原文-20261006.md)

## 决策结论

审计结论合理：V3 已达到本地研究型 MVP / Synthetic Validation Release，教育闭环、合成学习者、课程准入、学校隔离 API、学习域双后端切片、CI 和本地运维验证均已落地；但不能据此宣称真实教学效果、完整生产平台或全平台 PostgreSQL 迁移。V4 是最后一次收口规划，目标是把边界、入口和后续验收条件写清楚，不以新增大量 Agent 或页面入口扩大范围。

本次只更新文档，不修改 `platform/app`、`platform/tests`、`platform/web`、CI 或依赖；V3 代码保持冻结。

## 逐项采纳

| 审计建议 | 决策 | 说明 |
|---|---|---|
| 收敛 README、文档入口和快速开始 | 采纳 | V4 总览成为新人入口，V3 保留为代码基线。 |
| 学生/教师/家长/研究治理职责拆分 | 采纳为产品规划 | 本轮只定义边界；学生端应隐藏 Token、Rubric、Evidence ID 等内部字段。 |
| Simulation Lab 增加趋势分析 | 采纳为后续实现 | 规划 mastery、独立表现、提示依赖和逐 KC 对比，不在本轮改 UI。 |
| Clock 与 Trigger 状态持久化 | 采纳为工程待办 | 需统一 timezone-aware ClockPort 和持久化状态后再改代码。 |
| Alembic 或同类 migration | 采纳为生产前置条件 | 当前不是 V3 已完成能力。 |
| Ruff、类型、coverage、浏览器 smoke、OpenAPI contract tests | 采纳为质量门规划 | 逐项在 CI 评估，不通过添加配置文件冒充完成。 |
| 真实课程、伦理、真人样本和参数校准 | 采纳为 P1 外部前置 | 没有教师、授权和研究审批时保持拒绝，不将 synthetic 转为 real。 |
| 完整 PG、SSO、多租户、worker、TLS、监控、灾备 | 采纳为 P2 生产前置 | 不是本地 MVP 的阻塞项，也不是 V4 本轮实现。 |
| 立即选择开源许可证 | 暂缓 | 需项目所有者确认，不擅自创建 MIT/Apache 等 `LICENSE`。 |

## 不采纳或明确禁止

- 不把合成学习者结果作为真实教育效果证据。
- 不开启 RSI、自动晋级、开放领域自动执行或数字孪生。
- 不把学习域 Repository 切片写成完整平台 PostgreSQL 迁移。
- 不在学生页面继续暴露教师审核、恢复队列和内部技术 ID。
- 不因审计建议在本轮增加未验收的远程 Provider、RAG、KT 或页面。

## V4 完成定义

V4 本轮完成定义是：反馈原文可追溯、采纳边界明确、V3/V4 状态不混淆、首屏文档可从零启动、P0/P1/P2 验收条件可执行，并将本计划提交到 `V4`。代码功能仍以 V3 HEAD 为准。
