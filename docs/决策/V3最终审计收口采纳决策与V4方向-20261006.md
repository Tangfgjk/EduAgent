## 决策结论

审计结论合理：V3 已达到本地研究型 MVP / Synthetic Validation Release，教育闭环、合成学习者、课程准入、学校隔离 API、学习域双后端切片、CI 和本地运维验证均已落地；但不能据此宣称真实教学效果、完整生产平台或全平台 PostgreSQL 迁移。V4 在用户追加授权下进行本地代码与文档收口，把学生体验、职责入口、分析与工程门禁落实，不以新增大量 Agent 或页面入口扩大范围。

2026-10-06授权更新：用户已明确要求完成V4所有本地可行任务、测试与文档记录；该授权覆盖此前“仅文档、不改代码”范围。V3作为历史基线保留；V4学生体验、职责入口、仿真分析和工程门禁本地P0已完成，冻结全量与浏览器通过，发布和远端CI待实际执行。

## 逐项采纳

| 审计建议 | 决策 | 说明 |
|---|---|---|
| 收敛 README、文档入口和快速开始 | 采纳 | V4 总览成为新人入口，V3 保留为代码基线。 |
| 学生/教师/家长/研究治理职责拆分 | 采纳并本地实施 | 学生六tab保留原风格；teacher/parent/research独立入口，不把本地凭据当学校SSO。 |
| Simulation Lab 增加趋势分析 | 采纳并实现，专项通过 | 四图来自实际report/transcript；描述性比较、缺失与截断口径、桌面/移动检查已记录。 |
| Clock 与 Trigger 状态持久化 | 采纳并本地工程实施 | 统一timezone-aware时间端口、持久化状态和契约测试；最终范围以freeze验收为准。 |
| Alembic 或同类 migration | 采纳本地可行迁移契约 | 不强行引入新框架；版本化迁移/拒绝未知版本/回归由工程任务落实，不宣称全平台PG迁移。 |
| Ruff、类型、coverage、浏览器 smoke、OpenAPI contract tests | 采纳并实现，本地验收通过 | 局部门与全量824项、浏览器20流程均通过；远端CI待实际执行，不通过配置文件冒充通过。 |
| 真实课程、伦理、真人样本和参数校准 | 采纳为 P1 外部前置 | 没有教师、授权和研究审批时保持拒绝，不将 synthetic 转为 real。 |
| 完整 PG、SSO、多租户、worker、TLS、监控、灾备 | 采纳为 P2 生产前置 | 不是本地 MVP 的阻塞项，也不是 V4 本轮实现。 |
| 立即选择开源许可证 | 暂缓 | 需项目所有者确认，不擅自创建 MIT/Apache 等 `LICENSE`。 |

## 不采纳或明确禁止

- 不把合成学习者结果作为真实教育效果证据。
- 不开启 RSI、自动晋级、开放领域自动执行或数字孪生。
- 不把学习域 Repository 切片写成完整平台 PostgreSQL 迁移。
- 不在学生页面继续暴露教师审核、恢复队列和内部技术 ID。
- 不因审计建议增加未经许可和未验收的远程Provider、开放自动执行或教育效果结论；授权的本地界面与工程收口须实际测试。
