# ADR 001 仓库目录与命名规范

日期：2026-10-05
状态：已接受

## 背景

初始交接包把设计文档、研究材料、代码、Web 资源和工作区放在同一目录树中，导致新成员需要从交接包内部路径理解项目，且设计文档与可运行代码的边界不清晰。

## 决策

1. `platform/` 作为唯一可运行代码根目录，包含应用、演化、测试、Web、题库和演示工作区。
2. `docs/` 作为所有项目文档总目录，按用途拆分 `overview`、`architecture`、`requirements`、`progress`、`decisions`、`guides`、`research`、`testing`、`logs`。
3. 文档和研究文件使用清晰主题名，并在末尾添加 `YYYYMMDD` 版本或归档日期。
4. 研究原始材料保持只读性质；实现规范以架构和需求文档为准。
5. 迁移使用 Git rename，代码包内部相对路径保持不变，减少行为风险。

## 影响

旧的 `桂子问津_交接包/` 路径不再作为开发入口。代码执行目录从 `桂子问津_交接包/platform` 变为 `platform`；文档链接统一从根目录或 `docs/` 相对路径引用。
