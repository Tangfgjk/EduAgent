# 首份真实课程候选被拒绝，首次具体原因未保留

## 现象

2026-10-18 自编有理数主题首次 DeepSeek 调用以 `invalid_course_proposal` 拒绝，884输入/358输出tokens。候选未发布，用量已保留。

## 定位过程

提出 JSON不符、七题结构不符、独立参考值不符三个假设；原首次响应未保留，不能证明其中一个。按批准的一次手动修复捕获仅自编开发输出：JSON合法、七题结构合法、独立数值核验通过，884输入/406输出tokens。

## 根因

## 解决方案
