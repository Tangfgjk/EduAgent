#### 问题现象

项目模式、全局计划、课程需求概念并列，初次使用仍需理解较多术语。规划候选是输入整理模板，非闭环规划执行。

#### 定位过程

2026-10-09：试用学生端七个页面，隔离测试贯通主要按钮。代码确认 loadReviews 和 loadCollaborationEvidence 仍读取全局学习者数据；不能宣称项目隔离完整。

#### 根本原因

项目只是部分证据关联边界，复习及圆桌尚未统一应用项目范围。新课程申请不是有效课程目标；本轮只处理申请当次页面的待准备状态，刷新后的持续引导仍需完善。

#### 解决方案

待完成：统一范围服务、严格范围测试、首次进入引导、临时会话恢复入口、真实模型测试、到期复习完整回归与教师/家长/研究端专项试用。

#### 验证方法

下一轮增加两个项目互不可见断言、刷新后课程申请状态断言和真实模型端到端测试。现有回归仅覆盖离线学生主路径。
