# 项目内默认单元与实际学习不一致

## 现象

用户在有理数项目完成陪学，进入圆桌仍默认概率；不知道为何需要重复选择单元，也难以辨认重命名和归档两个图标。

## 定位过程

检查 StudentApp 导航仅传 workspace，StudyPage 原默认方程，ActivityPage 原默认概率；页面单独选项随普通导航丢失。Workspace.title 是自定义文本，未绑定课程。互动目录已有 parent_unit_id，可可靠关联基础单元，但没有有理数互动包。

## 根因

产品把记录隔离与课程适配混为一谈：数据属于项目，却未从项目实际学习记录推导页面默认内容。缺包和未启用也未充分区分。图标已有无障碍名称，缺少可见提示。

## 解决方案

按当前空间最近陪学视图的 unit_id 选默认内容，并用 parent_unit_id 匹配互动；缺包时明确说明并保持未选择，手动切其他内容显示范围差异。新空间不猜名称。重命名/归档增加鼠标和键盘提示。未新增课程固定绑定或自动生成有理数互动。

## 验证方法

隔离浏览器测试构造名称与实际课程相反的空间，验证改名、刷新、跨空间、缺包及匹配；原互动兼容共 5 项通过，增强键盘断言后专项再次通过。详见 [84 验收](../进度/84-工作空间学习上下文与图标提示.md)。
