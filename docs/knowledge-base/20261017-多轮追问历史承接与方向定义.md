#### 问题现象

真实 v2 基线 15/18、原独立样本 8/10；两组同文不同历史对照失败。四项承接句均返回 clarify，一项询问分子位置返回 favorable。这里“已解决”只指本轮开发样本上的缺陷，不表示真实学生教学质量已达标。

#### 定位过程

先用冻结报告重放得到固定五项失败，再读取实际 ModelOperation 的冻结请求，确认当前文字、正确前文与允许方向全部存在。比较“澄清条件过宽”“方向定义不足”“历史未传入”三个假设。请求证据排除了本轮历史遗漏；前两项合并改动后再用相同语料及新增语料运行真实模型。

#### 根本原因

应用提供了历史，但提示没有明确“唯一历史指代应优先承接”的规则，也没有清楚区分 favorable 与 ratio；结果与这两项不足一致。不能将相关证据写成对模型内部决策的确定性解释，两项提示改动也没有做单因素消融。

#### 解决方案

新增 v3 提示版本，补充方向定义、意图优先级与不能猜测时的澄清条件；共用原有上下文来源校验、枚举与引用验证。CLI 显式支持版本选择，恢复时拒绝换提示版本。原 v2 与原量规保持不变。

#### 验证方法

v3 原基线 18/18、原独立样本回归 10/10、新增回归 12/12；同批新增样本 v2 为 8/12，对照未通过。v3 三组对照均通过。已核对同一比较对的语料哈希、题库版本、型号、文本和参考标签一致。保守澄清与历史伪规则测试保持通过；引用必须来自本轮，版本切换不能串入历史。

真实结果仍为单次开发测量；原独立样本参与过定位，不能继续作为未见验证集。详见 [量规复核](../研究设计/60-多轮失败样本与开发量规复核.md)和 [对照验收](../进度/65-v3多轮追问改进与对照验收.md)。新增独立问题卡以遵守项目历史文档不覆盖的约定。
