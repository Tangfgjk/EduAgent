### [MODEL-KEY-001] 模型配置页面因密钥读取权限返回错误

#### 问题现象

实际管理页面“模型与运行配置”显示请求失败，后端调用 `model_key()` 读取本机文件时报 PermissionError。健康检查和无凭据接口仍可成功，不能据此认定模型配置已可用。

#### 定位过程

通过真实页面复现，检查错误日志的相关堆栈，核对文件 ACL，再只读获取三个项目服务进程的 Windows 运行身份。文件只有先前测试身份权限，实际服务由本机用户运行。终端中的密钥预检成功与服务进程读不到可以同时发生，因为两者身份不同。

#### 根本原因

凭据文件的访问控制与实际服务运行身份不匹配；另外配置概览直接读取密钥而未处理 OSError，把文件不可读放大为整个接口失败。

#### 解决方案

仅向已核实的本机服务用户增加该文件读取权限，不给所有用户授权。`model_key()` 捕获 OSError 并返回不可用状态；管理端提示未配置或权限不足，发布时提示检查服务读取权限。不记录密钥内容。

#### 验证方法

管理配置页面恢复、DeepSeek v3 实际发布成功；项目 API 与模型 worker 完成两次概率追问和一次真实我教 AI 追问。另有失败注入测试，模拟文件读取 PermissionError，确认配置读取路径不会因该错误崩溃。
