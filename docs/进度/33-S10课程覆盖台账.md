# S10 课程覆盖台账

日期：2026-10-16。依据本仓库 12 号开发方向、13 号实施规划及现有源代码建立。本文是工程交付台账，未完成课程标准条目或指定教材版本的专业映射，不作为权威课程目录。各主题面向七至九年级，具体教材章节顺序以后续核对为准。

## 1. 状态与完成口径

- **开发样例部分可用**：存在可执行的开发内容包，仅支持下表明确列出的子范围；不表示完整单元完成。
- **待建设**：没有相应的正式开发内容包。通用工作空间、页面入口、旧 seeds 示例或可输入文字均不算交付该主题。
- **专业审核待完成**：适用于所有现有内容；管理员开发启用不是专业教师审核。

完整单元至少需具备：知识点/先修映射、足量且经审核的任务与答案、误区、分级提示、适用验证器与人工出口、独立检测、可追溯证据，以及教学质量审核。题量与覆盖范围需按单元确定，不使用“5 题”作为统一完成标准。不计算三年课程完成百分比。

## 4. 下一开发顺序与样板

1. **概率样板贯通**：复用已有有理数验证器，把 S04 的现有概率包接入独立审核的圆桌与我教 AI；先验证通用多包互动扩展接口。
2. **领域验证扩展**：从整式等价表达、解集和根式逐项建立受控输入/输出契约与未知分流，不把单个数值核验扩大解释为过程验证。
3. **按台账补单元**：为每项登记题目、误区、提示、检测、先修、验证及审核状态；新增内容快照，保持历史记录。
4. **试点准备**：部署与恢复等 S11 工程准备可并行；真实学生开放仍需内容责任确认、专业审核及授权。

完整概率样板的本轮实施目标见 [34 号计划](34-S10概率单元贯通实施计划.md)。样板“贯通”指工程路线齐备，不能标记为全章或教学有效性验收完成。
