# 当前能力边界与后续完善清单

记录日期：2026-10-16。此文档记录后续开发必须跟进的缺口，不改变已确认的初中数学方向及历史基准文档。

## 必须保留的现状说明

**当前未接真实模型，不自动理解课程正文或评定教学效果。**

已采用 LangGraph 编排流程。现有计划、角色话术、教学提示和策略候选来自开发模板；使用智能体框架不代表已经接入真实模型。

## 当前能够做什么

- 保存教材、考纲等资料正文与来源信息、发布状态和版本快照；这些是人工录入资料，来源真实性与专业适用性仍需核验。
- 引用当前项目的学习事实、学生自述、人工备注及已发布资料，形成可追溯的固定开发策略候选，完成管理员审核、学生确认、激活、导出 Skill.md 和回滚。
- 对开发题中的有理数结果做程序核验，保存原始步骤、提示使用和反思，展示全局及项目内部的过程证据。数值通过不能等同于推理正确、知识掌握或素养提升。

资料进入候选快照表示“可查来源”，不表示系统已经理解正文、完成教材映射或根据正文自动生成教学策略。人工启用开发题也不等同于专业教师审核。

## 后续完善任务与完成条件

| 任务 | 实现方向 | 完成条件 / 需要确认 |
| --- | --- | --- |
| 真实模型接入 | LangGraph 保留状态与人工关口，按需采用 LangChain 模型适配；集中配置模型、超时、重试和预算 | 用户确认服务商、型号、接口地址、数据出网范围及预算；密钥在本机配置，不放聊天或仓库 |
| 模型运行基础设施 | 将长耗时模型调用移出当前短事务，补齐独立检查点、租约续期、取消、幂等结果提交和失败恢复 | 中断重启、超时、重复投递、过期提案与预算限制均能验证；不直接在现有数据库锁内加入外部调用 |
| 课程正文理解 | 资料解析/切分、引用定位、知识点及教材映射、检索与结构化提案；内容作为数据处理，不执行其中的指令 | 有人工核对样本与引用定位，能识别缺失、冲突和不确定信息；错误资料停用后能阻止候选激活 |
| 教学策略生成 | 用可追溯事实和正文引用提出受约束的软策略，保留冻结版本、硬规则及双重确认 | 超越允许字段、无来源结论、越权读取及未经确认激活均被阻止；不自动修改仓库规则或执行生成代码 |
| 教学效果与素养评定 | 与具备资质的数学教学审核人员制定量规、标注样本和独立检测，再以授权试点验证 | 明确样本、基线、测量口径及不确定性；过程次数或模拟学生结果不能替代真实教学效果证据 |
| 完整课程内容 | 逐单元建设自编题、答案、分级提示、误区、独立检测和先修图，再做专业审核 | 七至九年级逐项有内容覆盖记录；代表性开发包不标记成三年级课程完成 |
| 几何证明与复杂答案 | 领域验证 Adapter、图形表达、证明过程及人工复核出口 | 未支持表达明确返回不可验证；人工结论单独保留，不能以数值验证宣称证明正确 |
| 多单元互动 | 为各内容包补充圆桌与我教 AI 的任务、角色支架、误区及来源协议 | 逐包单独审核；当前单独的方程互动模板不能自动代表其它单元已支持互动 |

## 开发阶段如何继续推进

使用自编版本化开发题、确定性场景回放、模拟账号和成人测试，验证交互、权限、状态恢复、证据引用与审核闭环。模型、专业审核和真实试点分阶段补齐；开发验收与教学有效性验收分别记录。

S10 的内容扩展仍遵守本边界。真实学生使用开发题的门禁继续关闭，直到专业内容审核与试点条件得到明确落实。
