建立时间：2026-10-06；分支：`V4`；状态：本轮文档规划，代码未修改。

## 基线与原则

V4 从 V3 发布 HEAD `ced270c1ecf721a386abada8d8695ed5906c8c65` 创建。V3 作为本地研究型 MVP 已冻结；V4 不重新定义教育闭环，也不把未来条件写成已完成。所有外部真人工作都必须经过课程、伦理、授权和数据治理准入。

## P1：真人 Pilot 前置（外部条件满足后）

教师逐题审核并冻结课程；确认教材来源授权、伦理/监护/研究 consent、测量 protocol、正式身份和家长关系；制定 retention/deletion、数据导出/撤回、事件升级和 Pilot 监测方案；配置真实 Provider 并完成 timeout、fallback、结构化输出、内容安全、成本和故障 smoke；用真实授权样本分别校准 BKT 与 Retention，并保留题目/学习者留出和人工审核。未满足时，human enroll 和采集保持拒绝。

## P2：生产部署前置

完整 PostgreSQL 主运行时与 migration；正式 RBAC、SSO/OIDC、租户/班级隔离；常驻 worker、队列指标和告警；TLS、加密备份、灾备演练、跨系统删除；Provider policy、成本/速率限制、审计导出；负载、安全和无障碍审计。

## 当前明确不做

本轮不改 Python、HTML、测试、CI、依赖、数据库和本地运行数据；不安装软件；不提交密码、DSN、API key 或 `.env`。
