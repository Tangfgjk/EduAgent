# V15 三层智能体联通：实现、使用与验收

日期：2026-10-23。开发基线：`V15-20261020`，数据库沿用 `r14_003`，本轮不迁移业务数据。主端口 4003。模型沿用管理端当前 DeepSeek 配置（本机核对为 `deepseek-flash`），没有擅自更换型号。

## 1. 本轮目标与实际改动

### 1.1 互动核心

- 新请求使用 `grounded-dialogue.v1`。明确告诉模型本次是陪学、我教 AI 还是圆桌，发送当前已展示题目、本轮脱敏输入、同题同配置最近最多两轮成功交流，以及受限策略偏好。
- DeepSeek 直接生成针对表达的问句，不再只选方向后用固定 `QUESTIONS` 覆盖。读取历史时保留经检查的生成原文；旧版本记录保留旧渲染器，不伪称过去也是生成式互动。
- 圆桌必须生成提出者、质疑者、整理者三个不同视角，各自引用本轮真实原话；它们是同一模型的角色视角，不宣称三位独立专家。
- 我教 AI 和开启通用互动的圆桌可连续回应，最多三轮，每轮都经过同题、配置、用途、取消和版本检查。独立验证阶段禁止继续模型求助。
- 结构检查包括原文引用、角色、题目选择范围、文本长度、禁止可执行内容、显式错误算术等式及直接答案表述。检查失败保存失败原因，不放宽条件或自动重试。
- 这些检查不能证明任意自然语言解释正确。数学真值仍由程序核验，教学质量与效果不自动认证。

### 1.2 教学调度

- 课程生成读取本次已曝光诊断题的实际提交与独立数值状态；不只接收通过数量。含混诊断仍有最多四题的准备边界，可以保留未知结束，不把未知直接当错误。
- 模型可选择已有未完成练习，或提出当前支持题族内的变式参数；不能选检测题充当练习。
- 专用有理数课程保持当前概念（如绝对值、相反数、数轴），通过现有十一种形式编译变式，不能把绝对值目标改成乘法练习。
- 变式经 `Blueprint` 参数检查及 `compile_problem` / `verified_task` 独立计算，参考值不一致、题族不符、与保留题重合时拒绝。
- 合法变式只在反思完成后进入当前任务，最多补充两题，不替换原题、不删除练习、不改变诊断与独立检测。答案不出现在模型追问的公开结果中。
- 变式题面、真值、父内容版本和参数随事实冻结，进入成长证据和复习卡。复习时重建核对参数与快照，父课程撤回后仍不可使用。
- 模型提出 maintain / fade / restore；渐撤需要实际未用提示的通过记录，困难时恢复具体支持，`step_first` 策略仍受尊重。模型建议不是能力判断。

### 1.3 规划、证据、RSI 与资源

- `goal_context` 统一提供当前项目课程主题、绑定修订、单元及最多六条结构化事实；不读取其他项目正文。
- 模型请求中移除工作空间和事实数据库 ID，使用临时观察别名。规划和 RSI 已有六条来源时，不再另加六条事实突破其范围；完整追溯引用只在本机保存。
- 普通规划冻结目标与近期调整依据。选择模型方式且启用执行策略时，模型可以建议既有四类枚举参数，仍不能添加权限、预算、禁用核验等字段；最后由学生确认。
- RSI 数据集与模型调用关联同一目标上下文；评测签名覆盖新互动、目标与调度模块，代码变化后的旧评测不能直接当新证据继续发布。
- 工作台、课程、规划和证据页面提供相互入口及目标卡片；恢复“规划与策略”和“Skill 改进”显式侧栏入口。
- 资源建议指向当前课程及已有资源；普通课程生成也接收同一目标上下文。OpenMAIC 文本与媒体生成继续检查原有独立开关和预算，不因为 Agent 给出资源建议就擅自开通付费生成。

## 3. 怎样体验

1. 登录模拟或成人开发账号，选择项目，确认课程与学习计划。旧进行中的任务可以结束后新开，以体验新初始化行为。
2. 陪学练习阶段写具体想法，例如“我知道先乘除，但负号的依据不清楚”，请求 AI 追问。直接作答仍由独立核验器处理。
3. 回答模型问题，观察它是否承接你的表达。需要变式时明确提出；模型必须返回可核验参数才会加入，不能保证每次要求都成功产生新题。
4. 通过当前练习并完成反思后，查看实际后续题目与支持依据；补充题也会留下事实和复习记录。
5. 进入我教 AI 或圆桌，勾选模型互动，保存表达后继续回应。完成最多三轮后保存修正、进入独立验证。
6. 在成长、规划和课程页查看同一目标卡片；进入规划可使用 DeepSeek 提案，确认参数后只对后续新任务应用。
7. 正式项目具备有效策略基线后，可进入 Skill 改进；语义方式默认展示，个人试用仍需明确同意，可关闭或撤回。

## 5. 保留的明确边界

- 变式自动核验仍限已实现的六类数值题族，不包含任意证明、作图、复杂单位及整套初中课程的全面核验。
- 课程级别的诊断准备有界；本轮没有建立经专业验证的误区分类器或掌握度测量。
- 圆桌是同一模型的多视角生成，不是三个自治模型协商的委员会。
- 实时更新仍是已提交消息与状态，不是上游逐 token 输出。
- 真实媒体预算仍未批准，原 OpenMAIC 文本预算仍关闭；不自动为资源建议付费。
- RSI 保持受限个人开发试用，教师量规与真实学生教学效果结论仍待验证。
