# V5 项目工作空间与规划 Harness 实施记录

## 已实现

- 工作空间上下文 API：正式项目与临时会话分离；临时消息单独存储并带 `formal=false`。
- 项目证据绑定：带 `project_id` 的评估、质性作品和陪学会话会在同一事务边界内追加项目引用。
- 项目局部成长：按项目证据和会话引用重放掌握与保持状态；全局成长接口保持原契约。
- 素养可视化数据：六维雷达数据契约，优先读取最近快照中的显式素养评估，未知维度返回空值。
- 规划 Harness：四类输入生成候选 Skill.md，版本化保存，支持候选审核、退回和已审核版本回滚。
- 路径采纳：保存客户端提交的路径提案，避免服务端静默替换为新推荐。
- Gate provenance：掌握门禁结果增加证据、事件序列、验证器和评估版本来源。
- 工作台：增加项目/临时路线、项目待办摘要、全局/项目成长范围、素养条形雷达和规划 Agent 页面，并沿用参考 HTML 的暖灰、白卡片、墨绿色、宽松布局。

## 尚未宣称完成

课程需求到完整课程资产的自动生成、互联网/Embedding/GraphRAG、多智能体委员会共识、自动 RSI 晋级、PostgreSQL 生产迁移仍未完成。界面和文档将这些能力标为候选、研究版或后续范围。

## 数据安全约束

临时会话不进入正式学习者画像；规划候选在人工审核前不改变教学规则；模拟数据不能写入真实学习者证据表。数据库凭据不进入仓库。
