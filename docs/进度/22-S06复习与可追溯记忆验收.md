# S06：复习与可追溯记忆开发基线

日期：2026-10-16。分支 main，未读取其他分支。已有 docs 保持原状，本文件与 23 号架构说明为新增记录。

## 1. 已实现的学生功能

“错题与复习”现在有三个真实页面分区：

- **复习安排**：数值未通过、使用提示后答对、人工复核建议回看，分别标注原因；可按待复习/已安排/全部筛选，每页 20 条。
- **不可验证与复核**：查看无法自动确认的提交、待处理状态和独立保留的人工意见。这些提交不会直接当作错题。
- **学习记忆**：当前空间摘要与观察记忆；全局正式项目视图包含归档项目，排除临时空间。按项目分页，每个观察都能回到来源。

可从复习卡或记忆点击原始来源，查看自己的答案、步骤、当时的提示、反思和验证结果；也可以追加“补充或纠正说明（学生自述）”。自述与人工判断分开显示，不能覆盖原始提交或验证历史。

正式与临时空间都可保留局部复习。临时空间不会因复做而自动变成正式项目，也不会进入全局正式项目记忆。归档后可阅读来源与记忆，不能提交新复做或说明。

## 2. 复习规则

当前采用**原题无提示复做**，不提供任何提示，只验证数值。原题已经见过，所以不把它称为新的迁移检验，也不把一次通过称为已掌握。

开发默认间隔为 **1 / 3 / 7 天**，未经过真实学生校准：

1. 到期复做数值通过，安排下一次回访；最长默认间隔保持 7 天。
2. 提前复做会保存结果，但不会增长安排档位，也不会延后原到期时间。
3. 数值未通过，回到当前可复习状态；不可验证则保留安排并进入人工复核。
4. 同一条目并发提交检查 revision；相同幂等键的原始请求不重复写入或重复推进安排。
5. 当前空间有正在进行的诊断或独立检测时，服务端拒绝复做，避免从另一页获得答案型帮助。
6. 开发内容撤回、版本失配、来源失配、真实学生账号限制继续生效。

## 3. 记忆边界

- L1：不可变学习事实，关联真实接收的输入、运行、题目版本、数据来源、验证结果和提示使用情况。
- L2：按来源与诊断/练习/检测/复做分类的可再生摘要；统计单位是提交次数，受辅练习通过单列。
- L3：受控观察引擎 `observations.v1`，只描述记录与来源。可引用 L1/L2，不允许引用其他 L3 结论，也不能伪装成 L2 引用。
- 学生补充说明与人工判断分别存为追加记录，作为相应来源展示。

本轮不启用未经校准的 BKT 数值，不推断误区成因、推理质量、掌握度或素养，不绘制虚假能力曲线。长期证据可视化、规划 Agent 与 Skill/Harness 更新继续按后续阶段推进。

## 4. 兼容旧 S05 数据

新增学习事实、复核补充、复做记录与学生说明均在数据库层禁止修改/删除。worker 将事实、复习条目变化、L2/L3 摘要与原运行结果在同一事务提交。

历史 S05 不能仅凭“输入已接收”或队列完成状态猜测结果。新增停服维护命令：

```powershell
uv run --locked python -m app.manage --env-file .local/database.env backfill-learning-facts
uv run --locked python -m app.manage --env-file .local/database.env backfill-learning-facts --apply
```

默认只报告。仅对相同图/内容/验证器版本，结合不可变输入、已处理任务、检查点的处理边界进行确定性重放，并与已保存视图核对一致后，才补建缺失事实。幂等重跑不会重复写入。

检查点仅用于核对处理边界和结果，不作为掌握证据或记忆来源。版本不符、缺失、核对失败均跳过。若已有新复做而仍缺历史事实，不自动插入旧事实重置安排，报告 `incomplete`，等待显式协调。

## 5. 升级与体验

停止本项目 API/worker 后，先备份数据库，执行：

```powershell
uv sync --locked --extra dev
uv run --locked python -m app.manage --env-file .local/database.env migrate
uv run --locked python -m app.manage --env-file .local/database.env backfill-learning-facts
uv run --locked python -m app.manage --env-file .local/database.env backfill-learning-facts --apply
cd frontend
npm ci
npm run build
cd ..
uv run --locked python -m app.main --env-file .local/database.env
# 另一个终端
uv run --locked python -m app.worker --env-file .local/database.env
```

本机已升级至 `s06_001`，API 版本 `0.6.0`。升级前备份位于 `.local/backups/pre-s06-20261016-201437.dump`。本机历史核对与补建均为 0 条，没有用测试数据填充正式库。

体验入口：<http://127.0.0.1:8000/student/review>。首次使用仍须本机隐藏输入命令初始化管理员，在管理端创建学生，并核对启用开发内容；本轮不创建正式默认账号，不自动启用内容。

先在陪学留下数值未通过或受辅通过的记录，再进入复习。若处于诊断/检测中，请先完成该阶段；普通练习期间可以回访既有条目。用文字提交的未知答案可以在“不可验证与复核”追溯。

完整 JSON 备份/恢复覆盖事实、说明、判断、安排、复做、投影及检查点；仍只允许同 schema revision 的空库恢复，不恢复登录 Cookie。L2/L3 可从事实再生；复习安排的灾备依赖完整备份，本轮没有提供独立的全量安排事件重放工具。
