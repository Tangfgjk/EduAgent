# S10 概率单元贯通实施计划

日期：2026-10-16。状态：下一轮代码开发计划，尚未实现新增互动能力。依据 [33 号覆盖台账](33-S10课程覆盖台账.md) 选择现有等可能事件概率包作为多包互动扩展样板。

## 1. 样板目标

在同一项目或临时空间内，学生能完成概率陪学、圆桌观点比较、我教 AI 纠错讲解、无提示复习，并从成长证据找到自己的原始贡献。沿用纸感、绿色及现有双端布局，新增单元选择和当前内容标签。

继续使用固定开发模板；不接真实模型，不自动判断学生讲解优劣，不把互动后的答案计为无辅助检测。当前概率陪学与复习已可用，新互动不改变基础包版本或已有记录。

## 2. 内容与交互

| 路线 | 任务与阶段 | 保存结果 |
| --- | --- | --- |
| 津津陪学 | 沿用当前 5 道概率开发题，诊断→练习/反思→独立检测 | 原内容版本、提示与尝试、反思、检测数值结果 |
| 圆桌 | 复用 3 红球、2 蓝球的等可能摸球题：先由学生表达；再展示“按球数计数”“两种颜色各一半”的冲突观点与核验问题；最后学生比较并提交概率 | 两次学生贡献、固定角色观点、末次数值核验；角色话术不作为学生证据 |
| 我教 AI | 同一题先请学生讲解；虚拟学伴提出“两种颜色所以各为 1/2”的预设误区；学生说明基本结果为什么按球而非颜色计数并给出结果 | 原始讲解、纠错贡献、固定 TeachReport；解释质量保持未评定 |
| 复习与证据 | 将真实提交按任务、基础内容版本和互动版本保存并追溯 | 错误/人工复核来源与复做；辅助后的答对不冒充独立表现 |

上述标准答案及模板只在管理员核对和适当学习阶段显示；开始页面和学生目录不能泄露未开放参考答案。模板不读取学生文字，也不能用“我理解了你的推理”等表达假装语义理解。

## 3. 按步骤实现

| 步骤 | 实现方式 | 完成目标 |
| --- | --- | --- |
| A 多包互动注册表 | 为方程与概率分别注册基础包、互动题、角色/误区、模板版本和边界；保留原方程 hash/版本兼容 | 互动内容不再依赖单个全局 TASK；未知内容包被拒绝 |
| B 后端贯通 | StartActivity 按注册表解析；graph 检查点保存包标识；service、worker、事实与复习按精确版本取包；人工复核用对应快照 | 方程/概率交互与版本隔离，旧运行可按原兼容策略恢复或查看，撤回内容后重新检查 |
| C 审核与页面 | 管理端逐包核对并独立启停；学生圆桌/我教 AI 选择单元，并保留工作空间与运行内容标签 | 启用概率陪学不自动启用概率互动；刷新、错误、空态与移动布局可用 |
| D 验收与记录 | SQLite/隔离 PostgreSQL 场景、Chrome/Edge 相关场景、旧方程回归、安装包与必要的恢复验证 | 可重复验收，新增版本/进度文档，更新实现快照并保留旧快照 |

## 4. 必须验证的行为

- 先保存学生表达，再开放观点/误区；学生必须再次贡献才能生成小结。
- 方程与概率内容、提示、参考结果不串包；不同账号、空间和来源不串记录。
- 审核启停有版本与 revision 校验；启动、恢复、worker 执行、复做均检查适用内容。
- 重复提交、旧 gate、取消、归档、重启恢复不重复写学生贡献；一次空间内的陪学与互动仍依次进行。
- 未支持的数值表达进入不可验证/待复核，不能猜测为正确或错误；人工结论不覆盖原始历史。
- 新互动学习事实与复习卡片能核对基础版本、互动版本和原文；全局证据继续排除临时空间。
- 固定模板/预设误区标识可见，无素养评分或教学效果结论；真实学生开发题门禁继续关闭。
