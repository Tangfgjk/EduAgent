# S08 成长证据可视化验收

日期：2026-10-16。当前分支 main；没有读取其他分支。既有 docs 文件不改动，本轮新增 26、27 号文档与问题记录。

## 1. 已交付

- 成长证据页面接真实 API，全局覆盖本人全部正式项目（含归档），局部可查看项目或临时空间。
- 支持 14/30/90 天、来源筛选；模拟、成人测试、真实学生分开统计。
- 展示作答/原题复做、独立检测、提示、反思、互动、自述和人工判断。
- 每日过程曲线可切换来源/指标、选择日期，并查看数据表；不自动解释为能力升降。
- 来源列表按记录类型筛选并分页，可打开原文、数值核验、提示和说明；追加自述后刷新读模型，归档只读。
- 六个素养方向有可选择的状态卡；无审核量规时 score=null，不画假分数或能力多边形。

## 2. 如何体验

登录学生端，选择空间，点击“成长证据”。默认“全局宏观”，可切换“当前空间局部”。有真实开发过程记录时显示统计；没有则显示空态。下方“证据来源记录”可按独立检测、提示、自述等筛选，再查看原始来源。

当前统计材料来自自编开发题和模板活动，不是专业教师金标。素养六维沿用产品观察框架，尚未进行初中数学量规审核与校准，所有方向均为未评定；没有用交互次数代替能力评分。
