# S10 概率互动贯通验收

日期：2026-10-17。基于 main 分支实现，未读取其它分支。承接 34 号实施计划；33/34 号及此前 docs 文件保持历史原状。本文件记录概率样板的新状态，不代表完整 S10 或三年课程完成。

## 1. 本轮交付与体验

概率单元已接通陪学、圆桌、我教 AI、复习与证据的工程路线。陪学沿用现有 5 题，互动复用 `P-PRB-02` 摸球题；没有把同一题的互动重复计为新增题量。

1. 管理员进入“知识点与题库 → 新增单元互动审核”，核对“概率圆桌与我教 AI”的题目、参考值、基础内容版本、角色观点及预设误区，勾选确认后启用该互动包。
2. 学生选择项目或临时空间，在“圆桌讨论”或“我教 AI”中选择概率互动包。两条路线先保存学生表达，再开放固定观点/误区，最后保存第二次学生贡献及数值核验。
3. 圆桌比较“每个球为等可能基本结果”和“按颜色种类计数”的依据；我教 AI 使用“两种颜色所以各为 1/2”的固定误区。角色不读取学生文字，也不自动评定讲解质量。
4. 学生可在学习记忆和成长证据查看自己的贡献及原文；角色模板不进入学生学习事实。互动后的核验标为辅助后表现，不作为独立检测。

陪学、互动内容包分别启停。互动审核包含完整的互动题与话术快照，所以可以单独体验，不要求先启用陪学包；复习执行基础题时仍要求基础包启用。来源涉及互动的复习还会检查该互动版本及启用状态，避免已撤回互动来源绕过门禁。

## 3. 架构与版本约束

- 新增 `activity_catalog.py`：集中注册互动包、基础包、任务、角色模板及内容 hash，提供按包和按版本解析接口。概率 hash 包含基础内容版本，内容变化需要重新审核。
- 原 `activity_content.py` 保持不变。方程沿用原内容 hash 与 `activities.v1` 图版本；图状态仍可按原 `view.activity_version` 定位，未对旧检查点批量改写。新概率使用 `activities.v2` 图版本。
- graph、service、worker、事实发布不再固定引用全局方程 TASK。恢复及事实发布按已保存互动版本定位；基础版本和互动版本分别进入事实/复核记录。
- HTTP 启动与继续、worker、互动来源复做均有相应门禁；过期 gate、重复请求、归档与真实学生开发限制继续有效。worker 遇到已退役版本直接记录明确失败，不反复尝试未知内容。
- 互动导致的错误来源按现有协议通过人工复核结论进入复习卡片；没有把首轮意见或未知输入直接算成数值错误。人工结论保留为独立记录，不能代替专业内容审核。
- 数据库仍为 `s09_001`，无需迁移。原学习事实和版本保留；历史内容撤回或版本无法匹配时，不能将新包套入旧事实自动复做。

新增鉴权接口：

- `GET /api/v1/student/activity-catalog`：学生目录，隐藏题目答案及角色模板，`tasks=[]`。
- `GET /api/v1/admin/activity-catalog`：管理员核对完整互动快照。
- `POST /api/v1/admin/activity-catalog/{unit_id}/development-release`：按包做版本、revision 和开发范围确认。

原 `/activity-content` 及审核接口继续只代表方程互动。两条活动启动接口现在按注册表解析 `unit_id`，未知互动包返回 404。
