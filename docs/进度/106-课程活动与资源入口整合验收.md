# 课程、活动与资源入口整合验收

日期：2026-10-19。基于V12 / API0.18.0，数据库仍为`g08_001`。本次是第一优先项的体验整合，不扩大模型、搜索或OpenMAIC付费生成范围。

## 1. 学生端

- “主题与课程”顶部新增“当前课程与学习路线”，集中展示课程、单元版本、陪学、圆桌和我教AI的内容开放状态及入口。
- 未绑定、未开放、计划待确认、归档、读取失败分别提示；概览不替代活动页的并发/权限/版本关口，不承诺“可开始”就绕过已有任务。
- 课程资源移到新主题输入之前，显示可用数量、读取状态、无资源原因和管理员处理路径。
- 无可用资源不冒报“未生成”，说明可能未生成、待审或已撤回。学生仍只能读当前空间/当前单元的已审核资源，诊断与检测隔离继续由后端执行。
- 资源请求失败时不继续渲染缓存正文；未审资源和其他项目资源不会因概览而开放。
- 顶部课程栏增加“查看当前课程、活动与资源”入口，复习/证据/策略入口也在概览集中提供。

## 2. 管理端

- 增加“主题→数学检查→开发审核→学生确认→资源审核”流程说明。
- 课程按项目分组，展示项目名、中文状态、检查结果及“下一步”；内部完整JSON折叠在审核详情，保留题目参考/检测核对入口。
- 每门课程可直接筛选对应资源审核；资源列表支持独立翻页，筛选在后端按`build_id`执行后再分页。
- 项目/课程关键词筛选明确仅作用于当前20条批次，不冒充全库检索。
- OpenMAIC显示预算未配置、已停止、已用完或已开放；额度、关联课程限制和已有任务都会约束预约按钮。后端预算关口保留，前端不单独授予调用权限。
- 预算停止不影响已有资源审核、阅读、导入和符合条件的“重新导入已生成文本”。没有自动重开预算。
- 生成用途和知识资料设置收纳为折叠区，避免进入页面先被配置项淹没。

## 3. 接口与兼容

- 课程列表增加空间显示名称，不改变所属空间权限检查。
- 管理资源列表增加可选`build_id`筛选，保持旧请求兼容；非法标识返回422，学生不能访问管理资源接口。
- 管理OpenMAIC任务返回预算关联标识，页面据此判断“本预算已用于另一课程”；不返回代理密钥。
- 生成接口类型与API同步；本次无数据库迁移。

- 学生：[主题与课程](http://127.0.0.1:4003/student/courses)，先选自己的空间。
- 管理员：[课程生成与资源](http://127.0.0.1:4003/admin/generation)。
- 现有内容、审核、调用额度、OpenMAIC首轮停止预算均保留；本次未把资源生成改成自动触发。
- 当前未增加“读取所有课程的全局检索”或学生端未审资源正文；课程状态与活动实际启动仍由服务端检查。
- 下一项是深化一个有理数主题的内容、误区、多轮评阅和独立检测，随后完善策略变化的可见性。它们不计入本次已完成项。
