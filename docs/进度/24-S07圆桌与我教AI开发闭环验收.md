# S07 圆桌与我教 AI：开发闭环验收

日期：2026-10-16。当前分支 `main`；没有读取其他分支。新增本文件与 25 号架构文档，既有 docs 文件未改动。

## 1. 本轮交付

- 学生端“圆桌讨论”“我教 AI”已接入真实 API、LangGraph、独立 worker 与数据库，不再是禁用的原型入口。
- 圆桌：学生初步思路 → 三种模板观点 → 学生比较、纠错与核验 → 讨论小结。
- 我教 AI：学生讲解 → 学伴预设误区 → 学生回应与核验 → TeachReport 讲解记录。
- 支持项目与临时空间、历史分页、刷新恢复、取消、归档只读、同键重放和错误提示。
- 管理端单独审核、启停确定版本的互动模板；原陪学包启用状态保持独立。
- 学生贡献接入学习记忆与来源，角色观点不当作能力证据；无法验证的数值进入现有人工复核。

## 2. 使用方式

1. 管理员进入独立管理端 `/admin/` 的“知识点与题库”。
2. 在“圆桌与我教 AI · 互动模板审核”打开完整题目与模板，核对预设错误和使用边界。
3. 点击“审核互动模板”，确认仅供开发测试后启用。不会因为启用了陪学题库而自动启用互动。
4. 学生登录 `/student/`，选择项目或临时空间，进入“圆桌讨论”或“我教 AI”。
5. 先保存自己的数值表达和思路；看到模板观点/误区后，提交自己的比较、纠错与检查依据。
6. 查看小结，进入“错题与复习 → 学习记忆”，打开来源查看学生原文、数值结果和自述。

同一空间的陪学与活动依次进行；有尚未完成的陪学/活动时，请继续或结束当前路线。诊断、独立检测期间不能通过互动入口获得辅助。互动也不允许与无提示复做同时运行。

正式项目可直接体验此活动，无需先创建陪学计划；这是范围固定的开发活动，不是自动生成的项目课程。临时空间不进入全局正式项目记忆。

## 3. 实现范围与限制

当前只使用一元一次方程 `P-EQ-01` 和固定角色模板，尚未接入真实模型。角色不会针对学生文字智能回复；故意设置的错误有明确标记。最后仅核验数值，讲解质量、论证有效性、误区成因、迁移能力、掌握度与素养均未自动评定。

TeachReport 当前是可恢复、可追溯的讲解过程记录。专业 rubric 和解释审核工作流仍待后续建设；本轮不宣称 S07 的正式智能教学能力已经全部完成。详细数据与运行边界见 25 号文档。

## 4. 运行与数据

API 版本 `0.7.0`。复用现有表，数据库 HEAD 仍为 `s06_001`，本轮无 schema 迁移。仍需分别运行 API 和 worker；真实网络模型不能直接接入当前短事务运行器。

```powershell
uv run --locked python -m app.main --env-file .local/database.env
# 另一个终端
uv run --locked python -m app.worker --env-file .local/database.env
```

首次管理员仍由本机隐藏输入命令初始化，不预设密码、不在正式库灌入演示账号或学习数据。首次初始化、建号、启用开发内容方式沿用 16、20 号文档。

本机预览已更新。更新前备份：`.local/backups/pre-s07-20261016-220439.dump`。正式开发库核对：管理员 0、内容审批 0、学习事实 0；测试账号和互动记录只在隔离验收库中。服务进程记录：`.local/s07-preview-processes.json`，日志前缀 `.local/s07-`。
