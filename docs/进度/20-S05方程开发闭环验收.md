# S05：方程与应用开发闭环验收

日期：2026-10-16。工作分支 main，未读取其他分支。已有 docs 保持原状，本文件与 21 号架构说明为新增记录。

## 1. 本轮交付

首个自编开发单元“一元一次方程与应用”，共 5 题：初始诊断 1 题、方程与应用练习 2 题、平行无辅助检测 2 题。

学生实际可以完成：

1. 正式项目先确认学习计划，再开始开发单元；临时空间可直接开始独立体验。
2. 诊断题独立作答，记录数值结果与可选的步骤，不提供提示，也不允许提交后改写结果。
3. 练习题可以反复尝试，查看程序验证反馈，并逐级请求 L0–L3 提示。
4. 答出结果或显式选择“记录为未完成”后，写下自己的反思再进入下一题。
5. 两道无辅助检测不提供提示，提交后锁定本题输入；完成后显示本轮题目的数值结果、尝试次数、提示次数和反思。
6. 刷新、重启 worker、数据库备份恢复后继续；可以取消当前陪学；各账号、项目与临时空间的记录隔离。

当前不根据自由文本目标自动选择单元。页面明确展示开发单元的范围，由学生主动选择体验。

## 2. 管理端同步开放

### 开发内容启用

“知识点与题库”展示全部开发题的题干、数值真值、输入约定和提示。默认关闭，管理员阅读并勾选“已核对开发内容，了解尚未通过专业审核”后，可启用当前版本的开发测试。

请求同时校验内容哈希和状态 revision。题目/提示变化后旧启用记录失效，须重新核对当前版本。管理员可以停用，worker 在每次处理输入前再次检查。

这不是专业教学审核。当前只允许 `synthetic` 与 `adult_test` 来源账号，标记为 `real_student` 的账号被服务端拒绝。账号来源沿用 S02 的配置与创建逻辑，本轮不篡改已有来源。

### 解答复核

验证器无法确定的提交会进入真实待复核队列。管理员可查看原始答案、步骤、题目版本快照与真值，记录“数值正确 / 数值错误 / 仍无法判断”以及依据。

复核保留独立记录和审计，不能覆盖不可变学生输入；也不自动改写已经保存的自动验证结果、后续学习路径或素养。复核后的待办数量按数据库实时状态读取。

## 3. 验证与教学边界

- 使用真实 LangGraph TutorGraph，不调用外部模型。模板支架与题目均为自编开发内容，尚无教师金标。
- 新正式入口不把不可信学生文本传给旧 `sympify` 路径；采用受限 AST + Fraction 验证有理数，只允许有界数值、括号与四则运算。不执行学生代码，不调用 eval。
- 接受 `x=3`、`6/2`、`(1+2)*2/2` 等等价数值；中文乘除号与负号会规范化。链式等号、函数、任意 Python、过长/过复杂表达式、除零等转为不可验证。
- 当前只核对数值答案，**不验证列方程、推理步骤或反思质量**。这些内容原样保留，页面持续说明“数值通过不等于步骤正确或掌握”。
- 练习第四次提示才开放完整对照，经过原 ActionGovernor 的 R-01 门禁；诊断和检测通过 R-09 禁止答案型帮助。最终计划所有权仍沿用 S04 的 R-02。
- 未完成、失败、不可验证与数值通过分开展示。不会把提示使用后的正确作答当作独立检测成绩，不生成掌握度或六维素养分数。
- 本轮是一个 5 题的开发样例闭环，不代表已完成七至九年级内容覆盖、真实模型陪学或正式学生发布验收。

## 4. 运行与体验

根目录依赖和进程方式沿用 README；数据库升级至 `s05_001`：

```powershell
uv sync --locked --extra dev
uv run --locked python -m app.manage --env-file .local/database.env migrate
cd frontend
npm ci
npm run build
cd ..
uv run --locked python -m app.main --env-file .local/database.env
```

另一个终端运行：

```powershell
uv run --locked python -m app.worker --env-file .local/database.env
```

若尚无管理员，在本机运行隐藏密码初始化命令，然后通过管理端创建学生：

```powershell
uv run --locked python -m app.manage --env-file .local/database.env bootstrap-admin --username admin
```

实际体验顺序：

1. <http://127.0.0.1:8000/admin/content>：核对开发题、勾选确认、启用开发测试。
2. <http://127.0.0.1:8000/student/>：选正式项目 → 学习计划确认 → 津津陪学 → 开始开发单元；也可在临时空间直接体验。
3. 使用文字或不支持的表达式提交答案后，<http://127.0.0.1:8000/admin/review> 会出现待复核记录。

本机升级前备份：`.local/backups/pre-s05-20261016-181409.dump`。未创建正式默认账号、未自动启用正式库内容。新版 JSON 备份包含内容启用、运行检查点、学习输入、事件与复核记录；仍仅支持相同 schema revision 的空库恢复，不恢复旧登录 Cookie。
