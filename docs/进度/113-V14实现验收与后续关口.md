### 2.1 不把Agent理解、数学真值和教学效果混在一起

- 普通明确答案先做保守提取；复杂表达可由模型产生带原文依据的候选，必须学生确认，数学另行核验。
- 程序仅核验已支持数学题族和显式算术等式；不能全面核验证明、长篇解释或单位推理。错误理由与最终数值分开。
- 通用未设计概念题的旧课程仍使用安全追问方向；有理数课程Agent可设计目标相关问题，互动模型在已开放范围选择。不声称所有追问都自由生成或已获专业认可。
- 支架渐撤和恢复基于实际作答/提示记录；语义RSI只改变既有四类软策略，不能自改代码、参考答案、检测、权限和预算。

### 2.2 OpenMAIC与媒体到底实现到哪里

项目自建适配层对接固定上游 v1.2.0，不直接嵌入带后台权限的4004页面。保留原始场景结构，以不可执行的React/SVG投影播放；无不可信HTML执行，也没有接受任意来源的消息桥。支持安全的文字、公式、图形、场景动作与音视频；不支持的上游组件列明并降级。

已恢复既有4004服务，并以本机只读GET重新读取历史三个文本场景、离线生成新版投影，无新增模型/媒体调用。此转换不等于重新审核原课稿：历史资料仍有零参与符号法则的适用前提、过强教学断言等内容需要专业核对，未因此自动批准一个新内容版本。原文本课没有收费音视频，不能承诺它凭空出现媒体。

课堂互动原话/核验/进度由本项目鉴权接口保存；可回到陪学继续当前课程，播放结束不计掌握。原始媒体加载失败有文字降级。

新增百炼北京图/音/视频接口已实现：2图、3段每段最多150字符/实测30秒、1段5秒480P无声视频，最多6提交、无重试；5元仅是**待批准**上限。下载不发送业务Cookie或模型密钥、不跟随跳转，限允许域/MIME/大小/元数据。媒体作为附加资产，不改写已审核课堂哈希。不能完整测量的编码拒绝落地；尚未真实调用供应商，后续需核对实际格式/账户权限/价格。

## 4. 两轴代码复查

复查涵盖V13基线后的修改及未跟踪新增代码，不只审已提交diff。两个轴分开，以下记录原发现和处置；最终复查补充见本节末。

### Standards

原发现3项行为/结构风险（不是格式错误）：

1. 关闭自动改进后排队候选仍可晚激活：新增同意版本token、候选冻结、停用取消及完成时fresh检查；迟回包测试覆盖。
2. 媒体worker只在预约检查课程/独立状态：统一`sources()`在执行前、发布前、资产读取重查；排队后切课/开始独立检测时零外部请求。
3. 资源机器审核可能只读截断文本卡片：改为覆盖全部实际展示元素、公式、动作、字幕；超容量留待复核，不静默丢尾部。

硬性规范违反0项；上述3项已修复。保留判断：多角色的状态检查应继续通过共享函数维护，避免新增消费者时遗漏。此轴最重要风险是授权/版本状态在异步阶段变化。

### Spec

原发现5项缺口：

1. 私有课堂仍需逐门管理员操作：新增学生自助入口、预算内复用/生成/取消及双次机器检查，异常仍复核。
2. 通用陪学未带同题历史：加入同题/同配置/同策略epoch成功轮次，避免跨题/跨项目混用；修复历史focus字段导致的第二轮500。
3. RSI只有旧四样本及不变量：保留旧消费者测试，新增候选相关的6个隔离影子场景和困难恢复/泄题边界。
4. 诊断固定两题：支持目标化初始数量、含混追加探测、最多4题及主动保留未知结束。
5. 缺少实时聊天更新：新增已提交消息与状态SSE及重连/轮询后备；上游逐token输出仍未开放，不等同原始模型流。

5项开发缺口已按本轮范围修复；教师量规、真实学生效果、媒体费用和全学段覆盖明确保留外部关口。本轴最重要剩余限制是工程评测不能证明教学有效。

### 最终复查补充与结论

Standards最终只读复查未发现新的确定性阻断问题；三项原风险已修复，硬性规范违反0项。

Spec最终又发现3项功能边界：课堂取消需同步停止检查并拒绝晚回包、检查要求修改/第二次无法入队不得永久checking、追加诊断的模型分母与排除参数不得固定两题。已分别补取消与完成栅栏、hold待复核出口和实际诊断快照。修复过程中再检查到Workspace/Job与Run/Operation两组锁序反转，已统一事务锁顺序，恢复先搜候选再按完成路径加锁、锁后复查。复查代理最终确认这些补丁无可确认阻断问题。

## 7. 下一步独立关口

1. **内容与理解覆盖**：按知识点—题族—核验器扩展七至九年级；补证明/作图/图像/解集与单位，不用放宽关键词冒充覆盖；建立合法教材/课标映射与来源版本更新。
2. **专业评价与真实效果**：教师量规、锚点/一致性、等值且隔离的四测题集；核对真实干预暴露与可比性，审批真实学生数据和试点G09。当前采集分组只是开发演练，不是RCT或因果结论。
3. **真实媒体与供应商**：用户另行确认费用、北京密钥/权限/实际价格、素材授权；再执行[112号方案](../调研/112-OpenMAIC外部媒体服务选型与首轮预算方案.md)首批；其他Provider逐家真实连通/协议/故障验收，不把适配代码当实测。
4. **运维与治理**：正式保存期限、备份/外部产物销毁、HTTPS和Cookie安全配置、容量/告警/成本对账；生产独立恢复演练及更多浏览器。当前专用删除默认预览，必须停服确认和备份，不通过在线接口解除不可变记录约束。
5. **体验与调度深化**：更细的课程跨活动建议、保留题库与新变式核验、首次可学习时间/等待恢复/成本指标；按证据评估追问质量，而非仅增加自动化次数。大前端主包按真实首屏性能需要进一步拆分。

这些是明确保留的后续工作，不改写成“已完成”或用模拟数据生成教学有效结论。
