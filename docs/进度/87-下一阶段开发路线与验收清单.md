## 1. 从哪里开始，以及最终要交付什么

**下一次编码先做 G00，再做 G01；第一条新能力以“有理数运算与依据”走通全链路。** 目标不是再手写一个有理数圆桌包，而是让主题、知识来源、课程/活动生成、核验和发布成为通用能力。

完整体验：输入主题 → 必要澄清/检索 → 已核验诊断 → 课程规划与学生确认 → 自动生成课程/资源/陪学/圆桌/我教 AI → 核验及所需审核 → 同项目自动适配 → 学生思考与渐撤 → 无 AI 即时/延迟检验 → 学情/素养证据 → 新计划和 Skill 候选 → 评测、审核、版本生效/回滚。

### 三个交付波次

1. **主题驱动的通用闭环（G00–G04）**：解决固定单元/概率硬编码的限制，先本地已授权资料与 Fake 验证机制，再按新批准预算接模型/搜索。
2. **资源与学情完整化（G05–G07）**：接 OpenMAIC 资源生产；成长证据、素养、课程策略与实际 Skill 消费到位。
3. **受控进化与试点（G08–G09）**：先离线 Skill 候选进化/评测/人工选择，再补专业审核、真实数据治理与试点。自动真实 RSI 仍受原启动门限制。

68 的三步计划保留历史定义；其中剩余成长证据、内容/试点项纳入本计划。此处增补并重排依赖，没有把旧任务直接标为完成。

## 3. 跨模块依赖与最小技术顺序

1. **先消除旧硬编码入口的扩展障碍**：统一内容仓储和版本，不直接再往 `ACTIVITY_PACKS` 添加一批主题常量。
2. **先来源/Schema，再生成**：搜索结果、教材片段和学情都是有标签的输入，生成 Agent 不能用输出反过来证明来源可靠。
3. **核验与生成并行开发**：有理数生成器和独立验证器先配对交付；暂不能判定的几何证明保持待复核。不能等“全自动课程写完”再补数学正确性。
4. **内容自动化和人的选择并存**：AI 自动生产/检索/检查，学生确认学习目标；专业审核与高风险发布保留人工职责，不让人手工替 Agent 编完每道题才算功能可用。
5. **素材覆盖先于素养分数**：先交付可追溯材料/未评阅状态及图形，再由审核过的量规驱动评定。
6. **Skill 先可执行、再进化**：G07 先证明版本会影响真实动作；G08 才评测是否改进，不能只改文件名或文案。

## 4. 第一条有理数全链路验收剧本

以下是后续开发验收剧本，不是当前可点击的功能，也不发送真实模型请求：

1. 学生新建项目，输入“负数乘除和运算顺序，想说明每一步依据”，确认范围，不要求项目标题含“有理数”。
2. 检索返回知识点/前提与合法来源，准备少量核验后的诊断。若没有可用来源/验证能力，显示具体缺口。
3. 学生作答并讲解，系统保留未知的解释质量；课程草案根据已观察证据与目标生成，学生确认。
4. 自动产生本次范围内的课时、任务、分级支架、资源、圆桌和我教 AI；每个产物显示数学检查、来源和待审核范围。
5. 发布后，学生从陪学切圆桌/我教 AI 都自动使用本项目同课程单元，不再选概率；圆桌能处理“已有充分依据”而不硬编反对。
6. AI 在不同后续任务逐步减少步骤性帮助，让学生先提出检查问题；学生卡住可求助，不以减少提示数强行当进步。
7. 独立任务不带历史答案/辅助；有延迟回访。题目曝光、验证状态和解释评阅分别入库。
8. 成长页可点击 KC/素养证据材料回到原始贡献，未知维度保留缺失。
9. 规划提出下一轮课程调整，Skill Agent 给出有依据 diff；隔离回归可拒绝不合格版本，批准版本只影响后续新任务并可回滚。
10. 断网、worker 重启、模型未知结果、取消、归档、撤回来源/资料或预算不足时，已保存记录不丢，迟到结果不能激活新版本。

完成这条链后，再用函数与几何/统计主题验证通用性和拒绝边界，而非对每个主题复制一份有理数特例代码。

## 5. 自动化指标和真实教学指标分开

| 类别 | 看什么 | 不接受的替代指标 |
|---|---|---|
| 工程 | 版本一致、恢复/取消、隔离、成本/时延、失败原因、产物可追溯 | 请求 200/202 就叫课程完成 |
| 内容 | 独立数学检查/专业审核、条件完整、无泄题、来源真实、活动与目标一致 | LLM 自评高分或多角色一致 |
| 学情 | 来源覆盖、缺失/不确定性、评分一致性和校准，跨项目口径明确 | 互动次数直接变素养分 |
| 教学闭环 | 可比的无辅助、延迟、迁移与学生自主检查证据 | 提示减少、完课率提高、对话增加就宣称增益 |
| Skill | 冻结回归/未见题族、受控对照、硬约束、人工批准、回滚 | 自动生成一份 SKILL.md 就叫 RSI 成功 |

课程/资源生成的新测试集按题族隔离构建/调参/冻结评测，记录生成种子、模型和来源。系统生成的测试参考同样要独立验证；不能把模型既当出题者又当唯一裁判。
