# 有理数教学 Agent：动态课程首轮开发验收

日期：2026-10-19。API0.19.0，数据库`g08_001`，主服务4003。原V12与106号入口整合继续保留；本篇记录主题驱动教学的新增实现及边界。

## 1. 本次目标与实际落点

将有理数从单一`a/b+c`、固定七项生成候选，扩展为“明确目标→准备数值观察→模型设计课程与活动→独立核验→人工发布→目标化引导”。

| 能力 | 实现 |
|---|---|
| 目标澄清 | 七类概念、每轮1–3项；宽泛主题或目标过多先澄清，不直接调用模型 |
| 课程设计 | 模型读取目标、分概念观察、焦点、来源与已曝光参数，生成5–11项有阶段的任务、概念支架、安排理由 |
| 多题型 | 数轴移动、相反数、绝对值、两点距离、较大数、加、减、乘、除、除后加、括号加后乘，共11种结构化问题形式 |
| 活动分工 | 模型为圆桌/我教AI各选练习目标与私有验证题；概念比较、讲解问题独立设计并审核 |
| 运行适应 | 练习根据数值未通过/不可验证、已用提示、无提示通过，选择表示核对、继续支架或自查；显示决策事实依据 |
| 即时模型引导 | 模型根据本轮表达选择该课程已审核的概念问题方向；保留引用、白名单与输出门禁 |
| 兼容与治理 | 新内容带`rational-agent.v2`标识；旧生成请求沿原编译器，旧题/旧运行版本不重写；新来源可撤回 |

Agent可以决定目标内的题型、数量、排序与教学文本；数学题干和参考值由编译器确定。依然保留目标白名单、数值形式、阶段和审核边界，不是任意文本数学问题的全面自动核验。

## 2. 代码结构

- `generation/rational_agent.py`：有理数目标、结构化问题、独立真值、候选Schema、课程/活动编译与模型请求。
- `generation/service.py`：LangGraph准备流程、幂等目标请求、分概念观察、版本化请求、核验与审核衔接。
- `learning/content_contracts.py`：类型化概念支架；非练习阶段不附加提示库。
- `learning/content_repository.py`：根据已审核内容构建目标化圆桌/讲解材料。
- `learning/tutor_graph.py`：v4内容消费者、可解释支持决定，保留固定数学和检测关口。
- `generation/interaction.py`与`learning/output_gate.py`：本轮模型选择已审核课程问句；历史读取重复执行受控渲染。
- 学生主题页提供目标、1–3项重点、设计理由；陪学提供支持依据。管理端显示设计并要求人工检查语义与泄题。

## 3. 独立检查范围

1. 参数类型、数量、绝对值界限、零除、比较不同数等条件。
2. Fraction精确计算，模型参考值不一致即拒绝。
3. 所选目标在练习与检测均有覆盖；活动引用有效练习并验证同目标。
4. 准备诊断、主任务、两项活动验证问题不重用；加、乘、距离、较大数交换参数也按同题拦截。
5. 诊断、练习、检测阶段顺序与数量上限；检测无提示/资源。
6. 来源存在、版本一致、未撤回；来源撤回阻止新准备和已有候选继续发布。

以上不证明讲解正确、教学适切、图形理解、未见迁移或学生学习收益。自由讲解与问题是否泄题仍需人工审阅；不能用字符串检查替代完整语义核验。

## 5. 运行与兼容说明

本次无需迁移数据库。主预览需要加载新版API和教学/模型worker，已有课程保持原快照。新增参考来源独立于旧有理数来源，未修改原有正文哈希。

本机已确认无排队教学/在途模型调用后加载0.19.0，核对API及两个worker进程；4003健康检查、学生课程页、管理生成页均返回200，实时OpenAPI含`agent_mode`。主配置仍为DeepSeek且课程/互动开放，OpenMAIC预算维持`enabled=false,calls=8`。

策略继续按新任务冻结；四类受限参数的权限、数学核验、次数额度和检测隔离未放宽。消费者源码变化会使此前G08机制报告签名过期，需按原门禁重新评测，不强行批准旧报告。

DeepSeek已有课程/互动开发配置继续适用，输出与总调用上限不增加；OpenMAIC首轮预算保持停止，不能把课程生成成功理解为资源自动生成。

## 6. 仍待完善

- 主题识别与概念选择仍有规则和白名单；两道准备探针由程序构造，不是开放模型诊断所有理解。
- 运行支持选择仍含规则；本轮没有自由改变在途题库或追加未经审核题目。
- 当前即时模型选择审核问句，没有开放任意未审自由回答，也没有自动解释/素养评分。
- 仅一次真实样本，缺少覆盖七类目标及不同准备表现的真实多轮对照和专业数学评阅。
- 已支持目标不是完整初中数学课程；乘方、一般证明、分数多步情境等仍需扩展核验器。
- 真实学生、自动RSI发布及教学效果验证继续待后续建设。
