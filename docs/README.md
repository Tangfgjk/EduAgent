1. [项目概览](项目概览.md)：项目要做什么、面向谁、如何判断有效。
2. [交接文档](交接/HANDOVER.md)：原负责人留下的基线、30/60/90 天路线及注意事项。
3. [当前状态](进度/当前状态.md)：依据工作区代码与交接材料区分已实现和规划项。
4. [总体架构](架构/01-总体架构设计.md) → [融合方案](架构/08-融合方案与优势说明.md) → [实施方案](进度/10-实施方案_v1_融合基座与进化就绪.md)。

## 文档阅读约定

- 01–09 是设计基线，10 是实施蓝图，11 是较新的 UI 规格；同一主题有差异时，先看较新的明确裁决，再核对代码。
- 交接文档记录的是 **2026-09-28 交接时** 的判断和测试结果，不代表今天重新验证后的结果。
- 调研目录中四份 PDF 是扫描/图片型文件，当前文本抽取结果为空；项目内已有 [三方案对标](调研/09-三方案对标与吸收.md) 可用于查找它们对设计的影响，引用原件细节时仍需人工核对页面。
