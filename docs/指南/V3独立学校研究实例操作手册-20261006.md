# V3独立学校研究实例操作手册

记录时间：2026-10-06 20:17（Asia/Shanghai，UTC+08:00）。当前功能用于本地受信研究准备，不是production SSO。与个人8000实例及仿真数据库隔离，默认新端口8012。

在platform目录使用现有Python3.11.5虚拟环境。root必须指定专用实例目录；不要指向既有个人实例数据。

## 离线创建账号

```powershell
.venv/Scripts/python.exe scripts/school_instance.py --root data/school-demo provision --tenant demo-school --class-id class-g7 --username learner-demo --role student --learner-id demo-school-learner
.venv/Scripts/python.exe scripts/school_instance.py --root data/school-demo provision --tenant demo-school --class-id class-g7 --username teacher-demo --role teacher
.venv/Scripts/python.exe scripts/school_instance.py --root data/school-demo provision --tenant demo-school --class-id class-g7 --username parent-demo --role parent
```

CLI会通过不可回显输入框询问密码和确认；按用户指定的本地开发密码设置即可，不把密码/散列写入公开文档、命令行、日志或Git。输出的account ID用于下一步受信关联。创建功能没有HTTP注册入口。

## 关联教师/家长

把下面占位符替换为上一步对应teacher/parent的服务器account ID：

```powershell
.venv/Scripts/python.exe scripts/school_instance.py --root data/school-demo assign --actor-id <teacher-account-id> --learner-id demo-school-learner --tenant demo-school --class-id class-g7
.venv/Scripts/python.exe scripts/school_instance.py --root data/school-demo assign --actor-id <parent-account-id> --learner-id demo-school-learner --tenant demo-school --class-id class-g7
```

双方必须同tenant且当前都在class-g7；跨tenant或class关联拒绝。真实监护关系或机构权属需人工验证，CLI不会假造或自动确认。

## 独立启动

```powershell
.venv/Scripts/python.exe scripts/school_instance.py --root data/school-demo serve --port 8012
```

仅绑定127.0.0.1，禁止使用8000端口，关闭access log，不改变原服务。数据为`data/school-demo/school-directory.sqlite3`与`learners/<sha256>.sqlite3`；该data目录应保持Git忽略。

API客户端先POST `/api/school/login`，请求只含tenant_id/username/password；返回bearer供后续`Authorization: Bearer ...`。不要在文档或截图公开token。退出调用POST `/api/school/logout`。使用loopback Host；若浏览器带Origin，它必须与请求服务的scheme/host/port完全相同，不支持跨站入口。

学生先在自己的`/consent`端点授权teaching（或scopes=[]撤回），再用`/assessments`取metadata，`/issue`获取题干和delivery_ref，`/hint`记录帮助，`/submit`提交ticket和作答。教师/家长仅assignment还不能读取：学生在自己的`/sharing`提交audiences=["teacher"]或["parent"]及expected_revision=0显式开启共享。再次修改要使用上一revision；audiences=[]撤销全部共享。更新consent版本会使旧共享失效，需学生重新明确授权。

教师需要assigned+teacher共享+当前teaching授权；家长需要assigned+parent共享，且仅返回summary，不给原作答/证据引用。两者不能代学生授权、开启共享或答题。

旧个人API、teacher token、parent token、governance写端点、`/api/agent/*`和任意内部路由均不在学校服务公开面。需要完整教学会话/教师工作台或SSO时，按架构契约另行实现，不用开放旧highpriv代理绕过角色边界。
