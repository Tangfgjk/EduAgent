# V4 数据库交接与恢复说明

更新时间：2026-10-07（Asia/Shanghai）。适用分支：`V4`。

## 是否必须携带数据库

不必须。别人拉取 V4 代码后，可以使用代码中的课程资产启动一个新的空 SQLite 数据库，完成页面和功能体验。数据库快照只在以下场景需要：

- 复现当前这台机器上的学习目标、作答记录、学习状态、计划和审计事件；
- 在另一台本地机器继续当前演示账号的研究型 MVP 状态；
- 做数据迁移、备份恢复或故障排查。

它不是发布依赖，也不是 GitHub 代码的一部分。没有快照时，首次启动会按配置创建 `platform/data/rsi.sqlite3`；课程题目来自 `platform/seeds/`，不依赖个人数据库才能展示。

## 重要安全边界

该目录被 `.gitignore` 的 `platform/data/` 规则忽略，不会随普通 `git add .` 进入提交，也没有推送到 GitHub。快照未脱敏、未加密，`public_distribution_approved` 为 `false`。不要把它上传到公开仓库、网盘或发给无权限人员。

快照不包含 `.env.local` 中的登录密码哈希、教师/家长 token、LLM API Key，也不包含 Simulation Lab 输出、PostgreSQL 归档、源附件或外部凭据。交接时仍需由接收方自行配置 `.env.local` 和新的凭据；不要复制原机器 cookie。

## 在新机器上恢复到新文件

先完成代码安装并停止使用目标数据库的服务。建议恢复到新文件进行检查，不要直接覆盖已有数据：

```powershell
cd C:\Users\<用户名>\Desktop\桂子问津EduAgent\platform
Copy-Item 'data\数据库交接快照\V4学习主库完整数据-20261006-233028\v4-learning-main-full-20261006-233028.sqlite3' 'data\rsi-restored-20261007.sqlite3'
$env:WENJIN_DB_PATH=(Resolve-Path 'data\rsi-restored-20261007.sqlite3').Path
$env:WENJIN_LEARNER_ID='demo_student_001'
.\.venv\Scripts\python.exe -m app.operations.cli --database $env:WENJIN_DB_PATH --learner-id $env:WENJIN_LEARNER_ID health
.\.venv\Scripts\python.exe -m app.main
```

如果启用本地登录，需要在 `.env.local` 设置接收方自己的 PBKDF2 密码哈希；快照中的学习数据不会自动赋予登录权限。恢复后应先确认 `health`、课程版本、学习者 ID 和授权状态，再访问工作台。需要恢复为正式 `data/rsi.sqlite3` 时，先备份目标文件，并保留原文件，不使用覆盖式恢复。

## 重新生成快照

快照脚本位于本次快照目录中，使用当前配置的数据库并采用独占新文件名，不会覆盖旧快照：

```powershell
cd platform
$env:PYTHONPATH=(Get-Location).Path
.\.venv\Scripts\python.exe 'data\数据库交接快照\V4学习主库完整数据-20261006-233028\export_snapshot.py'
```

如需长期保存或跨系统交付，先做脱敏、加密、访问审批和保留期限评估；当前文件只适用于本地开发交接，不构成生产备份或合规归档。
