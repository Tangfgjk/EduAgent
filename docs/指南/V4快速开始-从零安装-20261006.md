# V4 快速开始：从零安装

适用：Windows、Linux、macOS；V4 为用户授权的本地研究 MVP 收口分支，来自已发布 V3 基线。本地 P0 完成，冻结全量与浏览器通过；发布/远端CI待实际执行，见[最终验收记录](../测试/V4最终集成验收与发布记录-20261006.md)。

## 获取代码

```bash
git clone https://github.com/Tangfgjk/EduAgent.git
cd EduAgent
git switch V4
```

若远端尚未提供 V4，可先切换到 `V3` 验证当前代码，等待分支推送完成。不要使用个人机器路径、个人密码或提交 `.env`。

## Python 与依赖

使用 Python 3.11，并安装 uv。

```bash
cd platform
uv sync --locked --extra dev --no-editable
```

复制 `.env.example` 为本地 `.env`（若需要），只填写本机配置；开发默认使用 SQLite 和离线模型。PostgreSQL 仅按 V3 Repository 文档显式启用，不能据此理解为整个平台已迁移。

Windows 中文仓库路径下 Python 3.11 读取 editable `.pth` 曾触发 GBK 解码错误，因此统一用 `--no-editable` 安装；运行请保持 `platform` 为工作目录以读取当前源代码。新增 dev-only Ruff 0.15.7、mypy 1.19.1、pytest-cov 7.0.0，锁含54包；安装原因、传递依赖和局部门命令见[V4工程验收](../测试/V4工程基础与增量质量门验收-20261006.md)。

## 启动与测试

```bash
uv run --no-sync python -m app.main
uv run --no-sync python -m pytest
```

浏览器打开 `http://127.0.0.1:8000/`。Simulation Lab 使用独立端口：

学生页保留原深色风格和六个顶部标签；教师 `/teacher`、家长 `/parent`、本地操作 `/research` 使用独立职责界面。它们不是学校生产 RBAC/SSO；学校独立 root/8012 实例仍单独配置。

```bash
uv run --no-sync python -m app.simulation.lab --port 8001
```

按功能查入口、请求和限制请读[V4功能操作与技术参考](V4功能操作与技术参考-20261006.md)；按领域核对当前能力和后续门槛请读[V4功能覆盖与限制矩阵](../测试/V4功能覆盖与限制矩阵-20261006.md)。

端口、输出目录和浏览器自动化路径应通过命令行或环境变量配置；不要把缓存、截图、数据库和凭据写入 Git。

普通工作台浏览器验收在仓库根目录执行 `node platform/scripts/v4_browser_smoke.cjs`；脚本自行启动隔离 8132、生成随机测试凭据且不读取 `.env.local`。需安装或显式指定 Playwright/Chrome；不要手工先启动历史 fixture，也不要用个人 8000 数据验收。
