# V5 工作台与项目学习使用手册

## 2026-10-09 实际操作速查

- 只想做题：打开首页 → 选知识点 → 写答案 → 点“提交答案”。当前题目和提交验证使用同一个任务，不再自动开启另一道自由探究题。
- 不会做：点“给我一点提示”；换题会清空当前页面对话并重置提示标记，不删除数据库历史。
- 长期任务：进入“计划”，填写项目名称、添加任务，点“保存项目”；顶部选择该项目后再作答。待办在计划页查看。
- 快速讨论：点“临时会话”，起名后输入消息；结束后返回正式学习。未配置模型时只能收到明确标注的离线回复。
- 看变化：进入“成长证据”，选择全局或项目范围。没有评估数据不等于零分。
- 规划规则：生成候选 → 阅读内容 → 审核或退回；审核状态不等同于自动执行或修改全局教学规则。

本轮隔离浏览器测试覆盖项目创建、待办更新、项目作答关联、成长范围、复习预览、离线圆桌、规则候选审核与回滚、临时消息隔离及设置入口。尚未验证真实模型质量、到期复习完整作答、教师/家长/研究工作台所有流程。复习和圆桌仍需补齐严格的项目级范围约束；不要将目前的页面切换视为后端隔离已经完成。

试用时曾在本地正式学习者下提交一条测试作答（2x + 1 = 7，答案 3），该记录未删除。之后的写入回归使用独立内存数据库。

## 先理解两条工作路线

“正式项目”用于陪学、复习、成长证据和圆桌探究的长期整理。项目可以保存任务、会话、作答证据和知识来源，项目内成长证据只读取项目引用的证据。

“临时会话”适合快速讨论、试问和不确定的想法。临时会话有独立上下文，页面会明确显示“不会进入正式画像”；它不会写入正式学习证据，也不会改变计划或掌握状态。

## 建议操作顺序

1. 在“设置”保存教学用途授权。
2. 在“计划”输入目标，查看课程覆盖范围，再审阅并签署计划。
3. 建立正式项目，在项目中添加待办任务。开始陪学前先在顶部选择项目。
4. 项目内的作答和陪学会话会自动关联到当前项目；归档项目不能再接收新证据。
5. 在“成长证据”切换“全局宏观”或某个项目，查看掌握轨迹、独立作答、提示使用和素养维度。
6. 在“规划 Agent”输入主观反馈、教材/资料和课程标准/考纲。系统只生成候选 `Skill.md`，需要人工“审核通过”后才成为可用版本；退回或回滚都会保留版本记录。

## 素养雷达如何解释

雷达包含自主规划、自我监控、证据推理、问题解决、合作交流、反思迁移。没有明确素养评估时显示“待积累”，这表示证据不足，不代表零分。面板会显示来源和评估说明。

## 新用户与演示数据

默认不注入模拟成绩。若需要演示，应使用独立的演示学习者或明确的 `synthetic_demo` 数据源；演示数据不能混入正式学习者的 `learning_evidence`，也不能用于自动晋级。

## 当前边界

规划 Agent 是本地候选生成器，不会自动修改全局 `Skill.md`、自动晋级课程或宣称学习效果。互联网搜索、向量检索和自动 RSI 进化仍属于后续工程范围；当前系统使用已准入的本地来源和人工审核。

## 运行与验证

在 `platform` 目录运行：

```powershell
$env:TEMP = "$PWD/.tmp-test"
$env:TMP = $env:TEMP
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m compileall -q app
```

本地数据库继续使用项目已有 SQLite 抽象。数据库密码不写入代码、文档或日志；只有明确接入 PostgreSQL 时才配置外部连接。
