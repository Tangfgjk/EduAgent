# 本地操作手册：V3仿真实验与治理

记录/更新：2026-10-06 20:33（Asia/Shanghai）。适用 `V3`；已获用户授权验收后提交推送，仅V3。

## 环境与启动

Windows + Python3.11.5；项目 `platform/.venv`，SQLite3.41.2；沿用uv锁46包，无新增Python/npm包或数据库安装。既有PostgreSQL16.15除了归档，新增可显式实例化的学习域主存储Repository；正常Web/学校应用仍SQLite，不要配置一个DSN就宣称整个平台迁移。密码/DSN仍仅忽略的本地配置，不复制进Git文档。

在仓库根进入 `platform`。普通深色学习页：

```powershell
.\.venv\Scripts\python.exe -m app.main
```

访问 `http://127.0.0.1:8000/`。读取本地用户配置/数据；不要用个人账户自动压力/破坏测试。本轮未重启已有8000，修改代码后需正常退出/重启服务才加载新实现。不要按Python进程名批量停止。

独立实验室：

```powershell
.\.venv\Scripts\python.exe -m app.simulation.lab --port 8001
```

访问 `http://127.0.0.1:8001/`。端口占用选空闲端口，例如 `--port 8003 --output-root data/simulation-qa`，不要抢占其他服务。只绑定loopback；无需个人密码，页面取得当前进程同源nonce。选择画像、场景、seed和1至100回合，运行后查看轨迹/报告或下载。可信output_root为CLI参数，不接受HTTP路径。

每root仅允许一个owner进程、一个活动作业；SQLite专用exclusive锁自动随进程退出释放，另一个应用启动拒绝。作业状态/请求/报告/run映射持久保存，页面显示最近20条，旧job仍可按ID读取。queued重启后执行；running/stopping若进程中断，不静默新建学习者：标记interrupted，检查点存在才开放显式resume，并继续校验课程/引擎/授权；没有检查点保持不可恢复。进程重启nonce轮换，旧nonce不可写。历史未自动删除，保留策略需运维负责人确定。

停止是回合间合作取消，本地API先完成。只有预算停止/超时可恢复，主动退出/失败/unsupported不可恢复；完成重复resume返回已有报告。源码、画像、原题库或冻结课程hash变化后恢复拒绝，应新建run，不改旧manifest绕过。默认60秒回合间预算，不承诺远程阻塞硬取消。

## CLI实验

```powershell
.\.venv\Scripts\python.exe -m app.simulation.runner --profile autonomous --scenario baseline --seed 17 --turns 10
.\.venv\Scripts\python.exe -m app.simulation.experiments --turns 20 --seeds 17 29
.\.venv\Scripts\python.exe -m app.simulation.assessment --profile autonomous --seed 17
```

- Runner调用真实教学路由的隔离ASGI实例，复用Verifier/LearningService/SessionRuntime/Governor。不连接8000、不加载.env.local/Key/真实DSN。
- experiments顺序跑六画像×五场景×seed17/29。CLI不再有旧--workers选项。基线与候选按画像/seed/冻结引擎/课程/预算配对，描述性bootstrap/Wilson不当真人置信推断；seed17与一半题拟合、seed29与另半题留出只产生候选。不是共享后端压测，参数不写回。
- assessment冻结待审核24题课程，跑前测/练习/后测/迁移/第7.5与13.5天到期复习。数字答案不证明推理rubric或远迁移效度；无due任务时记录deferred/缺项，不伪造旧task。
- seed控制结构化轨迹，不控制UUID、时长和审计墙钟。逐KC潜变量仍是模型假设，不是真人真值。报告不能用于学习效果宣传或替代真实校准。

输出在忽略的 `platform/data/simulation/`、`simulation-expanded/` 与 `simulation-assessment/`；每run独立SQLite、课程快照、manifest、latent、evidence/report/transcript。manifest记来源、seed、画像、课程/源码hash；旧引擎报告不混入新配对。latent仅实验侧，不发送给教学策略。不要将实验数据库合并/归档成真人证据，导出来源始终synthetic；旧版本实验留历史，不直接resume。

## 服务器测量凭据

正常Settings.load默认 `RSI_ASSESSMENT_REQUIRE_TICKET=true`。先POST `/api/learning/assessment/{learner}/issue`，带assessment_id/version与唯一issuance_id，获得stem/delivery_ref；提交带该delivery_ref及同题版本、唯一attempt_id、answer、occurred_at。普通发题使用服务器时间；只有显式仿真实例接受模拟occurred_at。

提示使用 `/hint`，服务端记录且不能降级/隐藏；凭据24小时有效、绑定当前Consent和内容hash，只消费一次。修改已提交答案需新凭据；重复暴露不计独立前后测。浏览器自动办理这些步骤。可信历史只覆盖本平台，不证明无人在平台外辅助；历史无凭据记录不伪回填成独立。
