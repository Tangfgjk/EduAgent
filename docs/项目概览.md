# 桂子问津项目概览

## 项目要做什么

“桂子问津”（Wenjin）的目标是做一个面向学生、教师的教育伴生智能平台。学生端的学伴“津津”应陪伴学习者完成 **设定目标 → 制订并确认计划 → 学习与探究 → 验证和反馈 → 反思 → 调整计划** 的自我调节学习闭环。产品以项目/模块化工作台为入口，优先让学生自主完成任务，而不是把 AI 变成答案提供者。

教师端的长期方向是辅助教师查看有证据的班级学情、复核系统建议、纠正不合适的教学行为；教师纠正可成为后续改进系统的高质量反馈。研究设计中的两项 AgentSociety 实验是可并行的研究线：一项研究同伴建议核查，一项研究教师帮助分配与纠错传播，并非当前平台已上线功能。

## 核心期待

1. **学习价值可验证**：重点看撤除 AI 帮助后的表现增量、认知层级提升和学习自主性增益。完课率、互动量只能辅助诊断，不作为主要效果证据。
2. **教育原则由机制保证**：用结构化学习者状态、教学动作、提示阶梯、状态机和硬规则约束教学行为。学生保有计划最终决定权；提示逐步升级且随能力与自主性增长而撤除；考试模式限制帮助；探究任务保留学生的过程所有权。
3. **估计有边界、数据有归属**：误区与状态是带不确定性的假设，学生可查看自己的学习模型；教师/家长按角色最小可见。对未成年人数据实行同意范围、审计和撤回机制。
4. **先建立可信数据与评估，再考虑自动进化**：交互事件、验证结果、教师纠正和真实后测构成证据链。自动策略优化、数字孪生晋升与权重级改动须经过校准、真实实验和治理门槛，不能因为模拟结果好就直接用于真实学生。

## 设计与当前版本的关系

交接包描述了六层总体架构：伴生层、学习科学引擎、多智能体协作层、可探究环境、进化层和治理层。面向用户的产品壳采用项目优先的工作台；教学内核采用“生成内容 + 符号规则/验证”的组合。设计范围明显大于当前工程。

现有初版已经包含 FastAPI 网关、静态 Web 工作台、学习智能体 CLI、学习状态/动作模型、R-01 至 R-10 规则、提示阶梯、简单知识追踪与数学验证、SQLite 事件与快照、路径推荐和成长证据接口，以及 L0 沉淀演示。教师工作台、完整派生体系、三层记忆巩固、Postgres、冻结回归集、可信数字孪生和自动进化仍是后续工作。具体核对见 [当前状态](进度/当前状态.md) 与 [实施方案](进度/10-实施方案_v1_融合基座与进化就绪.md)。

## 近期方向

按交接路线，先补完 M1：学习引擎适配、可验证的派生角色、记忆巩固、数据持久化与回归场景。随后进行真实学习者小范围试运行，积累撤除帮助后的表现、自主性和教师反馈等基线。自动 RSI 的启动以实施方案 §9.3 的五项量化条件为前提。
