# V3合成学习者仿真实验子系统设计

建立时间：2026-10-06 17:33；实现回填：2026-10-06 18:22（Asia/Shanghai，UTC+08:00）。状态：本地实现并测试，真实效果/远程模型/学校生产能力未验证。
决策：[模拟器采纳与边界](../决策/V3合成学习者模拟器采纳决策与边界-20261006.md)。

## 定位与功能入口

单独功能，属于开发者/研究者的“仿真实验室”，不是学生学习页面里的伴聊角色。首版CLI/自动化场景运行即可，稳定后再加独立开发者页面，支持选择课程版本、画像、seed、回合/成本预算、运行/停止、轨迹与报告。默认关闭，不对外暴露控制端点，不把它嵌入正常教学Runtime循环。

独立的是客户端和实验状态，复用的是桂子问津应用代码：通过隔离的应用实例调用与真人相同的API，使用相同Verifier、LearningService、SessionRuntime和Governor。模拟实例内可以生成合成Evidence并更新该实例的Mastery/Retention，用于测试完整主链；禁止写真人实例。不是维护第二套教学算法。

## 模块职责（实际实现）

```text
platform/app/simulation/
  schema.py       画像/动作/快照/场景/运行manifest/结果契约
  learner.py      隐藏状态、受seed控制的行为与答案/误区规则
  client.py       公开API白名单、隔离应用实例配置与观察投影
  runner.py       显式时钟、多轮调度、恢复、停止、预算
  evaluator.py    离线评估、配对比较、失败样本与限制
  policy.py       Governor约束下的渐撤候选策略
  experiments.py 六画像/五场景/跨seed拟合留出/独立实例负载
  assessment.py   冻结审核课程的前后/迁移/到期复习API测量
  renderer.py     有限表达Provider与schema/模板回退
  lab.py          loopback独立Web作业服务
platform/data/simulation/{run_id}/
  runtime.sqlite3 该run的教学实例合成状态
  catalog.json / question_bank.json  实际课程/题库快照
  latent.json     仅实验侧隐藏状态与随机源快照
  manifest.json   版本、seed、环境、课程/策略hash、来源
  transcript.jsonl / report.json
```

生成结果沿用被忽略的 `platform/data/`，版本化画像和场景不含真人资料。`runtime.sqlite3`和latent快照是两类状态，不把模拟器隐藏状态写入教学数据库。现有 `TeachVirtualStudentRunner`继续留在agents中，不迁移或合并。

## 现有代码约束与接入

- `gateway/routes.py:create_app(Settings)`已有应用工厂；模拟runner须显式注入全新的DB/workspace/catalog等配置，不调用 `Settings.load()`继承本机 `.env.local`、真人token、真实DSN或API Key。
- 当前learning API只允许 `settings.learner_id`（单用户），因此第一版每个模拟学习者单独应用/存储上下文，不能直接向8000当前个人实例提交 `sim_*`。跨学习者共享后端负载实验要先实现相应身份契约，不能靠放宽local检查。
- 可在隔离应用上用ASGI/TestClient调用公开路由：这是“同API协议的进程内闭环”，不是网络端到端。后续真实HTTP压测单独绑定localhost测试端口，并记录与生产不同的拓扑。
- 现有 `allow_simulated_time`支持隔离评测时间，但会话和审计还有 `utcnow()`调用。完整重放需要可注入时钟/稳定事件标识或明确的轨迹规范化，不能仅设置seed就声称所有墙钟字段相同。
- 当前LearningEvidence没有显式source_kind字段。必须通过受信的模拟运行配置与manifest标记来源，导出时由受控适配器写 `synthetic_ai_generated`，不能让客户端自由声明real来源。需要扩展核心契约时走版本迁移及回归，不擅自在现有extra=forbid模型中塞字段。
- 隔离实例中的授权是测试授权，标记 `simulation_fixture`，不伪造真人同意、监护人同意或教师签名；教学/撤回逻辑仍通过公开端点测试。

## 状态、动作与信息边界

画像初始条件和隐藏状态属于人为构建的假设模型，所谓 `true_mastery`只表示“该仿真模型内的潜变量”，不是人类真实知识真值。掌握概率、召回概率、作答成功概率必须分开；猜测、失误和援助会影响作答，不能直接将潜变量当答对概率。

客户端可见：题干、KC公开标识、已接收教学动作、提示级别、作答/自检/求助文本、计划确认操作。禁止把latent数值、profile标签、答案key或系统对该人的隐藏估计送给教学策略作为输入。评估器可按单独只读观察接口读取系统公开估计，不能供行为生成器作弊。

确定性答案模型可使用离线题型结构/评分key作为计算oracle，但oracle不进入renderer或学生请求；它按画像和误区生成答错/猜测/正确响应，而不是每轮复制答案。首版只支持已声明可解析的一元一次方程题型，其他题型明确unsupported，不随机编造可验证答案。

LLM renderer若后续启用，只收到已定动作与可见上下文；输出校验必须保留动作、答案和援助标签，越界或失败回退模板。隐藏状态变更只能由版本化结构化规则执行。

## 反偏差与复现

- 至少包含多套不同学习/遗忘假设，包括零学习增益、强提示依赖、不同猜测/失误率；不能仅用“支架有效”的内建规则证明支架最好。
- 生成器不能复制被测BKT更新公式后再宣称验证了BKT；同模型恢复实验与跨模型鲁棒性实验分开命名。
- 使用版本化配置、课程hash、主seed与按画像/场景/回合/机制划分的随机流；比较策略时固定初始条件，避免不同调用次数使随机数序列偏移。
- 确定性核心同配置/seed/时钟可重放结构化事件；UUID/运行时间字段需稳定生成或从等价性比较中明确排除。失败、退出和停止也保留轨迹，不只报告成功样本。
- 远程LLM版本/采样/延迟可能不可重复，报告单独标“不保证语言级确定性”，保存脱敏生成结果与成本，不承诺seed控制外部服务。

## 实验与指标

| 类别 | 合法指标 | 注意事项 |
|---|---|---|
| 潜在状态识别 | 估计与仿真潜变量的MAE/RMSE、分画像误差 | 不是人类认知真值误差，必须同一时点同KC |
| 作答预测 | 预测下一次无辅助通过概率的Brier、校准误差 | 必须对二值作答结果评分，不直接拿p_mastery当通过概率 |
| 仿真学习 | 新题无辅助表现、提示/答案依赖、模拟保持、退出 | 任务与援助日志可比，量化模型假设敏感性 |
| 可靠性 | 收据重复、CAS冲突、丢/重复事件、恢复一致性 | 遵守正常Governor，先低预算增加规模 |
| 负载 | 成功/错误数、p50/p95延迟、资源、队列、调用成本 | 一人一实例压测不等于共享多租户吞吐；PG归档不等于主存储 |

策略对照只能选Governor允许的候选。“始终提前给完整答案”不是允许上线的策略；优先测试其被R-01拒绝。需要研究答案暴露的仿真假设时，在仿真器离线反事实模型中做，并标 `offline_counterfactual`，不关闭系统R-01/R-07，不向真实用户发送。

报告固定包含 `source_kind=synthetic_ai_generated`、`evaluation_kind`、所有版本/hash/seed、样本单位、失败/缺失计数、假设/范围和 `educational_effect_claim=false`、`automatic_promotion_enabled=false`。结果只能生成候选，不改运行参数或confirmed plan。

## 实施与验收分层

| 阶段 | 交付 | 前置门 |
|---|---|---|
| S1a | 契约/六画像/误区/隐藏状态/确定性行为与独立存储 | 来源标记、路径隔离、隐藏状态拒泄漏、预算、snapshot/RNG单测 |
| S1b | 同API隔离实例多轮Runner、评估和5组基础场景 | 公开接口、计划签署、assistance一致、时钟、撤回/恢复、真人库不变 |
| S2 | 多模型假设敏感性、预校准候选和规模递增压力 | 基线/留出seed、反偏差、错误率、成本上限、拓扑明确、无自动晋级 |
| S3（可选） | LLM语言renderer、独立实验室UI | 核心稳定、合规模型配置、schema约束、无隐私/Key、黑色原风格 |

S1/S2及S3本地实验室已实现，远程renderer仅受控接口/模板测试，未启用真实Provider。画像固定在learner.py，场景固定在schema/policy，未创建空profiles/scenarios目录。实例计划/会话存SQLite，此Runner未调用文件作品工作区；独立实验结果在忽略data中，不写个人实例。

manifest绑定实际合并catalog、题库快照、应用Python源码hash和画像。恢复拒绝代码/画像/题库变更及快照篡改；完成/unsupported/failed/主动退出不重跑已撤回实例，仅预算停止可恢复。checkpoint明确记待推进动作，收据键保持稳定。结构化重放排除UUID和墙钟；超时为本地API调用之间的合作预算，不宣称可强制取消远程阻塞。

状态模型是课程级单潜变量近似，不是每KC真实知识诊断。答对率预测映射采用显式默认guess/slip假设，平均校准偏差不是分箱ECE。预校准以seed3拟合、seed17留出，课程题目仍共享，不宣称题目留出/真人效度。assessment.py另用审核包24题，通过前/后/迁移API及第7.5/13.5天两次合法due任务覆盖延迟蓝图；测量期不增加潜在掌握，仅practice改变掌握，模型内召回效应仍为假设。

身份/隐私最小准入仍必须早于真人试点；生产能力独立验收。结果和剩余边界见[V3验收报告](../测试/V3本地开发集成验收与未完成边界-20261006.md)。
