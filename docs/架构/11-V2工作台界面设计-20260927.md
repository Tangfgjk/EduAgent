**定名：桂子问津**（学伴角色名：**津津**）。

| 关键词 | 落点 |
|---|---|
| 华中师范大学 | **桂子** = 桂子山，华师的校园与精神地标（"桂子飘香"） |
| 武汉 | **问津** = 问津书院（武汉新洲，"子路问津"典）；两江三镇的"寻路"意象 |
| 学生自主学习 | 《论语·微子》"是知津矣"——问的是渡口，**过河终究要自己过**；平台的成功 = 学生学会自己找渡口（与北极星 autonomy_index、撤脚手架同构） |
| 未来教育 | 未来不是被送到的地方，是自己问出来的路——"问津"即面向未来的学习姿态 |

## 1. 设计语言（Codex 风）

**气质**：安静、高密度、低饱和、工具感——像开发者的代码工作台，不像游戏化的学习 App。与 DeepTutor / OpenMAIC 最新版同一代际（暗色优先、卡片化、流式会话），差异化在独有教育承载件。

| 元素 | 规格 |
|---|---|
| 色板（暗色默认） | 背景 3 层：`#0d1117`（壳）/ `#161b22`（面板）/ `#1c2128`(卡)；主色 `#3fb950`（成长绿，用于掌握度与通过态）；辅助 `#58a6ff`（智能体）、`#d29922`(阶梯/警告)、`#f85149`(红线/拒绝)、正文 `#e6edf3` / 次要 `#8b949e`。浅色主题同构映射 |
| 字体 | UI：系统无衬线（PingFang SC / Noto Sans SC）；**数据一律等宽**（掌握度、预算计数、哈希、Verdict 分）——数字用等宽是"证据感"的来源之一 |
| 工具卡语言 | 智能体每次工具调用渲染为可折叠卡：`▸ verify.answer ✓ 等价通过 (0.42s)`，展开看输入/输出/规则依据；运行中转圈、失败红边、被规则改写黄边+解释 |
| Diff 语言 | 一切"计划/契约/内容审定"用代码评审式 diff：绿色新增、红色删除、行内评论；**签署 = approve**，把 R-02 的仪式感做足 |
| 密度 | 紧凑（默认）/ 舒适 两档；小学低段档强制舒适 + 大图标 |
| 动效 | 克制：仅流式打字、阶梯升级脉冲、通过/拒绝徽章；全局尊重 `prefers-reduced-motion` |
| 声音 | 默认关；TTS 讲解与语音输入入口常驻（课堂/低学段主力） |

**禁用清单**（07 原则 2 的具体化）：无红点角标、无连胜火焰、无排行榜、无倒计时焦虑色、无"再学 X 分钟解锁"。所有进度只与自己历史比较。

## 2. 信息架构（壳层）——项目优先（v0.2 修订）

**第一级目录 = 项目（任务）**，对齐 08 裁决①"产品视图按项目隔离"：陪学、圆桌、证据不再是全局模式，而是**项目内的视图**——L1 项目导航 → L2 项目内视图 → L3 工作面，逐层展开；学习者模型、记忆、自主性仍按人跨项目累积。

### 3.5 其余屏规格要点

- **A4 计划签署关口**：左"计划.md v2 草案"、右 diff（+新增任务 −删除任务 ~修改）；每行可评论；学生逐条 approve 或提修改；底部"⚠ 小伴只能提议，最终决定权在你"；签署后版本锁定，修订须回反思关（双环学习）。**图形化进度面板（v0.2 新增）**：diff 之上常驻三件——①总进度环（D6/14 · 43%）；②里程碑时间轴（诊断✓→巩固✓→撤辅助挑战●今日→模拟测→复盘，今日光标 + 未来节点虚线）；③子目标条（达成标准逐条：概念辨析 80% / 独立解题 55% / 讲明白 3 题 0/3）。**分工：diff 回答"为什么改"，图形面板回答"走到哪了"**——签署是决策，进度是事实，两者不混排。

### 3.6 苏格拉底式启发的可视化（v0.2 新增）

原则：启发不能只是"感觉上在启发"——把苏格拉底式对话**机制化**为可标注、可统计、可检查的对象，也让教育原理在对话里可见：

1. **启发动作徽章**：津津的每条会话消息携带启发动作标签（与 `scaffold_type` 联动）：反问 · 追问 · 特例试探 · 举反例 · 类比 · 请你先说 · 沉默等待（WAIT）。徽章可点开看"为什么用这个动作"（状态依据 + 规则 ID）。这一条把审计中"Socratic 仅存在于 persona 文本"的短板补成**消息级可标注对象**，动作序列进事件流，可被进化环评估。
2. **问题链（右栏承载件）**：把会话压缩为"问题 → 你的回答 → 下一问"的链条，学生随时看到"这两个结论是我自己得出的"——外化苏格拉底法的成果，也是元认知支架。
3. **话语占比计**：状态条显示"这节课你说了 9 句 · 津津说了 5 句"。学生话语占比是苏格拉底式会话的一级健康指标（目标区间随学段档可调），也是调研报告"Tutor 型思维代替"风险的仪表化对策。
4. **不直接给答案的可见性**：L3 锁 + R-01/R-10 拒绝解释卡 + "等待"卡（productive struggle：津津显示"我在等你再试一次"而非继续输出——07 的 WAIT 动作 UI 面）。
5. **教育原理 → 对话的映射**：Engage 阶段必以真实两难问题开场（好问题）；Explore 阶段只给特例与反例不给结论；Explain 阶段"学生先讲、津津追问"；一切 FEEDBACK 过 R-04 归因分类器——**每个阶段的教育原理都有一条对话纪律对应**，写入提示词验收测试。

## 6. 理论效果可视化——"我们的教育思想起作用了吗"

**回答：可以，且分三层做。** 原则：可视化的是**证据**而非**分数排名**，每一层都防误读。

### 6.1 三层可视化模型

| 层 | 给谁看 | 回答的问题 | 承载屏 |

### 6.2 理论 → 可视化映射（A13 的图表规格）

| 教育理论/机制 | 可视化 | 数据源 | 防误读设计 |
|---|---|---|---|

### 6.3 防古德哈特与反表演五原则（本节的地基，写进验收）

1. **给证据不给分数**：autonomy_index 原始值只进教师/治理端；学生看行为分解（"你先尝试了 3 次才求助"），无法直接优化一个"自主性分"。
2. **求助永不污名化**：任何图表不把"求助多"渲染为负面；help-seeking 是策略（07 原则 1 的推论）——否则学生会为好看而该问不问，这是本类可视化**最大的毒性风险**。
3. **只比自己的历史**：无他人对比（07 原则 2）。
4. **不确定性永远显示**：一切估计带区间与"估计/猜测"措辞（镜子原则）。
5. **每张图可钻取**：证据卡→L2 场景小结→L1 原始事件三级链（07 UI-10 继承），杜绝"不可解释的图表"。

**研究者通道**：A13/B1 数据可导出为研究格式（脱敏、按 consent_scope），直接对接既有的教育实验设计（如 2×2 同伴建议核查、教师帮助分配分组实验）——理论效果可视化同时就是论文的图源。

### 6.4 认知诊断与知识追踪的预留位（v0.2 新增）

A13 预置两张"**接口就绪、模型可插拔**"的证据卡——数据契约现在定死，未来自研模型直接落座，不动前端：

| 卡 | 可视化形态 | 数据契约（预留） |
|---|---|---|
| 认知诊断画像（CDA/IRT 族） | 认知属性雷达图 + Q-matrix 掌握热力图（属性×知识点，p∈[0,1] 带区间）；"薄弱属性：等量关系建模" | `DiagnosisReport{attr_id, p_mastery, ci, model_version, q_matrix_ref}`；属性词表与 R-10/策略族识别共用 |
| 知识状态追踪（BKT/DKT 族） | 每知识点 p_mastery 时间轨迹（事件打标：练习/测验/撤辅助）+ 下一题表现预测（区间） | `KTState{kc_id, p_mastery, ci, history_ref, model_version}`；措辞"津津的估计" |

工程挂点：docs/10 §2 已在学习引擎留出替换点（`compute_mastery` 可换 IRT/BKT、出题难度 `irt_params` 预留）——这两张卡就是替换点的 UI 面。**模型未接入时卡片渲染为"预留位"态**（虚线边+说明文案+示意数据明确标注"示意，非真实模型输出"），不用假数据冒充实模型。

### 6.5 学习路径推荐接口（v0.3 新增）

帮助学生"制定计划、修改计划"的规划层推荐引擎。**接口现在定死；v1 由规则 + 津津（POMDP/策略层）生成，v2 可插独立推荐模型**，输入信号与 CDA/KT（§6.4）天然衔接。

数据契约：

```text
PathRecommendation{
  path_id,
  nodes: [ { kc_id, seq, est_sessions, difficulty, depends_on } ],
  source_signals: [ kt_ref, fsrs_ref, contract_ref, preference_ref, evidence_ref ],
  rationale,                     # "为什么这样走"——每条边可钻取到信号
  branch_rules: [ { when, then } ],   # 条件分支（如通过率<60%插入变式）——本身是软参数
  status: proposed | accepted | modified | rejected
}
```

- **输入信号**（全部已有挂点）：KT/CD 掌握概率与薄弱属性（§6.4）、FSRS 遗忘风险与复习队列、GoalContract 目标/达成标准/截止（02）、支架偏好（§4）、撤辅助表现等北极星过程数据。
- **输出作用于 PLAN_VERSION**：推荐只是提案；采纳/修改后进 diff → 计划签署关口（R-02：路径归学生所有，推荐引擎不得直接改计划）；`rejected` 样本连同理由回流金标数据集（v2 进化的原料）。
- **UI 面**：A4 计划签署页的"学习路径推荐"面板（§3.5）；"我的镜子"可回放走过的历史路径。
- **验收**：三键各自可用且都有事件留痕；采纳后 diff 必含路径变更；`status` 全生命周期可追溯。
