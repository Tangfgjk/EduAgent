# S08 成长证据统计口径与量规边界

日期：2026-10-16。延续 12、13、23、25 号文档，既有文档保持不变。

## 1. 读模型与范围

新增 `app/modules/evidence`，不新增事实表、不改写 L1，不修改 L2/L3，不重算学习结果。读取当前已持久保存的 LearningFact、关联 LearningInput、MemoryNote、FactJudgment，构造页面读模型。

- `/api/v1/student/evidence`：当前学生的全部正式项目，包含归档，排除临时空间；不采用记忆接口的项目分页作为全局总体。
- `/api/v1/student/workspaces/{wid}/evidence`：当前学生拥有的一个空间，可为正式、临时或归档空间。
- `days`：14/30/90；`source`：all/synthetic/adult_test/real_student。
- `record_kind`：仅筛选下方来源列表；`offset`：列表每页 20 条。统计始终覆盖选定时间、来源和空间的完整总体。

网关复用学生角色与所有权检查。跨用户空间返回 404，管理员不能调用学生接口。全局按空间 ID 固定顺序锁定已选择的空间，与 worker、复核、自述及归档写入保持一致；既有账号授权还会锁账号，当前读写可核对。没有将“串起来分别读取几十页再累加”的前端结果当作全局总体。

这是本地开发规模的实现，会读取范围内事实及原文，并在读取期间持有空间锁；不是大规模分析仓库。未来达到试点并发/数据量要求前，应基于同一口径建立增量聚合与快照，分页/SQL 聚合优化不能改变来源和总数。该路线尚未压测，不承诺生产吞吐。

## 2. 时间与来源

固定 UTC+08:00 自然日。N 天窗口为“今天及前 N−1 天”，开始时间为第一天 00:00:00，结束为本次报告 as_of；只计入范围内已保存记录，排除未来时间。UI 按同一时区生成零记录日。

日期按事实、自述、判断各自的创建时间计算。旧事实的新自述或新人工判断可出现在本期，即使其原始事实在窗口之外；点击时仍能追溯原始事实。因此“本期事实为 0、自述为 1”是有效状态。报告暂不提供任意时区/任意日期段。

来源使用事实保存时的 source_kind，不用当前账号标签追溯重分类。all 仍返回每个来源独立的统计与趋势；不生成混合模拟和真实学生的正确率。人工判断和学生自述还有独立的 record_kind，不作为原始自动核验计数。

## 3. 指标口径

| 指标 | 计数依据 | 不代表什么 |
| --- | --- | --- |
| 学习事实 | 窗口内 LearningFact 条数 | 活跃人数、能力值 |
| 作答与原题复做 | kind 为 answer/review_answer | 题目去重数、知识点覆盖数 |
| 独立检测提交/通过 | kind=answer 且 stage=checkpoint；通过再要求 status=passed | 初始诊断、复做、受辅核验，或已经掌握 |
| 提示请求 | kind=hint，每次已开放提示计一条 | 提示强度、独立性分数 |
| 反思 | kind=reflection | 反思质量已达标 |
| 互动贡献 | kind=activity_contribution | 角色发言次数、解释能力分数 |
| 自述 | 窗口内 MemoryNote | 客观诊断 |
| 人工判断 | 窗口内 FactJudgment | 自动验证结果被覆盖、教师金标已具备 |

阶段核验表仅纳入 answer/review_answer，按原始 stage 分组，分别统计 passed/failed/unverifiable。skipped 仍可在“全部记录”追溯，但不伪装为数值答案。人工改判不会重写该表；来源页同时展示原始自动结果与人工意见。

重复请求已由写入路径的幂等协议去重；真正重新尝试则按次数保留。所有值只描述目前这批开发题，不能跨不同题型、样本或难度推断学习增益。日期无记录显示次数 0，不代表能力为零或退步。

## 4. 素养与可视化

沿用既有六个产品观察方向：数学抽象、逻辑推理、数学建模、直观想象、数学运算、数据分析。此框架尚未完成初中数学专业量规审核与校准，不能标为课标达标量表。

接口中六维 score 均为 null，status=rubric_pending；模型估计数量固定为 0。页面显示灰色观察框架、可选择的六维准备状态与“等待量规审核”，不绘制能力多边形，不将未评定显示为 0 分，不擅自把某段学生文字映射为某个维度的能力证据。

真实可交互部分为：按来源和指标切换的每日过程曲线、键盘可选择日期、可展开的数据表、来源记录筛选/分页、原始来源弹窗与学生说明。图表没有自动插入“提升”“下降”评价，没有前后平行测验时不报告学习增益。

学生自述、过程观察、数值实测、人工判断保持可辨识；当前没有模型估计数据。独立检测只是数值验证，推理和素养仍未评定。角色模板只作为背景保留，不作为学生素养证据。

## 5. 来源与后续治理

列表返回 fact_id、workspace_id、run 对应的原始事实、记录类型、时间、题目 ID、归档状态和原文摘录，不返回未公开参考答案或未来提示。打开来源继续走原有所有权检查，可查看完整自己的原文、当时实际开放提示、后续判断和自述。

归档允许读取，禁止追加说明；追加仍经过原有 CSRF、空间、幂等与不可变写入约束。保存后刷新证据与记忆缓存，旧自动结果不变。

S09 规划模块今后可以按范围和来源收集这些记录，但该读模型不直接触发策略更新。量规、教材/考纲版本、主观信息与客观资料的授权范围、提案检查/审核/学生确认等仍需独立治理。
