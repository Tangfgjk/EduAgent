# S05 教学与验证实现边界

日期：2026-10-16。适用范围为本地开发与成人测试，不构成真实教学效果结论。

## 2. 数据与版本

`agent_runs` 新增 `kind=plan/tutor` 与公开 `view`，原计划行默认补为 plan。计划与 TutorGraph 的列表、快照、恢复接口互相隔离，避免用计划决定误推进学习图。

TutorGraph 每次输入先保存不可变 LearningInput 与 outbox，再由 worker 执行。框架检查点、业务视图、不可变事件、复核待办和任务完成在一个事务提交。故障时全部回滚，重试不留下半份复核记录。

运行版本绑定图版本、内容哈希、硬规则注册表哈希和数值验证器版本。内容启用记录绑定完整哈希；代码内容变更或规则/图升级时，不静默继续旧图。

`content_approvals`：unit_id、内容哈希、启用状态、revision、核对管理员与时间。客户端提交看到的哈希和 revision；服务端验证其仍为当前版本。

`answer_reviews`：唯一 input_id、run_id、题目 ID/版本与完整快照、处理状态、人工结论/依据、revision 和处理人。原始答案与来源从不可变输入读取，题目快照确保未来改题后仍可复核原题。

管理员复核有审计和版本检查；不修改原 LearningInput，也不将人工意见悄悄写成过去的自动验证成功。

## 3. 教学状态

诊断：一次提交 → 保存结果 → 学生继续。

练习：可多次作答；错误或未知不自动判通。可逐级求助；数值通过后进入反思。也可先尝试，再明确记录“未完成”并反思。两道练习各需独立反思。

检测：一次提交锁定本题，不提供提示，不允许使用练习的“未完成并反思”路径跳过检测；确认继续后进入下一题或小结。

完整对照通过 EXPLAIN(worked_full) 复用 R-01，只有提示阶梯达到 L3 才放行。诊断/检测上下文通过 R-09 拒绝答案型帮助。反馈复用 Governor 的策略归因约束，不使用能力归因作评价。

反思只作为学生自述保存，不通过关键词或字符数量推断理解水平。当前诊断也不会自动生成个性化路径或掌握度。

## 4. 验证信任边界

学生数值文本不进入 eval、sympify、任意工具或子进程。验证器只处理有界有理数表达式：十进制数字、正负号、括号、加减乘除，可带单个 `x=` 前缀。采用 Fraction 保持精确比较，逐节点限制数字位长。

不支持的合法数学记法（如根式、文字证明）返回 unverifiable；不自动判错，也不让模型猜测真值。多重等号不提取最后一段冒充答案。列式与推理仍需后续专门验证器/人工判断。

学生接口仅返回当前题干、输入要求与已开放的提示，不返回标准答案、后续检测题、未开放提示或检查点。管理员内容接口可以读取完整开发题，用于核对，学生角色被拒绝。

最终小结只显示本次诊断/练习/检测的结果与过程。没有更新 BKT、长期素养、六维雷达或正式复习计划。

## 5. 接口

学生接口，均验证账号拥有当前 workspace：

- GET `/api/v1/student/content`：开发内容状态，不包含答案或提示。
- GET/POST `/api/v1/student/workspaces/{wid}/tutoring`：列表/开始，POST 使用 Idempotency-Key。
- GET `.../tutoring/{rid}`：安全视图。
- POST `.../tutoring/{rid}/inputs`：带 gate_id、expected_revision 与幂等键的 answer/hint/reflect/next/skip 类型化决定。
- POST `.../tutoring/{rid}/cancel`：取消并保留事实。
- GET `.../tutoring/{rid}/events` 与 `/event-history`：安全 SSE 批次与 JSON 事件，最多 100 条/批，支持序号续传。

管理接口，仅 admin 角色、写请求须 CSRF：

- GET `/api/v1/admin/content`：完整开发题核对。
- POST `/api/v1/admin/content/development-release`：版本 + revision + 开发用途确认，启用或撤回。
- GET `/api/v1/admin/answer-reviews?status=pending&offset=0`：每页 20 条，支持已处理状态。
- POST `.../answer-reviews/{id}/resolve`：带 revision 与依据的人工意见。

## 6. 后续扩展的边界

目前仍是 S04 的有界、无网络副作用事务图。将其扩成外部模型、检索或工具长运行前，必须先升级独立持久 saver、单 thread 写者、心跳、租约与幂等结果协调；具体要求见 19 号文档。

未来内容包扩展沿用：知识点与版本 → 审核状态 → 可验证输入 → 提示门禁 → 独立检测 → 来源清晰的学习事实。几何证明等无法用数值比较的任务应使用专门协议，不能复用数值通过来宣称证明正确。
