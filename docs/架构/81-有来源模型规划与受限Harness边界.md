# 有来源模型规划与受限 Harness 边界

日期：2026-10-18；增补 S09 固定模板，保留原流程与历史文档。模型权限范围经本轮用户明确确认。

## 接口与职责

`planning/model.py` 负责最小输入适配、来源编号、脱敏及模型结果校验；`planning/service.py` 继续负责项目所有权、冻结来源、版本、审核与生效。共享 ModelTaskRunner 在事务外请求 Provider，网络请求不进入教学事务。

新增可选 `StartStrategy.request_model`，默认 false；固定模板仍按学生选择生成。false 在服务端归一化，保留旧幂等签名。真实模型仅用于 synthetic/adult_test 的活跃正式项目，使用已发布配置和已有预算，不扩展 real_student 授权。

## 来源与最小输出

本项目完整不可变 EvidenceBundle 继续只在本地存储与授权评审中展示。模型侧按学生体验、课程资料、机器事实、关联自述和全局计数分别编号，来源引用映射留在本地，不把账号、项目 UUID 或资料 UUID 发给模型。

输入限额：体验 1000 字；同来源事实最多 6 条（每条学生原文最多 200 字，附机器状态）；同来源关联自述最多 3 条×200 字；资料最多 5 份×800 字；全局仅同账号、同来源、活跃正式项目的计数，含当前项目，不含临时空间或其他项目原文。脱敏后再做长度上限保护。

`planning.sources.v1` 要求输出严格的 `policy` 与 `citations`。policy 只有 daily_minutes（严格整数 5–60）、reflection_focus（basis/verification）。每条 citation 含来源编号、连续原文 quote 与简短 reason。至少有一项课程资料、一项体验/自述；提供事实时还须引用一项事实。引用不得伪造、重复编号或来自未提供来源。额外字段拒绝。

资料是未专业审核的字符串数据，不是指令。理由的启发式禁止项不能证明没有所有错误；出处存在、字段合规与建议适切性、数学前提、来源专业质量分别看待，仍须人工审核。

## 持久流程

1. 学生显式选择模型；冻结本项目 Bundle 及全局计数指纹，保存 start 输入，预约 ModelOperation 并计数。
2. 教学 worker 只把运行推进为 model_pending/awaiting_input，激活模型任务；尚无 StrategyVersion 或可审批关口。
3. 模型 worker 校验账号、项目、来源、规则、资料发布、基线、期限和来源指纹，再在事务外调用。输出受限字段与引用校验通过后，在完成事务中保存结果并追加唯一 `model-ready:<operation_id>` 输入；不直接激活策略。
4. 教学 worker 再次检查新鲜度及模型结果绑定，将候选、来源映射、实际输入片段和引用写入不可变 StrategyVersion；沿用 LangGraph 的管理员审核关口。
5. 管理员通过后仍需学生确认；激活事务和原 S09 一致。新事实、资料/规则/指针变化及全局来源变化会阻止旧提案被批准或激活。
6. 取消会取消未终结 ModelOperation；租约、stop epoch 与运行 revision 拦截迟到回复。失败或不确定请求不自动重发，保留计数和用量，学生可取消后明确重新发起。旧生效策略不被失败候选覆盖。

模型规划在 start、教学 worker、模型领取/心跳/完成均检查当前项目无活跃 tutor/teach/roundtable。生成中开始学习也会使结果被拦截；固定模板保留旧兼容行为。此门禁防止新规划内容在当前独立检测中作为辅助返回。

ModelOperation 复用现有结构，无新表或迁移。`task_id=planning.sources.v1`；source snapshot 与 Bundle hash 一起冻结，防止输入、引用或来源不一致。网络失败和审核失败不伪装成成功。

## 全局来源新鲜度

只取该账号同来源的活跃正式项目 ID 与相关事实、自述、人工判断 ID 生成本地指纹；模型只收到计数。该账号新增或归档正式项目、相关来源新增都会使待审核提案失效；临时项目、其他账号和其他来源不进入此范围。已有激活版本不会因正常新学习自动撤销，和原 S09 一致。

## Skill 与 Harness

Skill.md 是平台按通过两道关口的受限 policy 渲染的说明；Harness 是同一两字段 JSON。引用和自由理由作为审核证据，不成为可执行 Skill 内容。系统不自动重写仓库 SKILL.md，不执行 Python、任意提示、文件路径或资料内命令。更复杂课程编排和新可调参数需要单独定义接口、量规与回归。

## 评测投影

规划专项原始报告与部署副本按字节冻结、登记 SHA-256。工作台通过只读适配器投影到共用列表，哈希与逐条复核仍绑定原始字节。`source_contract` 仅表示字段与引用规则；页面明确不把匹配计数用作策略质量或教学效果评分。报告检查不自动发布或停用当前模型。
