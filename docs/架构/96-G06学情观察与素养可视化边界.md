# G06 学情观察、素养材料覆盖与规划摘要

日期：2026-10-18。API 0.16.0，数据库仍为 `g05_002`；本轮无需迁移。

## 1. 本轮交付范围

本轮交付 G06 的过程覆盖层：知识点地图、辅助/曝光分类、原题复做时点、支架时间线、六个素养观察方向的候选材料、全局/局部过滤与来源钻取，以及冻结进策略依据的本机观察摘要。

这不是 G06 全部研究目标已完成。正式 RubricVersion/RubricAssessment、专业评阅、置信校准、未见题迁移测量和教学效果评估尚未实现；不以候选材料数量替代它们。下一步 G07 的课程/复习/追问策略扩展与 Skill 消费尚未实现。

## 2. 模块与接口

- `app/modules/evidence/insights.py`：从不可变事实重建只读投影，复用来源与所有权边界；不额外写学生能力状态。
- `insight_contracts.py`：图形、来源索引和规划摘要的显式契约。
- `GET /api/v1/student/learning-insights`：本人正式项目全局观察，默认包含归档，可排除归档，不含临时空间。
- `GET /api/v1/student/workspaces/{wid}/learning-insights`：本人单空间观察，包括临时与归档空间；他人空间返回404，管理员不能借学生接口读取。
- `days=14|30|90`、`source=all|synthetic|adult_test|real_student`。日期采用 UTC+08:00 自然日，包含首日零点，排除未来记录。
- 原成长证据接口增加全局 `include_archived`，图形与原列表应用相同过滤条件。记录类型和分页仅筛选列表，不改变全量统计。

图形总数来自窗口内完整事实集，不受20条列表分页或8条来源索引上限影响。各图显示近期最多8条索引，支架显示最近50条并注明总数；全部过程继续在来源记录分页查询。接口不把答案、提示阶梯或原文重新复制到图形索引；查看原文通过既有按空间所有权校验的事实接口。

## 3. 指标定义与限制

| 图形/指标 | 来源与定义 | 不可推导的结论 |
|---|---|---|
| 知识点地图 | 可信内容版本关联开发 KC；版本、来源分开。不同题数按 task_id 去重 | 不表示掌握度，不证明每题覆盖单元所有知识点 |
| 初始诊断 | tutor diagnostic 答案提交 | 不能与难度不同的后测直接相减 |
| 本轮未用提示/辅助后练习 | practice 答案的 hints_used 为0或大于0 | 不证明平台外无辅助，不是独立能力分 |
| 首次曝光/已见题/曝光未知检测 | checkpoint 的 fresh/seen_before/缺失；活动仅 verify，按 independent 已有标志分类 | 不证明平台外未曝光，不与原题复做混为新题 |
| 到期/提前/时点未知原题复做 | RecallAttempt.created_at 与 due_before 比较；无关联时标未知 | 到期失败也计到期提交，不能以是否推进日程判到期；原题不是迁移 |
| 支架时间线 | 实际练习事实中的 support_decision、hints_used、事件时间 | 减少提示不自动代表进步；两次求助恢复具体支持是可逆机制 |
| 素养材料覆盖 | 六方向候选事实数；可重复归入多个方向 | 不计算能力雷达、百分制或置信度；0条不代表能力为0 |
| 自述/人工数值复核 | 窗口内 MemoryNote / FactJudgment，可关联较早事实 | 不覆盖自动核验，不当作素养专业评阅 |

本轮首次曝光指标对缺失历史标志采用未知；原接口的首次检测计数同样不再把缺失标志计作 fresh。历史回填仅忽略视图中的派生 exposure_status 比较，原题/状态仍须匹配，回填不捏造首次曝光。

开发 KC 映射采用已知静态单元或登记/生成内容的明确知识点；不按项目名称猜测。找不到版本或明确映射时保留“未映射”，原事实仍可追溯。当前只有6个开发 KC，不是七至九年级完整课标图。

素养归档规则对用户可见：数值提交进入运算候选；依据/反思非空进入推理候选；方程/函数的文字材料进入抽象候选；几何/函数文字进入直观想象候选（不证明有图形作品）；统计文字进入数据分析候选；明确标注的开发建模任务表达进入建模候选。它们是待评阅材料路由，不是对文本含义、论证质量的自动识别。

## 4. 规划摘要及数据范围

新策略提案在创建时冻结当前项目、最近30天、账号对应来源的 `learning_observations`：窗口、as_of、事实/自述/人工数值复核计数、分组数值观察、最多6条事实来源索引、限制、指纹和版本。旧策略没有此字段仍可查阅和回滚。

指纹包含全量事实与自述/复核标识、空间状态、时间窗口和内容映射版本；刷新时仅 as_of 变化不会制造新指纹。源事实不可变，原策略新证据/资料/基线失效检查继续有效。

**本摘要 delivery=local_only。** 前端可查，策略评审双方可核对；不自动扩大 DeepSeek 请求。既有模型规划仍只使用此前确认的本项目最多6条脱敏记录、3条自述、体验、受限资料与全局计数。本轮没有新增真实模型调用、搜索调用或预算调整。

## 5. 后续接口边界

1. G06 待量规与审核：版本化量规、具体作品标注、合格评阅者、评阅撤回/纠错；在此之前不发布素养分。
2. 延迟与迁移：建设等值且未见的题族和任务版本，记录平台曝光、延迟、难度及辅助条件，避免将重复熟练度当学习增益。
3. G07：在白名单 policy DSL 内增加真正被课程/复习/支架消费者读取的参数，展示差异、验证、双重确认与回滚。新增摘要如需真实外发，另确认最小数据范围后修改冻结请求契约。
4. 大样本：当前只读重建适合本机开发；规模上升后增加带版本及水位的可重建投影、索引与性能验收，不复用展示截断作为统计总量。
