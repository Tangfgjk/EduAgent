# S06 学习事实与记忆分层

日期：2026-10-16。适用范围为当前开发单元，不替换既有项目方向、硬规则或 S04 长运行升级要求。

## 1. 数据边界

| 模型 | 职责与变更规则 |
| --- | --- |
| LearningInput | 原始输入，不可变；继续关联账号/空间/会话/来源 |
| LearningFact | 已处理的作答、提示、反思、未完成和复做事实；按 input_id 唯一，不可变 |
| FactJudgment | 管理员复核的独立补充，引用原事实与 AnswerReview；不可变 |
| MemoryNote | 学生针对某条事实的补充/异议；不可变，并保留提交身份与幂等键 |
| ReviewCard | 项目、题目版本与来源分别隔离的当前复习工作状态；包含原始事实 ID 与原因 |
| RecallAttempt | 每次原题无提示复做的结果、间隔前后值与是否计入安排；不可变 |
| LearningProjection | 当前 L2 摘要与 L3 观察，可从事实再生；不是新的学习事实 |

未知答案只进入复核，不直接创建“数值错误”条目。原始数值失败、受辅通过与人工建议回看分别作为入队原因。后续普通练习答对不自动消除已有复习安排。

学生接口只返回来源题干和当时实际开放的提示，不返回标准答案、未开放提示或框架检查点。原始答案与学生说明仅在授权空间内读取。

## 2. 一致性与来源

`app/modules/memory/facts.py` 在 TutorGraph 处理完成后发布事实，复用 worker 已持有的账号/空间锁，与运行检查点、业务视图、事件和任务完成在同一事务提交。

`projections.py` 从 L1、人工补充和学生说明生成：

- `learning_digest.v1`：按 source_kind 与 stage 分类的提交次数，另保留提示、反思和补充数量。
- `learning_observations.v1`：`observations.v1` 受控引擎输出，引用摘要版本与相应原始来源。只作描述，不生成掌握概率或能力等级。

L3 入口验证引用类别，拒绝 L3 自引用，也拒绝把观察记忆伪装为 digest 引用。每条公开观察都能通过 fact 来源链接查看原始记录及其人工判断/学生自述。

摘要内容与来源未变时，不递增 revision。全局读取同样取得空间锁，使单次响应中的 L2 与 L3 引用版本匹配。权限边界仍由当前学生身份和空间所有权确定，客户端 ID 不能赋予权限。

## 3. 默认安排算法

固定开发策略 `fixed-recall.v1`，间隔为 1、3、7 天，之后保持 7 天；不是经真实学生校准的遗忘模型。

- 原题到期数值通过才增长档位；提前通过只记录事实。
- 数值未通过回到当前可复习状态；未知结果不改动档位与到期时间。
- 每次提交独立保存输入、结果和安排前后值；同键请求重放不重复提交，异内容同键/旧 revision 拒绝。
- 诊断/独立检测活动期间拒绝从复习入口获得数值帮助；原内容启用、来源与版本限制继续生效。

原题已经暴露过，复做不能作为新的迁移测量。以后若接入平行题、BKT 或其他排程器，应提供独立版本、参数来源、来源层级和适用范围，不能把当前计数解释为已掌握。

复做是无外部 IO 的有界数值验证，直接在鉴权事务内完成，不创建无处理用途的 outbox。输入仍进入统一 LearningInput，并绑定内部 recall 运行；公开计划/陪学路由不接受该运行种类。

## 4. 历史处理与恢复

`backfill.py` 只重建可核对的 S05 历史：相同运行版本；不可变输入；处理成功的任务；检查点记录的已处理轮数；确定性重放视图与保存视图一致。

检查点用来界定哪些输入真正执行过。例如取消后队列被标记完成的输入，不能仅凭 completed 状态认定为已作答事实。重放只处理检查点中确认的轮数，并核对最终视图。

已有事实按 input_id 去重；已处理的人工复核可以补建独立判断。版本未知、输入缺失或视图不符则跳过，不计算猜测结果。已有复做后的空间不自动补插更旧事实重置现行安排。

维护默认只报告，只有 `--apply` 才写入，应在停服与备份后执行。完整备份保留全部关系；当前独立重建工具针对 L2/L3 和已核对的旧 S05 来源，不宣称已经具备所有历史版本的完整事件溯源恢复。

## 5. 模块与 API

| 文件 | 职责 |
| --- | --- |
| `app/modules/memory/contracts.py` | 来源、条目、复做、自述、摘要和观察的类型契约 |
| `facts.py` | 原始处理结果与人工补充的发布、入队依据 |
| `projections.py` | L2/L3 的受控生成与引用规则 |
| `service.py` | 所有权、复做、安排、来源、自述、局部/全局读取 |
| `backfill.py` | 停服历史核对与幂等补建 |
| `app/gateway/memory.py` | 学生鉴权路由，写操作继续验证 CSRF |
| `frontend/apps/student/src/review.tsx` | 三类页面、无提示复做、来源与说明弹窗 |

所有当前空间接口在 `/api/v1/student/workspaces/{wid}` 下：

- GET `/review-cards?status=all|due|scheduled&offset=0`，以及 `/review-cards/{cid}`。
- POST `/review-cards/{cid}/attempts`，需要 Idempotency-Key、expected_revision、answer 和可选步骤。
- GET `/unverifiable-answers?offset=0`。
- GET `/facts/{fid}`：返回安全原始来源与独立补充。
- POST `/memory-notes`：需要幂等键、fact_id 与学生说明。
- GET `/memory`：当前空间摘要与观察。
- POST `/memory/rebuild`：仅重新生成 L2/L3，不重写事实或自动重排复习。

GET `/api/v1/student/memory?offset=0`：本人的正式项目，含归档、排除临时空间，每页 20 项；来源模式仍单列。该视图不是 S08 的正式素养测量或真实学生效果统计。
