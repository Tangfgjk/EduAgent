# S10 多内容包与版本隔离

日期：2026-10-16。首批工程实现；完整课程建设仍按 13 号规划逐步推进。能力限制见 [30 号清单](../进度/30-当前能力边界与后续完善清单.md)。

## 1. 模块接口与职责

`app/modules/learning/content_catalog.py` 定义 `ContentPack`，统一提供单元 ID、标题、年级编排建议、领域、知识点、先修参考、题目及内容版本。`get_pack(unit_id)` 拒绝未知包；`pack_for_task(task_id, version)` 为历史复习精确匹配来源，不把其它包的启用当成授权。

内容包保存诊断、练习、独立检测、四级预设提示和新增题目的常见误区。注册表属于开发内容，不能通过外部资料或模型输出任意执行代码。下一阶段可以把题目存储替换为审核后的持久化题库，但应保持这一调用边界。

| 模块 | 多包实现职责 |
| --- | --- |
| content_service / tutoring router | 学生目录隐藏答案与提示；管理员核对完整题目，按包做版本和 revision CAS 启停，写审计 |
| tutor_service / tutor_graph | 按包启动，保存单元标识到检查点，统一诊断—练习—反思—独立检测；沿用项目计划、归档、幂等和门禁 |
| worker | 按运行的包重新核对版本、启用和来源，持久化对应内容版本的复核快照 |
| memory/facts / memory/service | 用该包的题目生成不可变事实和复习条目；复做检查该包版本及发布状态 |
| memory/backfill | 只重放当前注册的确定性版本或原有兼容版本，完整视图核对一致后才允许补事实 |
| 学生 React | 目录按年级/领域筛选，展示实际启用状态和先修参考；链接携带 workspace 与 unit，陪学可选择包 |
| 管理 React | 原方程入口保留，新增内容包在独立弹窗中核对题目、误区、提示与版本后启停 |

年级仅为开发编排建议，没有宣称已完成课标或教材版本映射。先修图目前是展示参考，不自动判断已经掌握，也不阻止学生自主选择。

## 2. 版本兼容

- 原 `development_content.py` 的题目、ID、内容 hash 保持不变，原 S07 互动模板继续独立管理。
- 原单元继续使用 tutor.v2 版本规则，旧 v2 检查点没有 `unit_id` 时仅回退到原方程包。旧 v1 的历史核对逻辑保留；旧运行查看和取消政策沿用 S09。
- 新包使用 tutor.v3，版本包含内容 hash 前缀、硬规则 hash 和数值验证器版本；内容 hash 覆盖题目及教学编排元数据。
- 学习事实、复习条目、人工复核继续保存内容版本和题目快照。旧版内容不匹配时保留历史，拒绝自动复做；不能把新版本套进旧事实。
- 此轮没有表结构调整，数据库仍为 `s09_001`。备份恢复机制继续覆盖所有业务表；不回写或删除旧学习事实。

## 3. API

新增鉴权接口：

- `GET /api/v1/student/content-catalog`：学生目录，`tasks=[]`。
- `GET /api/v1/admin/content-catalog`：管理员目录，包含开发题与审核参考。
- `POST /api/v1/admin/content-catalog/{unit_id}/development-release`：版本 + revision + 开发范围确认的启停操作。

原 `/student/content`、`/admin/content` 与其启停接口继续只代表原方程包。原 `StartTutor.unit_id` 从单个固定值改为注册表解析；不存在的包返回 404，未启用返回 409，真实学生使用开发题返回 409。

学生不能通过目录接口获得参考答案、未开放提示或误区。管理员审核结果不改写原始提交；无法验证的输入继续进入人工复核队列。

## 4. 验证器与扩展路线

首批五包均使用已有 `bounded-rational.v1` 安全有理数验证器，只核验单个有理数结果。函数包目前是给定模型求值，几何包是已知直角三角形的整值求边，概率包是明示等可能条件下的计数，不宣称支持完整领域推理。

后续增加代数表达式、多解集合、根式、图形或证明时，应新增独立领域 Adapter，明确输入格式、可验证范围、版本和人工复核出口，再由内容包选择。不能扩大当前数值 `verify` 的含义，也不能把解释文本解析失败视作答错。几何证明任务在完成该协议与人工出口前不作为已可用单元发布。

完整 S10 后续顺序：补齐课程覆盖台账 → 分批建设题目/提示/误区/独立检测 → 引入对应 Adapter → 扩展逐包互动 → 专业审核 → 授权试点。真实模型及教学效果评定另按 30 号清单确认与验收。
