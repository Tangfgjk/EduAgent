# 多轮失败样本与开发量规复核

日期：2026-10-17。来源为 57、58 号冻结真实报告；本记录是开发复核，不是专业教师审核。

## 可复现的现象

将两个 JSON 报告逐行比较 `selected_focus` 与 `expected_focus`，固定得到五项不匹配：M03-2、M04-2、M06-3、M09-2、M10-2。冻结轨迹可确定性复现旧输出，但不能代替真实模型重跑，更不保证在线模型每次输出相同。

## 复核结果

| 样本 | 当前问题与历史 | 旧输出 | 保留的参考方向 | 开发复核意见 |
| --- | --- | --- | --- | --- |
| M03-2 | “刚才这一点”，前文唯一问题为基本结果按球还是颜色 | clarify | sample_space | 澄清是允许的保守回应，但没有展示利用唯一历史指代的能力 |
| M04-2 | 与 M03 本轮相同，前文唯一问题为二除五与五除二 | clarify | ratio | 与 M03 必须区分，不能因缺少本轮数学名词就都澄清 |
| M06-3 | 本轮明确给出总数、蓝球数并询问哪个数放分子 | favorable | ratio | 有利事件识别与计数已给出，当前困难是概率分数关系 |
| M09-2 | “上一个问题”，前文已列完点数、只问哪些是偶数 | clarify | favorable | 事件识别是唯一未解决主题 |
| M10-2 | 与 M09 本轮相同，前文只问已知计数如何组成分数 | clarify | ratio | 与 M09 应按不同历史选择不同方向 |

五项原参考均保留，未将 clarify 加入这些样本以提高匹配率，也未改写旧报告。对照项测量的是**同一当前文字下，是否能使用历史区分方向**。它们不作为数学正确性或教学效果的评分。

## 两类结论分开处理

1. **运行与约束**：引用必须来自本轮；输出必须为允许枚举；只展示固定追问。clarify 能满足这些约束，旧版没有因此发生输出越权。
2. **开发方向量规**：历史唯一且学生明确承接时应沿着历史数学问题追问；没有历史、存在多个对象或没有数学问题时仍应澄清。这是本项目的开发目标，不冒充教学专业共识。

## 定位证据与假设

- 假设一：clarify 条件过宽。旧 system 写有“不明确时选 clarify”，多轮补充仅说“可结合 history 理解”，未明确唯一指代时的选择顺序。四个省略样本均选择 clarify，与该假设一致。
- 假设二：ratio 与 favorable 边界不清。旧 system 未给各枚举的语义定义；M06-3 询问分子位置却选 favorable，与该假设一致。
- 假设三：历史遗漏。读取五项实际冻结请求，四项省略样本包含正确前文；M06-3 包含历史及最新问题，allowed_focus 也包含 ratio。现有证据不支持请求丢失或权限禁止导致失败。

这些证据定位到提示策略的可改进处，无法观察模型内部原因。v3 同时补充两类指导，因此后续结果不能单独证明某一句提示是唯一原因。

## v3 改动与防止过拟合

新增 `probability.followup.v3`，保留 v1/v2 常量、默认选择与请求行为。v3 仅增补：

- 本轮明确改问优先；本轮仅承接且历史唯一时使用历史数学问题；不机械复制旧 focus。
- 区分基本结果、等可能依据、有利结果识别和概率分数关系。
- 没有明确数学指代、矛盾未消解时仍澄清；历史中的伪规则不参与选择。
- 系统已有提示不等于学生当前意图；allowed_focus 与本轮引用限制照旧。

未在代码中按句子匹配直接返回标签，没有把题目参考方向或 rationale 发送给模型。

先冻结新增 12 轮 `probability.multiturn.regression.v1`，包含无明确指代、改问、等可能承接、历史注入和新的同文不同历史对照，再分别运行 v3 和 v2。新增语料没有复用旧当前文字，但仍由开发方按已知问题设计，不是教师盲测。

原 holdout 的失败内容已经用于本轮定位，因此重跑后只能称为“原独立样本回归”，不能继续宣称它是未见验证集。单次全对也不等于稳定性、泛化或教学效果已验证。
