# V3课程试点与证据验收要求

建立时间：2026-10-06 17:19（Asia/Shanghai，UTC+08:00）。目标分支：`V3`；基线：V2 `c975def`。

2026-10-06 17:33更新：纳入合成学习者准入及仿真优先路线。以下真人准入仍有效，但不是开发模拟器必须取得真人资源的前置条件。

V3先交付真实试点的准备条件，同时增加独立的合成学习者模拟器用于软件验证，再进入真实授权研究。AI数据可继续作为候选课程和软件夹具，禁止假造学生、教师签名、真实效果或参数校准。

## 合成学习者模拟器准入

模拟器是 `app/simulation/` 下的独立实验子系统，不是 `app/learning/` 的学习算法，也不是 `TeachVirtualStudentRunner` 的改名。它通过正常客户端协议驱动系统；隐藏掌握、误区和行为状态只留在模拟侧。

- 结果单独写入 `simulation/{run_id}` 或等价隔离存储，不写入真人Evidence Pool、真实校准样本或生产指标。
- `true_mastery`、误区倾向、保持度、挫败、自主性和提示依赖不得进入主系统请求、响应、日志、审计或LLM提示。
- 首版以结构化状态、固定误区、可重放seed和确定性行为为主；LLM只可选地渲染语言，不能决定对错或学习增益。
- 输出必须标记 `synthetic_ai_generated` 或 `simulation_precalibration`，不得写成真人学习、教师金标、真实参数校准或因果教育效果。
- 同一版本、seed、画像、课程和策略应可重放；模拟客户端仍遵守Consent、Governor、考试隔离和审计边界。
- 验收至少覆盖六类画像、固定误区、支架渐撤、过早答案、KT识别、复习调度、状态污染与并发/恢复压力；详细边界见[模拟器采纳决策](../决策/V3合成学习者模拟器采纳决策与边界-20261006.md)。

先S1a确定性核心/隔离，再S1b同API多轮与基础五场景，S2增加敏感性与负载，S3才评估LLM/UI；并发规模不是首版直接要求。全量回归、隐藏状态泄漏红队、真人DB/workspace内容不变、来源导出拒绝混合、显式预算/停止和重试收据应通过测试。直接答案作为R-01拒绝场景或离线反事实，不可禁用Governor。潜变量MAE与下一次作答Brier分开，所有指标必须包含模拟假设局限。详见[架构设计](../架构/V3合成学习者仿真实验子系统设计-20261006.md)。

## 工程准入

- 锁文件可验证，隔离环境安装一致；编译、依赖完整性、pytest全量通过。
- CI应执行PG16真实归档/恢复测试和中文OCR，不以未配置DSN或无字体静默跳过代替验收。
- 冻结场景、红队、幂等/CAS/回放/撤回仍是门禁；浏览器主要流程及深色风格保持。
- 首次远端运行的job链接、SHA、结果和跳过数量单独记录；本地未推送时不得填远端成功。

## 首选课程审核包

候选：初中数学一元一次方程，复用现有等式性质/求解等KC，不凭空扩展全科。

每个课程版本至少应有以下材料与字段；这是验收清单，当前不是已审核课程。

| 对象 | 必备内容 | 审核/拒收条件 |
|---|---|---|
| 课程来源 | 课程版本、来源/许可、适用年级、source hash | 无权使用或版本无法定位则拒收 |
| KC与先修 | KC ID、可观察目标、先修边和例证 | 图中循环、含糊目标、来源不明需修订 |
| 评测蓝图 | 诊断、练习、前后测、迁移、延迟回忆与KC覆盖 | 前后重复同题不作为独立增量；迁移不能只有标签 |
| 每个任务 | assessment/version、题干、答案/可验证条件、难度依据、Bloom任务要求 | 自动标签不是学生认知结论；真实教师逐题复核 |
| 定性rubric | rubric/version、等级描述、正反例、评分者流程 | 不一致或无可审证据不能进入mastery gate |
| 误区与支架 | 误区证据、提示0..N阶梯、答案暴露标记、渐撤条件 | 不用完整答案替学生执行；审查逐题提示 |
| 审核记录 | 真实审核人引用、时间、审查版本hash、approve/revise/reject、意见 | 课程修改使旧批准失效；未审核草案只供本地/夹具 |

课程 `source_kind`（合成/真实来源）和 `review_status`（草案/批准等）必须独立：教师审核AI草案不等于生成真实学生数据。教师审核不能由AI代签。本机审查包先准备为待审，不写虚假approved。

## 真实Pilot之前必须满足

1. 明确研究目的、范围和责任人；未成年人按适用规定取得研究/监护及学习者授权。教学授权不能代替研究授权。
2. 最小学习者身份隔离与教师权限可以验证，记录主体不可由请求随意指定；单用户用途token不足以宣称学校部署。可评估隔离单人研究实例，但需证明无跨人数据混用。
3. 已审核的课程版本冻结，配置更改记录来源；R-05有人工升级路径，来源/KC/action接地与真Provider风险通过审查。
4. 授权范围、撤回后的读取/分析排除、数据最小化、保留期限与删除流程被明确并可演练。append-only保留不直接凌驾于删除权；删除后允许留下什么去标识审计痕迹需政策批准。
5. 单独研究数据集，不混入synthetic、虚拟学生或开发账号；pseudonym不是充分匿名，映射表需独立受控。
6. 冻结测量方案、终止/退出条件、缺失记录方法、安全事件处理与备份恢复。正式收集前确认适用的伦理与机构批准。

10～30人仅为反馈中建议的探索规模，不预设招募权限、统计效力或KC校准足够样本。真实招募/学校协调需外部条件，本地开发不能替代。

## 测量与校准

- 用不重复且经过可比性审核的前后题、rubric与难度层；显式记录attempt、assistance/答案暴露和测量窗口。
- 无辅助后测、迁移任务、延迟回忆均保留来源Evidence；自主性保留独立尝试、求助、反思、修订、自检的行为分解，不任造总分。
- 先检查缺失、异常和教师纠正工作量，再分析描述性增量；不能据小样本宣称因果或长期收益。
- BKT/Retention等参数从离线评估开始。校准/验证划分防止同一学生或相同题泄漏，报告样本与KC覆盖、不确定性和群体差异。
- 自动晋级继续关闭；真实样本不足/研究授权撤回/教师抽样未通过时阻挡发布。手动版本晋级需回归、回放、审批与回滚。

## 不在第一批交付

真实学生研究执行、实际教师审批、实证教育效果、PG主存储、完整SSO/多租户、neural embedding、成熟长期画像和自动RSI均不能凭本文宣称完成。
